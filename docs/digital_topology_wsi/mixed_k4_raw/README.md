# Mixed F2→F1 K4 development evidence

The `p4` and `p8` prefixes designate F2 patch widths of four and eight source cells. Each model has four mixed F2→F1 macro-rounds at a 257×257 **control-vertex** grid, not a 257×257 image. Both use the same 102 ACROBAT training IDs, frozen base/lower recurrent heads, 2,400 training steps, batch four, and DHR coordinate pseudo-target as the K2 study. Their two learned 257-level image heads are shared over rounds. The models were trained separately from K2; this is an architecture-budget comparison, not a controlled continuation of K2 weights.

The train/prediction manifests, head-weight archives, 16 actual/blank final maps per arm on eight **previously opened** development IDs, pseudo-target reports, four BIRL landmark score reports, compact stage-trace summaries, and one K4 p8 full-P1-image-loss VJP report are kept here for web review. The original 96-stage per-arm trace arrays are under `D:\QC_optimization_data\digital_topology_wsi\ACROBAT_train_subset\scaleup102\mixed_p{4,8}_k4_2400_trace.npz`; image inputs and DHR teacher arrays are not duplicated in Git. The stage-trace summaries were generated without loading the teacher. Each saved stage array is audited for exact-binary32 positive Q1 corners and ordered boundary, but the stage archive does not include every internal patch/color pass.

These are development cases and a teacher fit, not untouched specimen-group accuracy, official ANHIR test results, or a claim of competitive pathology registration. See [EXPERIMENTS.md](../EXPERIMENTS.md) for metric definitions, comparisons, timing scope, and limitations.
