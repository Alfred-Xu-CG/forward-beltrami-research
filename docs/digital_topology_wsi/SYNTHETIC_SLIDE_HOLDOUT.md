# 真实切片纹理上的合成形变：组间留出网络能力实验

## 问题与不能推出的结论

问题是：现有图像到安全 Q1 网格的网络，能否从**未见过的真实病理切片纹理**推断人工生成的、真值已知的同模态小形变？同时比较不训练网络、而在每个测试图像对上直接优化**相同安全几何解码器**的方案。本实验不能检验真实跨染色配准、复杂大形变、病例级统计泛化或 SOTA；64 个测试形变只来自**一个**完全留出的肾脏切片组，其两种染色图像也不能视作独立病例。

## 坐标、输入、输出及真值

令图像域为 $\Omega=[0,1]^2$。$512\times512$ 灰度图像的像素 $(i,j)$（先行后列）位于亮度采样点

$$q_{ij}=((j+\tfrac12)/512,(i+\tfrac12)/512).$$

与之不同，$257\times257$ 形变控制顶点位于 $v_{rc}=(c/256,r/256)$。图像亮度在像素中心之间作双线性插值；网格 Q1 地图在控制顶点之间作双线性插值。调用中的 `align_corners=False` 用于**亮度**采样，`align_corners=True` 用于**地图顶点**插值；它们不是两种任意可交换的数值设置。

设 $b_1=\sin(\pi x)\sin(\pi y)$、$b_2=\sin(2\pi x)\sin(\pi y)$、$b_3=\sin(\pi x)\sin(2\pi y)$。从六个独立系数 $a=(a_{x1},a_{x2},a_{x3},a_{y1},a_{y2},a_{y3})$ 构造

$$T_a(x,y)=(x,y)+\left(\sum_{k=1}^3 a_{xk}b_k(x,y),\sum_{k=1}^3 a_{yk}b_k(x,y)\right).$$

各分量系数从对称均匀分布取样，绝对值上界为 $(.018,.008,.008,.018,.008,.008)$。所有 $b_k$ 在边界为零。每个导数分量的绝对值小于 $\pi(.018+2\cdot.008+.008)<.132$，因此 $\|DT_a-I\|_2<.264<1$：$T_a$ 为恒等边界、全局双 Lipschitz 的取向保持映射。移动图像 $M$ 是**单张真实切片缩小后的纹理**；固定图像由 $F_a(q)=M(T_a(q))$ 双线性取样生成。所以每个样本的两张图是同一纹理的人工变形，不是两种真实染色之间的对应图。真值 $T_a(v)$ 只进入地图监督实验和**事后评价**，绝不进入图像编码器输入。

训练纹理为 HistoReg CD68/CD4 与 BIRL lesion HE/proSPC 四张缩略图，索引 0–3；测试纹理为另一 BIRL kidney HE/PanCytokeratin 两张，索引 4–5。训练的128个系数向量由 seed `291002` 生成，测试的64个由 `291003` 生成，随机训练抽样使用 `291004`。两类训练中不读取测试纹理；每张测试纹理被反复配以不同系数，因此**64 不是 64 个独立病理组**。此前其他开发实验已经检查过 kidney 组，而且这次100步先导结果也先于800步实验被查看；这是**训练组隔离的开发探针，不是未触碰的确认性盲测**。预处理只把每张原图各自缩到512²、转灰度并将强度表示为 $1-I/255$，未把两张不同染色图对齐。源路径和确切样本系数保存在 D: JSON 中。

网络输入为 $(F_a,M)$ 两张 $512^2$ 灰度张量；16通道卷积编码器输出 17² 种子上的四次 F2 latent，以及 33²、65²、129²、257² 各一级 F1 latent。F2/F1 的局部安全缩放产生同一张 257² Q1 残余顶点表 $U_\theta(v)$，边界恒等。这里**忽略并不训练**网络的全局仿射头，以保证比较中的三种地图都以方形域和固定边界为目标；没有后处理折叠修复。网络输出不是一张512²图，也不是一张低分辨率图经随意重采样后的地图。

## 三种训练/推断口径

1. **地图监督网络。** 800步、batch4、Adam学习率 .002，目标为 $|V|^{-1}\sum_{v\in V}\|U_\theta(v)-T_a(v)\|_2^2$。真值地图是特权训练标签；这只验证表示与从图像中预测该合成分布的能力，不可与只见图像的优化器作信息量公平的胜负结论。
2. **仅图像损失网络。** 完全相同的网络、样本和步数，从新随机初始化开始，但目标为 $512^{-2}\sum_q[M(U_\theta(q))-F_a(q)]^2$。代码在组 batch 时生成真值表以供之后评价，训练分支的 `loss` **不引用**该表。即使如此，训练对的合成生成规律显然是研究者已知的。
3. **无网络逐对优化。** 冻结相同 F2/F1 几何层，对每批四个测试图像对的每个 seed/fine latent 直接从零开始用 Adam 优化50步，目标为上式图像 MSE 加 $\lambda|V|^{-1}\sum_v\|U(v)-v\|_2^2$。开发选择只用训练纹理索引0–3和另一个系数 seed `291005` 的16例，固定学习率 .01、50步，从 $\lambda\in\{.01,.1,1,10,100\}$ 按**开发地图误差**选得10，然后锁定并运行64个肾脏测试样本；没有依据其测试真值调参。这是有开发真值用于超参选择的基线，非纯无监督模型选择。

各样本地图误差定义为 $e_a=\sqrt{|V|^{-1}\sum_{v\in V}\|U(v)-T_a(v)\|_2^2}$；表中是64个 $e_a$ 的算术均值，不是把64例平方误差先合并再开根号。图像 MSE 是512²固定像素中心处的平均亮度平方残差，再对64例取算术均值。恒等地图使用同样的真值和图像采样口径。速度在AI主机空闲 RTX A6000、PyTorch2.5.1+cu124、float32、batch4计时；“每图”是 batch4 的吞吐时间除以4，**不是单例延迟**。peak CUDA allocated 不是全部预留显存或整机 RSS。

网络训练完整步中位为地图监督 .07839 秒、仅图像损失 .09593 秒；分别训练800步。逐对优化50步的单步中位为 .07597 秒；上表逐图时间含循环与输出评估。**上表网络的 `.0044–.0046 s` 仅计图像到257²顶点的前向，不含随后512²查询与亮度取样；逐对优化 `.95282 s` 包含50次图像取样、反传及最终评价，不能把两列直接称为完全同口径速度比。** 下述 P1 完整前向另测网络、P1查询与亮度取样共约每图 `.005 s`；它仍不含 JPEG 解码、CPU→GPU、文件证书，且使用 batch4 热态吞吐。数字不是跨机器随机交叉多次的稳定性能估计。开发集 $\lambda$ 扫描所得地图误差依次为 `.009487/.009195/.008410/.007804/.007976`，恒等 `.008364`。测试上，逐对优化虽把图像 MSE 降得最多，几何地图却比恒等还差；这正是 **光度最优不等于位移准确** 的具体反例。在这个单组测试里，仅图像损失的网络比该预选逐对优化器地图误差较低、吞吐较快，但仍有很大的真实跨染色证据缺口。

### 三组轮流不参与网络训练的开发复核

为避免把 kidney 一组的方向误当普遍规律，保持上述架构、800步图像损失、系数种子、batch4、257²/512²设置不变，让三个文件组轮流完全不参与**该折**网络训练。每折其余两组各两张图作训练纹理；每折测试64个形变仍只属于一个物理切片组。逐对优化统一使用上面开发扫描选出的学习率 .01、50步、$\lambda=10$。注意 $\lambda$ 是用 HistoReg+lesion 两组开发纹理选出的，因此 HistoReg 与 lesion 两折的优化器超参**接触过其测试纹理**；这只是重复开发诊断，不能称干净的嵌套交叉验证或盲测。

| --- | ---: | ---: | ---: | ---: |
| HistoReg CD68、CD4 | .00824281 | **.00526904** | .00748458 | .000308744 / **.000159402** |
| BIRL lesion HE、proSPC | .00824281 | **.00702022** | .00837340 | .004381866 / **.001378624** |

三折图像损失网络的地图误差都比恒等和这个有限预算优化器低，但各折只有一个测试文件组，且同一系数 seed 在不同纹理组复用。这支持**该合成任务上的可迁移倾向**，不足以估计未知病例分布的泛化置信度，更不证明所有无网络优化方法不如该网络。对应逐例文件是本目录的 `synthetic_slide_{histo,lesion}_image.json`、`synthetic_slide_{histo,lesion}_baseline.json` 及 kidney 的原两份测试 JSON。

### 把同一顶点表当作真正的固定剖分 P1 地图

用户目标是分片仿射地图，因此又冻结上述三折的**仅图像损失网络权重**，在每个257²输出表上以固定 SW–NE 对角线每格构造两三角形，而不改变顶点、重新训练或重采样地图。每个映射有 $2(256)^2=131{,}072$ 个 P1 面；从 Q1 的四个角行列式取对应 SW–NE 的两项。三折各64张地图上的 $64\times131{,}072=8{,}388{,}608$ 个面均在 float32 计算中严格正；每折保存首例另有精确二进制四角证书。Q1 和 P1 是**不同的格内函数**，虽然共享控制顶点；下表专门在512²像素中心计算 P1 插值误差，而非以顶点误差冒充。

| 组 | P1 query-map RMSE | Q1 query-map RMSE | P1 与 Q1 query 值 RMS差 | P1 / Q1 图像 MSE |
| --- | ---: | ---: | ---: | ---: |
| HistoReg | .00527298 | .00527142 | .000103735 | .000308909 / .000308744 |
| lesion | .00702451 | .00702298 | .000123026 | .004384876 / .004381866 |
| kidney | .00724517 | .00724385 | .000105556 | .003900571 / .003897643 |

此512²中心点与257²顶点的尺度组合中，恰有一半 query 落在某个固定 SW–NE 对角线**上**。这不造成地图值含糊：在对角线上，两侧仿射公式的值及对**顶点值**的导数相同；对 query 位置本身的导数则可有左右差别。专门的单元测试核对了前两者。P1 测试代码为 [`digital_q1_synthetic_p1_eval.py`](../../tools/digital_q1_synthetic_p1_eval.py)，逐例 JSON 为本目录的 `synthetic_slide_p1_{histo,lesion,kidney}.json`。上述图像损失是在 Q1 表示下训练的，P1 结果只是冻权重部署评价；不能声称重新以 P1 图像损失完成了训练。

### 真正通过 P1 查询路径反传训练

为填补上一段的缺口，再从新初始化的网络分别运行三折，训练数据、800步、batch4、Adam `.002` 与前述**仅图像损失网络**一致，但训练与测试亮度目标都明确替换为

$$\mathcal L_{P1}(\theta)=512^{-2}\sum_{q\in Q}\big[M(P1(U_\theta)(q))-F_a(q)\big]^2,$$

其中 $P1(U_\theta)$ 是固定 SW–NE 三角剖分上以网络输出顶点为节点值的分片仿射函数，不涉及全局线性系统。反向传播依次穿过像素亮度的双线性取样、P1 重心插值、F2/F1 安全更新以及 CNN 权重。此次没有用真值 $T_a$ 作训练损失。独立 checker 暂停 Q1 图像查询路径后 P1 训练仍能运行；P1 查询的反向梯度非零；把 `target` 改成 `target+123` 不改变损失与更新权重，只改变事后地图评价。这比仅检查梯度非空更能排除误走 Q1 或真值泄漏。

| --- | ---: | ---: | ---: |
| HistoReg | .00526904 / .000308909 | .00535760 / **.000295019** | .00501 s |
| lesion | .00702022 / .004384876 | **.00678150** / **.003777946** | .00496 s |
| kidney | .00723054 / .003900571 | .00728848 / **.003869798** | .00500 s |

三个完整训练步的中位耗时分别 `.07960/.07903/.08307 s`（batch4，含前向、P1图像损失、反传和Adam更新），峰值 CUDA allocated 均约 `597.6 MB`，800/800步梯度有限。每折64例实际 P1 原面均经浮点严格正定向检查；首例存储文件另经精确二进制Q1角符号和边界审计。这一结果证明**该具体 CNN→F2/F1→257² P1→图像取样路径可端到端训练**，不证明图像误差和几何误差同步改进：P1直接训练在三折图像目标均好一点，顶点精度只在 lesion 折提升。完整前向吞吐是已在 GPU 上的512²图像、batch4 的热态每图时间，计网络、P1查询和亮度取样，不计数据装载或证书。`synthetic_slide_p1_trained_{histo,lesion,kidney}.json` 与 `synthetic_slide_p1_eval_trained_{histo,lesion,kidney}.json` 给出每例数字和完整P1查询指标；权重和首例地图留在D盘。

每批网络/优化输出都运行现有浮点 Q1 四角检查和边界检查；每种最终方法的**首例保存表**又经精确二进制符号核验，有262,144/262,144个严格正四角、精确恒等边界。其余63例当前未各自保存并逐例作精确二进制核验，不能把一个样本的文件证书写成64个文件证书。F2/F1构造的数学保拓扑前提与实际保存浮点表的复核范围应分开说。固定 SW–NE 对角线的 P1 插值也能由四角正性得到原三角形取向正，但这次脚本没有另导出含全体面的显式 P1 网格文件。

独立 checker 在另一执行上下文中用 NumPy 解析地图与 SciPy 插值，重新从**已保存的地图监督网络权重**推断全部64例，得到地图误差 `.00404106303598`、图像 MSE `.00318869504553`，对应原 JSON 为 `.00404106308997`、`.00318869541843`；逐例地图误差最大差 `8.32e-9`。checker 还把训练 batch 的真值 target 毒化为 `target+123`：仅图像损失模式的单步 loss 和训练后权重逐位不变，而事后地图评价如预期恶化，排除了该分支意外读入目标坐标的路径。另一个负索引故障样本曾能用 `test=[-1]` 绕过训练/测试索引不相交检查；现已拒绝负索引并增设回归测试。首例三种方法的存储坐标独立精确符号检查分别严格正；仅图像网络和优化器的最小**归一化**角行列式约 `.0499990/.0499871`，不能把名义 `.05` 安全阈值误写成保存浮点表的严格下界。checker 的常量纹理反例使图像损失接近零而地图误差仍为 `.014975`，进一步说明单纯亮度目标不识别所有位移。

实验代码为 [`digital_q1_synthetic_slide_holdout.py`](../../tools/digital_q1_synthetic_slide_holdout.py)、[`digital_q1_synthetic_slide_baseline.py`](../../tools/digital_q1_synthetic_slide_baseline.py)、[`digital_q1_prepare_slide_textures.py`](../../tools/digital_q1_prepare_slide_textures.py)。逐例及开发扫描 JSON 同时存于本目录并进入 Git；输入纹理缩略图、首例 NPZ 与两套网络权重保存在 `D:\QC_optimization_data\digital_topology_wsi\synthetic_slide_*`，不把切片像素或派生网络权重推送到远程仓库。保存权重和图像纹理的独立复算需要访问这些 D 盘文件。

**下一判断：**此结果只给出“网络学到了少量可转移的同模态合成形变先验”的有限证据，仍不足以把 G2 标为真实病理配准 PASS。应增加独立切片组，评估不靠人工已知地图监督的跨染色对应，并维持整个物理组留出与相同安全几何层的无网络对照。
