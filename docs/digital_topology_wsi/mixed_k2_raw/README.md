# Mixed F2→F1 K2 development evidence

The p4/p8 prefixes designate the F2 patch width (4 or 8 source cells). Both models use two mixed macro-rounds at a **257×257 control-vertex grid**, the same frozen base/lower recurrent heads, 2,400 steps on the same 102 ACROBAT IDs, and a DHR pseudo-target. The p4 F2 raw span is 1; the p8 span is .5. The two head weight archives and common frozen-base archive allow the model class in `src/qcopt/neural_bijection/dense/q1_recurrent_image_network.py` to be reconstructed. Training/prediction manifests record the remaining options.

`p{4,8}_<case>_{actual,blank}_safe_q1.npz` are the 16 final residual-map predictions per arm on **eight previously opened development IDs**. Each archive includes the final vertices, boundary reference and saved external affine. The JSON reports contain their DHR pseudo-target scores, development landmark scores for two separate BIRL pairs, and measured round-entry/F2/F1 changes. The full 48-map per-arm stage archives and original run directories are retained on D under `D:\QC_optimization_data\digital_topology_wsi\ACROBAT_train_subset\scaleup102\mixed_p{4,8}_k2_2400_trace.npz` and `...\recurrent102_dense257_mixed_p{4,8}_k2_2400`; the 512² image inputs and DHR teacher arrays are not duplicated here. Thus this Git subset supports inspection of final maps/checkpoints and reported numbers, while recomputing a trace certificate requires the named D archive.

The image-to-latent network was trained on DHR *pseudo-target coordinates*, not manual correspondences. The eight ACROBAT IDs and lesion/kidney landmark cases were used repeatedly in development. No result here is an untouched-group performance estimate or an official ANHIR test result. See [EXPERIMENTS.md](../EXPERIMENTS.md) for the exact metric definitions, topology scope, timing and limitations.
