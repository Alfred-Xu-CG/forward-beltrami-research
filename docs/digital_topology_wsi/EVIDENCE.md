| **ACROBAT** | Official 2023 challenge page lists 750 training cases, 100 validation and 300 test. The challenge data are breast-cancer FFPE WSIs (H&E plus up to four IHC in training; H&E plus one IHC for validation/test), 0.23 µm/pixel at 40x with lower pyramid levels. Published CSC archives are 461 GB + 475 GB train, 55.4 GB validation and 173 GB test. Current official page recommends CSC because SND downloads have had corruption reports. Rules state CC BY-NC for use outside challenge, permit external training data, and require fully automated registration. In July 2026 organizers offered test evaluations on request, limited to one per algorithm per four months. [data](https://acrobat.grand-challenge.org/data/) · [rules/license](https://acrobat.grand-challenge.org/Participation_Rules/) · [current challenge notice](https://acrobat.grand-challenge.org/) | Anonymous case ID is the available split/group key; keep all stains and resolutions for a case together. No training landmarks are supplied; validation/test source landmarks are provided while target landmarks remain hidden. Formal challenge evaluation expects a warped source image and registered landmarks in physical micrometers; use the official container protocol. [container/output convention](https://acrobat.grand-challenge.org/docker-container-details/) | **Not present locally; full-data route impractical for first pair.** Use a validation container sample or a selected downsampled WSI pair only after checking the license and downloading its official small test files. |
| **ANHIR** | Official challenge says 50+ histology sets and WSI scales from 5% through 100%; image dimensions include tens of thousands of pixels and originals up to 100k×200k. Access requires a Grand Challenge account, accepting the license and joining the challenge. Dataset use is CC-BY-NC-SA with citation/acknowledgement. Current FAQ says challenge is over, submission has reopened, and half the landmarks remain private. [dataset/access/license](https://anhir.grand-challenge.org/Data/) · [FAQ](https://anhir.grand-challenge.org/FAQ/) | A set contains successive tissue sections/stains from a sample/block; use set as the indivisible grouping key, never split images/pairs within a set. Landmarks are image-plane pixel coordinates with top-left origin. Official evaluation specifies medium-scale results, registration time including image loading (excluding landmark warp), and treats missing registrations as initial rTRE / last-ranked. [evaluation](https://anhir.grand-challenge.org/Performance_Metrics/) | **Not present locally; not runnable pending account/join/download.** Lowest storage entry point is official 5% scale, but current access needs account/join. |
