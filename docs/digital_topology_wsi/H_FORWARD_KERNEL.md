# A one-pass coarse-to-fine, positive-Q1 decoder of sparse image matches

## Predeclared research card

**Question.** Pair-specific Adam fitting of the safe Q1 residual reaches its best image-match checkpoint after only 2–27 completed updates on three development pairs, yet the planned 200-step run takes about 13 s. Can a *forward* Gaussian interpolation of the same image-generated sparse displacements, followed by explicit F1-D safety updates, produce a useful dense Q1 homeomorphism at much lower latency without solving any large linear system?

**Exact claim under test.** Given fixed-frame machine matches \(q_i\mapsto p_i\), define \(d_i=p_i-q_i\). At grid vertex \(v\), compute normalized Gaussian interpolation \(d_\sigma(v)=\sum_i w_i(v)d_i/(\sum_i w_i(v)+10^{-8})\), with \(w_i(v)=\exp[-\|v-q_i\|^2/(2\sigma^2)]\) and one predeclared \(\sigma=0.12\) in unit-square coordinates. Starting from identity on 17², apply a single four-color F1-D safe update toward \(v+d_\sigma(v)\), then exactly dyadically refine to 33² and 65² and repeat one F1-D update on each; refine without additional motion to 129² and 257². At each update, propose per-coordinate logits \(z=\operatorname{atanh}\operatorname{clip}((v+d_\sigma(v)-U(v))/(2h),-.95,.95)\), so the existing F1 layer's raw proposal \(2h\tanh z\) points toward the interpolated target and its per-vertex safety scale preserves corner signs. This construction is differentiable with respect to finite match coordinates/displacements **away from** proposal-clamp thresholds and F1's active-constraint min/max/conditional ties, and has the existing F1-D exact-arithmetic topology guarantee. The exported binary32 table still requires an actual saved-output audit.

**Assumptions.** Initial affine \(A\) and SuperGlue/RANSAC matches are frozen image-only inputs from `H_SIFT_RESIDUAL.md`; no anatomical labels enter interpolation or parameter selection. A fixed ordered identity boundary is maintained by F1-D; \(A\) has exactly positive determinant. All Gaussian weights are nonnegative, but this alone gives no injectivity; topology comes from F1's local guard. The 257² output has effective deformation detail no finer than 65² and is not advertised as a fully independent 257² latent field.

**What would falsify utility.** Invalid saved corner signs, nonfinite gradients with respect to displacement inputs, inability to reduce held-back machine-match error below identity, worse anatomical TRE on all three development pairs, or forward latency comparable to a 200-step optimizer. Even a positive result is a feature-to-map decoder, not the desired image-to-latent CNN, because the external DHR affine and SuperGlue matcher cost seconds.

**Smallest decisive test.** Unit-test identity, a smooth synthetic displacement, finite match-displacement VJP and exact dyadic Q1 refinement. Then run the same 80/20 deterministic match split as the pair-specific optimizer, feeding **training matches only** to Gaussian interpolation; evaluate held-back match vector RMSE and independently evaluate anatomical landmarks. Use exactly the same \(\sigma=0.12\), three update resolutions and floating-point precision on all three pairs. Record decoder-only forward/VJP time, CUDA allocated peak, saved map certificate and full upstream image-feature timing separately. No landmark-based tuning of \(\sigma\) or step schedule within this experiment.

**Prior work / novelty boundary.** Gaussian/Shepard interpolation of sparse motion and multiscale deformation are standard. F1-D is a hard local feasibility map built earlier in this repository. Their combination is a candidate fast *forward topology-preserving decoder of spatial proposals*, not yet a new image-to-map network and not evidence that the chosen kernel approximates most homeomorphisms.

## First fixed-bandwidth experiment

The implementation receives only the frozen SuperGlue/RANSAC match JSONs and the previously image-only DHR initial-affine archives. It uses the same deterministic 80/20 accepted-match split as the 200-step sparse optimizer; only the 80% subset supplies kernel motions, and the remaining 20% supplies an image-generated diagnostic. As in the optimizer comparison, RANSAC was performed **before** the split on all candidate matches, so the held-back points are not an independent test of match generation. No anatomical label enters map construction, bandwidth selection or match splitting. The fixed sigma is `.12` unit-square widths for all pairs. The selected residual is computed in a single forward pass with F1-D updates at 17², 33² and 65², then Q1 refinement to 257²; the published output is the **saved binary32 257² residual table plus unchanged positive affine factor**, not a newly rounded composite table.

Times are ten-repeat medians after three decoder warmups on idle RTX A6000 GPUs (physical GPU0 lesion, GPU2 HistoReg, GPU6 kidney), batch one, float32. The VJP differentiates a scalar map loss with respect to **input match source and target coordinates**, not all possible image pixels or neural-network weights; all tested match-coordinate gradients were finite. Reported memory is PyTorch CUDA *allocated* peak measured around decoder calls, excluding the external affine matcher, pretrained SuperGlue model, JPEG loading, output saving and certification. The SuperGlue extraction itself took 1.73/3.33/2.09 s for lesion/HistoReg/kidney in isolated commands, while DHR image-only affine initialization was separately measured at about 1–2 s for small JPEG pairs and ~38 s for HistoReg under the cached pipeline. Those upstream costs must be included in any full registration accounting; the 9–10-ms figure **is decoder-only, not image-to-map inference**. The first GPU pilot failed because an F1 layer was constructed on CPU while its input and generated logits were on CUDA; a CUDA reproducer caught that `index_copy` device mismatch, then a one-line device transfer fixed it. No output from the failed run was used.

All three returned in-memory residuals had ordered identity boundaries and no nonpositive corners. Each saved archive passed the binary-rational checker for all **262,144/262,144 Q1 corner determinants**, and its unchanged float32 affine matrix has exactly positive determinant as a binary rational. Under the established Q1 global-boundary hypotheses, each stored factorization represents a homeomorphism onto an affine parallelogram. The separate read-only evaluator found exactly one inverse root for each matching original-JPEG landmark (77/77, 78/78, 69/69, respectively) and mean TRE **25.7405, 8.1245, 7.4369 pixels**. The full saved maps, machine reports and evaluator results are at `D:\QC_optimization_data\digital_topology_wsi\h_forward_kernel_{histo,lesions,kidney}_257_{map.npz,report.json,eval.json}`.

**Interpretation.** On two inspected development pairs, a direct forward decoder improves anatomical TRE by more than the sparse 200-step fit using the *same* accepted matches, while the lesion pair worsens relative to the affine initializer. The comparison is not a clean algorithmic superiority claim: the pair-specific optimizer trains only early levels but uses held-back match checkpoint selection, whereas the forward kernel uses an a priori bandwidth and no fitting; neither is tuned on independent specimens. The 257² table is an exact-Q1-refinement design in exact arithmetic but has effective nonrigid detail no finer than 65² and can differ slightly after binary32 rounding; each stored output was checked anew. This finding motivates replacing the seconds-cost external proposal chain with a learned image-to-match or image-to-kernel-field frontend and testing spatially localized, multi-bandwidth proposals on independent groups. It does **not** yet meet the project's target of a fast end-to-end image-pair neural layer at genuine dense-detail resolution.

## Independent forward-kernel review

An independent NumPy Gaussian calculation agrees within `1.39e-17`. The `+1e-8` denominator shrinks motion toward zero where support is weak; this is a smoother, not exact interpolation through the matches. The proposal formula correctly inverts default `raw_span=2`: before safety scaling it is `2h*clip(Δ/(2h),-.95,.95)`, capped at **1.9h per component**, not necessarily parallel to the unclipped vector. All interior vertices, including inherited coarse vertices, can update at 17/33/65; 129/257 only refine. Identity matches reproduce identity exactly in a 65² double-precision fixture. Gaussian nonnegativity alone is insufficient: deliberately reflected matches gave unguarded minimum normalized Jacobian **−7.27768**, whereas the guarded 17² output retained **+.25**. Deliberately using raw span 1 instead of 2 halves the intended proposal.

The input split matches the optimizer exactly: **92/24, 118/30, 64/17** training/held-back points. Only training matches enter construction; labels are absent. Direct four-weight evaluation of saved maps gives held-back RMSE **`.00309882132/.00714605591/.00474111384`**, within `6.4e-9` of reports. As documented, all-match RANSAC precedes the split and the held-back values are not independent pathology-test evidence.

Independent arbitrary-precision integer checks find all **262,144** residual corner signs positive per map, with exact identity boundaries. Minimum normalized determinants are **`.3827972412/.7789282981/.7361273239`**. Saved affine factors match the declared archives bitwise and have positive exact rational determinants. Separate affine inversion plus SciPy bilinear residual inversion reproduces **25.7405340574/8.1244535032/7.4369027521 px** mean TRE and **77/77, 78/78, 69/69** unique roots; maximum per-label discrepancy is `2.87e-12` px. These checks certify the stored Q1-plus-affine representation, not arbitrary later resampling.

Source-and-target directional VJP checks against central differences on double-precision 17² small/large-motion fixtures differ by **`1.84e-9/2.06e-8`**. This strengthens the finite-gradient evidence but is not a global gradient theorem; active-constraint ties and clips remain nonsmooth. CPU tests: **5 passed, 1 CUDA-only test skipped**. Forward timers include Gaussian construction, newly constructed F1 layers and refinement, but exclude affine composition, upstream matching and validation. Forward allocated-peak measurement also spans the post-loop match diagnostics and tensor validator, so it is not a strictly isolated timed-region peak. VJP timing is forward plus one scalar-loss backward, not the full Jacobian or differentiation through discrete SuperGlue/RANSAC. Upstream cached-DHR timings describe a separate run, not an end-to-end timing of these exact saved-affine artifacts. No GPU jobs or implementation edits were performed for this review.
