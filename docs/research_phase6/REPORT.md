# Phase VI：稠密矩形三角网格的可微同胚层——总报告

> 状态：执行中；本报告在 18 小时终点前还会接受独立复核。原始计时起点见 [START_TIME.json](START_TIME.json)。所有结论只针对明确写出的网格、边界、目标族、数值精度和检查条件。

## 1. 研究问题、输出对象与符号

令 $\Omega=[0,1]^2$。一个 $N\times N$ 控制顶点网格有 $N^2$ 个顶点；本轮每个小正方形按西南—东北对角线分成两个三角形，故原三角形数为 $2(N-1)^2$。当 $N=257$ 时，**控制顶点**有 66,049 个、原面有 131,072 个；512²图像像素/查询点是另一个量，不能代替控制规模。当 $N=1025$ 时，控制顶点有 1,050,625 个、原面有 2,097,152 个。

给每个顶点 $p_i$ 一个像 $Y_i\in\Omega$，在每个原三角形上用三个顶点值的仿射插值延拓，所得 $F_Y$ 称为固定原网格上的 P1 映射；P1 即“每个三角形内一次多项式/仿射”。它与“储存多个 P1 因子并按顺序在动态点查询”的精确 PL（piecewise linear，分片仿射）组合不同：后者一般需把原三角形进一步切开才成为 P1。不能把组合在原顶点上采样后重新 P1 插值，当作原组合；[17²显式反例](02_alternating_factorization.md)中两个因子各自无翻折，重新插值却出现负面积。

本轮希望实现的层是 $z\mapsto F_z$，或更具体的图像条件版本 $(I_f,I_m)\mapsto z\mapsto F_z$：$z$ 是网络学习或从图像推断的内部坐标（latent），$I_f$ 是固定图像，$I_m$ 是移动图像；一次最终图像采样为 $I_m(F_z(x))$。训练像素损失是 $Q^{-1}\sum_{q=1}^Q|I_f(q)-I_m(F_z(q))|^2$，不把真目标映射放进 image-only 训练损失。反向的 VJP（vector-Jacobian product，向量与 Jacobian 的乘积）是把像素损失对层输入、latent 和可训练参数的梯度经链式法则送回去；只报告 forward 而没有可用 VJP 不算神经层。这里的“硬拓扑”指符合各路线前提时，**整个连续 PL 映射**是同胚，而非仅抽样点的 Jacobian 正。

面上仿射 Jacobian 写为 $J=\begin{psmallmatrix}u_x&u_y\\v_x&v_y\end{psmallmatrix}$。复导数 $f_z=\tfrac12[(u_x+v_y)+i(v_x-u_y)]$，$f_{\bar z}=\tfrac12[(u_x-v_y)+i(v_x+u_y)]$，Beltrami 系数 $\mu=f_{\bar z}/f_z$。$|\mu|<1$ 对单个非退化仿射面等价于正定向，却不能单凭它证明边界覆盖或全局单射；本报告的全局结论各自还需要边界与拼接条件。

## 2. 共用实验口径与证据强弱

主要合成任务有 32 张训练图、8 张独立保留图，以及另一个 seed 的 128 张新样本；移动/固定图分辨率 512²，目标包含 32 周期局部细节。目标映射独立于 A/B/C 候选生成，真实顶点/面几何只供评价，不进入 image-only 损失。六张来自 scikit-image 的灰度照片各叠加 16 个**已知合成**形变构成 96 例域外图像内容测试；这不是临床数据，也不是未知真实形变注册。训练 batch、设备、精度、迭代和目标函数在各路线文档与原始 JSON 中列出；跨路线冻结计时采用同一 AI 主机物理 GPU2，见[共同计时](25_same_gpu_257_crossroute.md)。

像素 MSE 是最终 warp 后 $Q$ 个像素平方残差均值。map RMSE 是 $\sqrt{(2Q)^{-1}\sum_q\|F(q)-F_*(q)\|_2^2}$，单位为单位正方形坐标。面 $\mu$ RMSE 对固定 P1 输出在全部原面上计算；对组合输出若只用源面重心/像素点计算，会明确称“采样 $\mu$”而非完整叠加分片积分。最小面积比是每个映后原三角形有向面积除以其原有向面积的全局最小值；组合路线则报告每个因子的该值，组合整体通过因子同胚定理，而不伪称有同一原面最小值。最大 $|\mu|$、最小面积及边界均应与浮点输出一起检查。求解路线另外报告真实相对线性残差；残差小不自动推出无翻折。

计时中的“完整 forward”通常包括图像条件 latent 推断、映射生成、512² 最终查询与一次 warp/loss；VJP 是该损失回传。GPU 同步后取热身后重复的中位数。显存是 PyTorch peak allocated，不是显卡总占用；部分脚本常驻训练/保留图的数量不同，不能把小幅峰值差当作严格算法排名。预计算和训练墙钟另报，不偷偷合进热启动 forward。若比较不同参数数目或 VJP 输出范围，也明确标注。

## 3. Route A：显式几何生成及精确嵌套细分

### 3.1 原网格单调纤维映射

取列坐标 $X_0=0<X_1<\cdots<X_{N-1}=1$；每一列取 $V_{i0}=0<V_{i1}<\cdots<V_{i,N-1}=1$。顶点输出 $F(x_i,y_j)=(X_i,V_{ij})$。有限 logits 经带正下界的 softmax 间距归一化与累加，构成严格有序坐标。对每个原面，$\partial_xF_1>0$、$\partial_yF_2>0$，且 $\partial_yF_1=0$，于是 $\det DF>0$。更强地，每条竖直纤维的第二坐标严格递增并覆满 $[0,1]$，不同纤维的第一坐标严格有序，给出全局双射及连续逆。水平方向交换坐标得到另一同胚因子。这一构造无线性系统、VJP 通过标准张量运算，但单因子的 $F_1$ 只能随列变化，表达受限；详见[交替因子及表示定理](02_alternating_factorization.md)。

### 3.2 学得粗层后的精确 P1 细分

最有用的 A 候选先通过 image-to-latent A8 网络生成 257²固定原网格同胚 $f_C$；“A8”是本轮第八个安全图像反馈实验变体的名称，并非数学算子。再令细网格边长为粗网格的四分之一，得到 1025² 网格。每个细三角形属于一个粗三角形；若细顶点 $p$ 的粗三角形重心坐标为 $\lambda_j(p)$，定义 $Rf_C(p)=\sum_{j=1}^3\lambda_j(p)f_C(v_j)$。因粗三角形内 $f_C$ 本来仿射，细面 P1 延拓**作为连续函数恰等于** $f_C$，并非普通双线性上采样的近似。这一步保留已学得的映射和拓扑，又提供了 1025² 个细控制顶点供新的局部反馈更新。

细反馈从图像残差和移动图梯度构造局部二维岭回归位移提议，在细顶点按行列奇偶划为四色；同色点不共享三角形，故可并行更新。每顶点更新量是 $t_p\Delta_p$，$t_p$ 同时满足所有邻面 QC 比率上界 $|f_{\bar z}|<k|f_z|$ 和面积下界的充分不等式，并只更新内部顶点。具体公式、系数与可微操作见[细分层完整定义](24_exact_coarse_to_fine_neural_layer.md)。这不是从最终损失取 $-\nabla_fL$ 再搜索一维步长；提议来自输入图像并通过 latent/局部响应生成。安全比率的最小值操作和模式排序在并列点不光滑，像通常分段可微层一样在几乎处处有 VJP。输入和输出须经边界、全部面面积与 QC 检查，数值失败即拒绝，不把浮点误差掩成证明。

在原8例保留集合上，1025²只细分的 image MSE 为 $1.84785\times10^{-5}$、map RMSE 0.00040936；两次细反馈后分别为 $8.29604\times10^{-6}$ 和 0.00026864，面 $\mu$ RMSE 0.09183→0.07754。完整可复用模块加证书的 batch1 forward/VJP 为约 78.86/203.95 ms、peak allocated 2.15 GB；全部细面最小面积比 0.15533，最大 $|\mu|=0.78257<0.8$。独立新128例上 image/map/面 $\mu$ 也改善，但最大 $|\mu|$ 达 0.79946，说明余量很薄。真正穿过1025²细反馈的300步 image-only 反向训练约88.09秒，无折叠、梯度有限；训练后保留 image/map 反而略差，故优选冻结粗网络加细反馈，而不把额外训练说成泛化进步。照片内容96例中安全参数改为0.795，全部例子图像和位置误差改善，但面 $\mu$ RMSE 从0.12111恶化至0.14830；只有3/96例改善该导数指标。故此 A 候选已经是细控制网格可训练硬拓扑层，却尚未同时解决域外 Beltrami 精度。

## 4. Route B：精确 PL 组合的收益和代价

一个竖直单调因子 $V$ 与水平单调因子 $H$ 可精确组合为 $F=H\circ V$。若两个因子各是固定网格 P1 同胚，连续组合必为 PL 同胚；查询 $q$ 先在 $V$ 的三角形中定位并仿射映射，再在 $H$ 的网格中**重新定位** $V(q)$，所以第二层不是使用静态源面索引，也不重复采样图像。链式 Jacobian 为 $DH(V(q))DV(q)$，链式 VJP 将最终损失经两次查询送回两个 latent。因第二层网格边的逆像会切过第一层源面，复合一般不再是原固定网格 P1，需保留因子表示或显式叠加分片。

在 257²+257² 双因子的同族8例 image-trained 检查点上，保留 image MSE 0.00050483、map RMSE 0.0019299；两个因子的最小面积比分别 0.09936 和0.75636。冻结层 batch1 完整 forward/VJP 约20.58/33.00 ms、peak allocated 298 MB，是这组三路热启动中最快，却远不及 A 的图像/位置精度。直接对 latent 用真 map 作 oracle 优化可以在局部高频目标上达到远低于 image-trained encoder 的误差，显示瓶颈至少一部分来自逆推断/训练而非精确组合本身。17²反例证实重新导出单张固定原网格 P1 时可翻折；不能把 B 的组合保证移交给导出结果。局部 patch 与 coarse+fine、错位层、表达成本和失败训练详见[Route B 总记录](02_alternating_factorization.md)与[凸块层级](05_convex_quad_hierarchy.md)。

## 5. Route C：正导纳与结构化精确平衡

令 $E$ 为全细网格无向边，$I$ 为内部顶点，$B_I$ 为边—内部顶点关联矩阵。每条边取 $c_e(z)>0$，固定边界为单位方形恒等映射；内部坐标解

$$A(c)Y_I=b(c,Y_{\partial}),\qquad A(c)=B_I^{\mathsf T}\operatorname{diag}(c)B_I.$$

在连通网格上 $A$ 对称正定，因为 $u^TAu=\sum_ec_e(u_i-u_j)^2>0$ 对非零零边界 $u$ 成立。内部平衡顶点为邻点的严格正凸组合。不过本方形边界含共线顶点，不能直接套仅要求“严格凸多边形各顶点”的简述版本。[Floater 2003 的适用条件与本网格 dividing-edge 检查](19_square_boundary_tutte_theorem.md)说明：固定方形边界的连续 PL 映射，在精确平衡解下无内部 dividing edge 映到目标边界，因而是同胚。浮点 PCG 输出并非精确平衡解；实现报告真实残差并另逐面/边界扫描，不能用残差代替几何检查。

实际 image-to-latent C 层用18个预设边中点空间模态 $\phi_{ke}$ 与18维图像条件系数 $a$，令 $c_e=1+15\sigma(-0.8+\sum_ka_k\phi_{ke})\in(1,16)$。模态频率包含目标族已知的32周期，所以这是任务特化而非任意 Beltrami 求解。先在均匀导纳处解析求18个映射响应 $V_k=\partial Y/\partial a_k$；输入图像的残差/梯度在128²**光度拟合点**形成18×18带岭正规方程，获得 $a$ 的初估并作有界非线性变换；最终在全257²或1025²控制网格求真正非线性的正导纳平衡解。对 $A(c)Y=b(c)$ 的隐式 VJP，先解伴随 $A(c)^T\lambda=\bar Y$，再用 $\lambda^T(db-dA\,Y)$ 回传到18系数、可训练 gain 与输入图像，无需保存 Krylov 全轨迹。细公式和差分检查见[18模态层](17_photometric_conductance_layer.md)。

257²、32训练/8保留、300步 image-only 训练后，保留 image MSE 0.00010018、map RMSE0.00088446、面 $\mu$ RMSE0.05771、最小面积比0.559、最大$|\mu|=0.316$。同卡冻结 batch1 完整 forward/VJP 30.68/31.52 ms、peak allocated156 MB（仅8图常驻）。在1025²真正细控制网格上，逐个预计算响应再丢弃全网格版本，把一次冷启动预计算显存从约7.46 GB降为约0.91 GB，耗时仍约13秒；稳态 batch1 forward/VJP约164/195 ms、peak981 MB。继续在1025²做300步 image-only 更新，训练显存约1.10 GB、墙钟111.60秒，几何全部通过，但保留图像 MSE略恶化，见[百万顶点训练](21_million_control_training.md)和[流式预计算](22_streamed_response_precompute.md)。照片96例上 C 的 image MSE0.03254、map RMSE0.004913，远差于 A；小 $\mu$ 误差和安全裕度不能掩盖位置/图像不准。

Woodbury 对少量正边更新有精确代数意义，但粗参数若改变大量细边，更新秩随边数增长，不会自动省掉大系统。分块 Schur 与正弦预条件 PCG 均已在细网格测到完整 forward/VJP；没有把有限步近似解未经检查地称为拓扑保证。具体成本、适用范围和受限表达详见[结构化求解比较](03_conductance_structure.md)。最新[正导纳逆诊断](26_positive_conductance_inverse_diagnostic.md)发现一个确定高频目标在257²、$c_e\in[1,16]$ 下可由全边导纳近似重建到最大坐标误差约$1.09\times10^{-8}$，但需3,000次逆优化迭代、129秒且未达到求解器收敛标志；这不是快速 image-to-latent 层，也非一般可表示性定理。

## 6. 当前三路共同结论与未达项

同一物理 GPU2、同一8例合成保留图、257²控制网格、512²图像的冻结热启动完整层比较见[表25](25_same_gpu_257_crossroute.md)：

| 257²完整冻结层，batch1 | 输出表示 | image MSE | map RMSE | 面或采样 $\mu$ RMSE | forward / VJP | peak allocated |
|---|---|---:|---:|---:|---:|---:|
| A8 | 固定原网格 P1 | $1.84785\times10^{-5}$ | 0.00040936 | 0.08700 | 29.91 / 80.93 ms | 451 MB |
| B 双细因子 | 精确 PL 组合 | 0.00050483 | 0.0019299 | 0.14998（源重心） | 20.58 / 33.00 ms | 298 MB |
| C 18模态 | 固定原网格 P1 | 0.00010018 | 0.0008845 | 0.05771 | 30.68 / 31.52 ms | 156 MB |

A8 image/map最优、C面 $\mu$ 与内存最好、B完整 forward最快但 image-trained 精度明显不足。这个排序只对既定目标族和训练协议成立；三路参数量和常驻图像数不同，不能从小幅计时差推出一般复杂度优劣。A 与 C 已有1025²实际控制顶点和VJP，满足“至少两种机制”现实尺度要求；B 257²精确组合表示的输出虽有硬拓扑，却不是一张固定原网格P1。

**尚未达到完整愿景**：没有一个由任意给定 Beltrami 场出发、在任意高细节真实图像上快速准确地输出固定细网格 P1 同胚并同时保持小 $\mu$ 误差的通用层。A 的输入有效性/QC cap是条件性的，照片内容的 $\mu$ 拟合恶化；B 的紧凑组合不能无条件转成单张原网格P1，图像 encoder 对高频 latent 恢复差；C 的18模态有任务先验且照片域外图像误差大，128²光度估计是瓶颈之一。下一步路线不应只降线性残差或只展示另一张拓扑有效图，而应在同任务上提高图像条件 latent 推断与面导数控制，并严格保留 A/B/C 的输出契约区别。
