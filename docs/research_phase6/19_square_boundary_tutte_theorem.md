# 矩形共线边界上的正 conductance 拓扑保证：精确前提与数值版本

## 命题及为何需要核查

许多 Tutte 定理的简略陈述把外边界顶点放在**严格凸**多边形各拐角上，而本仓库 257² 规则网格的边界有 1024 个顶点，其中绝大多数共线地排列在单位正方形四条边上。若误把“严格凸多边形顶点”假设直接应用到这里，正边权层的核心拓扑结论缺少证明。原始 [Floater, *One-to-one piecewise linear mappings over triangulations*, Mathematics of Computation 72 (2003), Theorem 6.1](https://doi.org/10.1090/S0025-5718-02-01466-7) 给出了允许共线边界顶点的精确版本：凸组合 P1 映射将边界同胚地映到凸区域边界时，它一一对应当且仅当**没有内部 dividing edge** 被映到目标边界。这里 dividing edge 是两个端点都在源边界、但这条边本身在三角剖分内部的边。文献证明也指出，当这种边的两端映到同一条凸多边形直边时，会使被截出的子网格退化到该直线。这不是任意正权重都安全的无条件口号。

以下给出本仓库具体网格为何满足额外条件的自包含检查。设 $T_N$ 是 $[0,1]^2$ 的 conforming 直边 SW–NE 三角剖分，$N\ge3$；每条网格边是其两个源端点间的直线段，边界顶点按单位正方形顺序固定为自身。令所有无向边有对称权 $c_{ij}>0$；内部未知坐标 $Y_i\in\mathbb R^2$ 满足

\[
\sum_{j:(i,j)\in E}c_{ij}(Y_i-Y_j)=0,\qquad i\in I;
\quad Y_b=b,\ b\in B.
\]

对任意零边界标量向量 $u$，$u^\mathsf TA_{II}u=\sum_{\{i,j\}\in E}c_{ij}(u_i-u_j)^2>0$，除非 $u=0$：网格连通且每个内部顶点可经边到达边界。因此 Dirichlet 矩阵对称正定，$x,y$ 各有唯一平衡解。将式子除以 $\sum_jc_{ij}$，可见每个内部 $Y_i$ 是邻点的**严格正**凸组合。这是 Floater 定理的内部条件。

边界映射显然按顺序一一对应并绕单位正方形一周。对任何 dividing edge $[v,w]$，若 $v,w$ 在源正方形同一条边上，则直线段 $[v,w]$ 必沿正方形边界，不能同时作为 conforming 三角剖分的内部边；因此真正的 dividing edge 必连接不同边上的点，其直线段不是目标正方形边界的一部分。因为边界在本层固定为恒等映射，同一个结论对 $[Y_v,Y_w]$ 成立。于是在**精确实数求解**下，Floater Theorem 6.1 的“no dividing edge mapped into boundary”条件满足，原网格 P1 延拓是全局同胚。其逐面 Jacobian 非零且符号由正向边界确定为正，不只是“控制顶点没有交叉”。

为避免实际三角剖分与概念图不符，独立枚举 mesh.faces 的边重数；在 $N=3,5,17,257$ 这四种规模，唯一端点均在边界且边重数为2的内部边恰有两条，均连接不同的正方形侧边并切过角格子。tests/test_phase6_tutte_square_boundary.py 可重算此事实。枚举是代码路径检查，不是对 Floater 定理的替代。

## 精确拓扑与有限精度证书不能混淆

float64 PCG 返回的 $\widehat Y$ 只近似满足平衡方程；即便真实相对残差 $10^{-10}$，$\widehat Y_i$ 未必是严格的正凸组合，因而不能直接把 Floater 定理套给**未收敛的数值迭代**。若确切解 $Y^*$ 的每面最小有向双面积是 $m>0$，近似解每顶点欧氏误差最多 $\varepsilon$，每条精确映后边最长 $L$，则一个三角形的双面积扰动至多 $4L\varepsilon+4\varepsilon^2$：两条边的端点误差各至多 $2\varepsilon$，将 determinant 展开并逐项用三角不等式即可。只在已有可计算 $m,L$ 且该扰动界小于 $m$ 时，残差经 $\|A^{-1}\|$ 导出的坐标误差界才可证正面积。当前实现不依赖这样可能很松的后验界，而是每次求解后**直接检查所有原面有向面积严格正**，同时检查固定边界及真实系统残差。对于一个固定边界的连续 PL 正定向盘映射，全体面正向与边界同胚还给出有限精度输出自身的全局同胚；相关拓扑条件可参见 [Lipman, *Bijective Mappings of Meshes with Boundary and the Degree in Mesh Processing*](https://arxiv.org/abs/1310.0955)。这不需要把近似数值解假装成精确平衡解。

权重范围 $c_e\in[1,16]$ 在固定有限网格上与上述精确定理结合，因紧致性与坐标连续性理论上给出某个正的统一最小面积，但这个下界没有在本仓库定量求出，也可能随网格细化极快变小。不能据此省略逐面检查或声称“大 residual 也安全”。若日后学到可移动/非凸边界、改变三角剖分、允许零或负边权，本命题须重新核查；尤其不能把它推广到3D四面体网格。

这项澄清适用于本轮 Route C 的 CPU 对称直解、GPU 正弦-PCG、Woodbury/Schur 子族，只要它们确实实现上述**全部细网格正对称边权**与恒等边界。Route A/B 的拓扑构造不同，不能靠此定理为其背书。
