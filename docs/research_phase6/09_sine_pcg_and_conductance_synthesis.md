# Route C 新进展：非周期正弦预条件的全边正 conductance 层

## 1. 定义、表示对象与保证的层次

固定源域为单位正方形，控制顶点是 (x_{ij}=(jh,ih))、(0\le i,j<N)、(h=1/(N-1))。每个小正方形沿西南到东北的对角线剖分为两个三角形。整个图有三种无向边：水平 (e_h)、竖直 (e_v)、东北对角 (e_d)。外边界的目标位置固定为源边界；有 257²=66,049 个控制顶点、131,072 个原始三角形、196,094 条至少触及一个内点的有效边。代码为张量布局还保留 1,026 条两端都在边界的无效边 logit，总数 197,120；这些 logit 对内点系统及其梯度都没有影响。

对每条边给对称正 conductance (c_e\in(c_{\min},c_{\max}))。(B_I) 表示全图有向边-内点关联矩阵，则内点的两坐标平衡方程是

\[
A(c)Y_I=b(c,Y_\partial),\qquad A(c)=B_I^{\mathsf T}\operatorname{diag}(c_e)B_I.
\]

等价地，每个内点 (i) 满足 \(\sum_{j\sim i}c_{ij}(Y_i-Y_j)=0\)。正权重给出对称正定的 Dirichlet 矩阵。对本固定平面三角盘及适用的凸/弱凸边界组合条件，精确平衡映射属于 Tutte 型正定向嵌入；本实现还对**实际返回的浮点顶点**独立检查所有原始三角形的有向面积为正、边界不动。后一条件与简单边界共同给出所表示 P1 映射的全局 PL homeomorphism，而不仅是抽样 Jacobian 大于零。若求解未达到容差或有面不正定向，层抛错，不能把该样本计为成功。

与以前的全边 Schur/PARDISO 层不同，本层把权重限定在固定区间，例如 \(c_e=1+3\sigma(z_e)\in(1,4)\) 或 \(c_e=1+15\sigma(z_e)\in(1,16)\)。该限制换来分辨率无关的预条件数上界，可能缩小可表达的映射族；两种层不能仅根据求解时间称作完全同一优化问题。

## 2. 为什么正弦预条件有效

对零边界内点向量 (v)，设 (P) 是仅用水平与竖直单位权重边构成的五点 Dirichlet Laplacian。它的能量是 \(v^{\mathsf T}Pv=\sum_{e_h,e_v}(v_a-v_b)^2\)。实际三角图的能量还包含对角边。对任意对角线的端点 (a,b)，选该小方格的一条水平边及一条竖直边作两段路径；因为 \((s+t)^2\le2(s^2+t^2)\)，该对角边的单位权重能量至多是其两段路径能量的两倍。按固定方向选择路径时，任一水平/竖直边至多用于一次对角线的估计，因而

\[
c_{\min}v^{\mathsf T}Pv\le v^{\mathsf T}A(c)v
\le 3c_{\max}v^{\mathsf T}Pv.
\]

于是广义条件数 \(\kappa(P^{-1}A)\le3c_{\max}/c_{\min}\)，上界不依赖 (N)。([1,4]) 给上界 12，([1,16]) 给上界 48；实际迭代数可更少。这个不等式针对同一规则三角网格及有界正权重，**不**适用于任意 unstructured mesh 或无上界的 softplus 权重。它也不表示 PCG 有限步就是精确逆。

五点算子在 (1\le p,q\le N-2) 的零边界正弦基上对角化，特征值为

\[
\lambda_{pq}=4-2\cos\frac{\pi p}{N-1}-2\cos\frac{\pi q}{N-1}.
\]

每次预条件操作对内点做二维 DST-I，逐频率除以 \(\lambda_{pq}\)，再做逆 DST-I。实现用奇延拓加 FFT，不把原正方形的左右/上下边界粘成周期环面。这与用户之前担心的 Beurling 全平面卷积周期假设不是同一个算法。矩阵乘只读取三组边权并计算图 Laplacian，无稀疏矩阵组装或逆矩阵存储；前后向都要求计算**真实**相对残差达到声明阈值。

## 3. 神经层及反向传播

`SinePreconditionedTutteLayer` 输入水平、竖直、对角边的三个 batch logit 张量；输出原始 (N\times N) 顶点坐标及其固定三角剖分上的 P1 延拓。解码器内部用 float64，允许 CPU/CUDA；图像训练将坐标转为 float32 后在 512² 查询点采样一次移动图像。没有保存 PCG 轨迹。反向给定 \(G_I=\partial L/\partial Y_I\)，用同一权重系统再求 \(A(c)\lambda_I=G_I\)，设边界伴随为零，则

\[
\frac{\partial L}{\partial c_{ab}}=-(Y_a-Y_b)\cdot(\lambda_a-\lambda_b),\qquad
\frac{\partial L}{\partial z_e}=\frac{\partial L}{\partial c_e}(c_{\max}-c_{\min})\sigma(z_e)(1-\sigma(z_e)).
\]

这包含内点-边界边的右端项导数。返回的是严格残差控制下的**一阶隐式梯度数值近似**；有限步 PCG 与 float64 舍入不是精确实数求解。若研究二阶梯度，需要另一实现；当前自定义反向明确只支持一阶。

小网格独立稀疏组装与方向有限差分通过。257² 的独立检查：GPU PCG 与重新组装并用 SciPy 稀疏直接求解的最大坐标差 (2.55\times10^{-14})，直接解真实残差 (4.63\times10^{-15})，PCG 真实残差 (2.71\times10^{-12})；伴随真实残差 (2.82\times10^{-12})。方向 VJP 的解析值约 (-2.808116\times10^{-6})，中心差分约 (-2.808126\times10^{-6})，绝对差 (9.94\times10^{-12})；由于方向导数本身很小，相对差约 (3.54\times10^{-6})。该实例最小有向面积比 0.578，全部 131,072 个面经过检查。方向有限差分并非全参数空间的形式证明，但与独立直接解及恒等式一致。

## 5. 表达能力、训练信号与图像层现状

目标族 (F_\star=(x+a_x b+a_f c,\ y+a_y b+a_f c)) 的 (b,c) 与图像生成协议详见 [A6 自包含说明](08_sine_spectral_inference.md)。首先用**目标坐标 oracle**直接优化所有边 logits，考察权重家族本身；这不是合格的图像网络结果。固定 32 例训练集的第 29 例具有 (a_f=0.00245835)，目标采样 P1 最小面积比 0.461。

|---|---:|---|---:|
| 只用目标坐标 MSE | 0.001112 | 0.000226 / 0.000226 | 0.874 |
| 坐标 MSE + (0.001\) 倍目标网格导数 MSE | 0.000126 | 0.002286 / 0.002288 | 0.567 |
| 坐标 MSE + (0.01\) 倍目标网格导数 MSE | 0.0000494 | 0.002454 / 0.002455 | 0.474 |

所谓“导数 MSE”是对预测减目标坐标在每条水平/竖直细边上作差，乘 (N-1) 后取两坐标平方均值；它使用目标几何，仅用于容量/优化诊断。结果说明在至少这一难例上，([1,16]) 的对称正权重足以高精度逼近；初始训练失败不能被解释成显然的表示不可能。方向投影给的是振幅，不代表所有几何误差为零。另以局部平衡方程投影到 360 个方向得到的必要权重比最大值仅为第 0 例 1.256、第 29 例 2.219，均小于 16；该局部条件不能证明全局对称边权可行。

真正的图像到 latent 测试使用两尺度 CNN，在细边中点从图像特征取样，产出边 logits，解码一次并在 512² 查询点采样移动图像。以下是**固定训练集第 0 例的单样本训练**，目标振幅 (0.0007347)；训练损失只用图像，目标几何仅事后计算。它不能代表 32/8 保留集泛化。

|---|---:|---:|---:|---|---:|---:|
| 局部 CNN，像素 MSE，300 步 | 0.001722 | 0.004530 | 0.15197 | 0.000014 / 0.000019 | 65/69 ms | 38.4 s |

残差差分是 warped-minus-fixed 图像在相邻像素的差，乘 100 后与像素 MSE 相加；没有使用目标 Jacobian。上下文 CNN 改善低频映射，但高频振幅依然消失。相反，直接在**这同一对图像**上逐边优化 logits 500 步（图像像素+100×残差差分、无目标几何损失）达到图像 MSE (9.15\times10^{-8})、映射 RMSE 0.000238、面 Beltrami RMSE 0.0434，预测振幅 0.000568/0.000544，最小面积比 0.665；耗时 40.4 s。这是 per-instance latent optimization，**不是**一次快速 neural-layer 推理。其成功证实图像包含可利用的细节信号，且当前 amortized CNN/训练目标组合没有有效提取它。解码器加完整图像路径单例训练峰值分配约 67–87 MB，但这些 batch-1 数值不能代替 32/8 训练或更大 batch 的测量。

## 6. 位移到 conductance 的显式前向合成：有价值但未闭合

为了避免逐样本 500 步反推边权，另提出一个 (O(N^2)) 的显式初始化。给定固定边界的候选 (Y=X+u) 与均匀基权 (c_0=4)，计算其平衡残差 (r=L(c_0)Y)。只改变横、纵边权；在每个内点的行和列分别积分

\[
\delta c_h(i,j)-\delta c_h(i,j-1)=r_x(i,j)/h,\qquad
\delta c_v(i,j)-\delta c_v(i-1,j)=r_y(i,j)/h.
\]

于是对源坐标 (X)，有 (L(\delta c)X=-r) **恰好成立**，而新权重对目标 (Y) 的剩余残差是 (L(\delta c)u)，为一阶线性化之外的非线性项。每行/每列加常数不改变此恒等式；一种 gauge 把增量均值置零，另一种在不改变一阶恒等式的前提下优先让该行/列落入 ([1,16])。最后才把边权截入正区间、转为 sigmoid logits、用正弦-PCG 解平衡映射。所有这些张量操作与最终隐式层均可反向传播；9² 的解析抵消、二次剩余误差尺度和方向 VJP 已通过。重复残差修正仅是启发式，**没有收敛定理**。

257² 真目标位移 oracle（因直接读取 (F_\star)，不是图像层）的关键结果：

| 样本 / 行列常数 gauge / 修正次数 | 顶点 RMSE | 预测 (x/y) 32 周期振幅 | 被截断横/纵权重比例 | 最小面积比 |
|---|---:|---|---|---:|
| 第 0 例 / 均值居中 / 1 | 0.000252 | 0.000760 / 0.000757 | 0 / 1.3% | 0.800 |
| 第 0 例 / 区间优先 / 1 | 0.000273 | 0.000751 / 0.000754 | 0 / 0 | 0.802 |
| 第 29 例 / 均值居中 / 1 | 0.003140 | 0.001631 / 0.001633 | 28.5% / 29.1% | 0.634 |
| 第 29 例 / 区间优先 / 1 | 0.002056 | 0.001638 / 0.001641 | 2.2% / 1.6% | 0.660 |

第 29 例目标振幅 0.002458；区间 gauge 减少了截断并改善了坐标，但仍不够准确。继续到第二、第三次修正会使部分边权饱和、坐标误差上升，说明这个朴素固定点并不稳定。该显式构造最好被视为一种快速、有梯度且拓扑最终由正权重解码器保证的候选**初始化**，不能声称已经从任意位移快速准确地构造其对应 conductance。图像估计位移代替真目标之后的效果尚未测定。

## 7. 图像位移到边权的桥接负结果

还测试了一个无需真目标位移的混合层：固定已训练的 A6 图像编码器，以其 257² P1 预测作为 `synthesize_bounded_conductances` 的候选 (Y)，仅做一次区间优先 gauge 积分，再用正弦-PCG 输出真正的正权重 Tutte 映射。该链的图像损失可一路反传到 A6 编码器；保留 8 例、batch 2 的完整 forward/VJP 中位数约 63/77 ms，PyTorch 峰值分配约 257 MB，编码器梯度范数非零。然而在同一保留集，A6 图像 MSE 约 (7.26\times10^{-5})，桥接输出恶化到约 0.00462，查询映射 RMSE 约 0.00551。每个 batch 的未截断合成水平权重范围可能达到约 ([-97,114])，水平/竖直边截断比例最高超过 40%。因此“可反传”与“正权重拓扑保证”都没有弥补逆 conductance 初始化的准确性缺口。

频率筛选降低了边权饱和，却使最终 C 映射仍比候选差一个数量级以上。这里的 (K) 是在训练集作诊断扫描；没有把这些 K 的保留集结果重新用作独立调参成功证据。目标坐标 oracle 的顺利拟合以及该桥接的失败并不矛盾：前者直接优化全边权重，后者只使用受限的一维积分构造。下一步若继续 C 图像层，应改进从候选位移到可行的对称正边权的逆构造，或为边权网络设计能保持高频图像信号的监督/架构；重复增加朴素固定点次数没有当前证据支持。

## 8. 当前技术判断与复现入口

新 C 层解决了一个实际瓶颈：在规则矩形三角网格、**有界正权重**条件下，全边 conductance 可以用分辨率稳定的迭代数、低显存和正确隐式 VJP 在 257² 乃至 1025² 上运行；它比之前无限制全边 CPU 直接解更值得继续研究。它仍没有达到本轮理想成果：在高32合成图像上，快速的**amortized image-to-latent** 编码器明显落后于逐样本优化，且对任意实图像/任意目标 Beltrami 系数的泛化或精确求解毫无保证。有限残差和面证书是每次求解必须验证的数值事实，不应混同成对所有浮点输入的无条件精确算术定理。
