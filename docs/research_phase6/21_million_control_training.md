# Route C：1025² 控制顶点上的实际 300 步 image-to-latent 训练

## 要回答的问题

[20 节](20_photometric_control_scaling.md)只验证同一个 257² 已训练检查点能在 1025² 控制网格上完成一次 forward/VJP 及 8 例评价。本实验要补足**多步优化**证据：百万控制顶点的正 conductance P1 图是否能在图像损失下连续更新，并使梯度、面积、内存和残差持续有效？它不测试一般 Beltrami 系数反演，也没有给百万个独立 latent 自由度。

1025² 即 1,050,625 个控制顶点、2,097,152 个原三角形。输入与输出图像 query 均为 512²，图像到 18 维 latent 的光度拟合为 128²。层的唯一可训练参数为 18 个模式增益；图片每次重新估计 latent，边权由 latent 非线性给出，最终全控制网格用真实正 conductance 平衡解生成。固定边界、正权及所有原面数值面积检查见[17 节](17_photometric_conductance_layer.md)与[19 节](19_square_boundary_tutte_theorem.md)。

## 实验设置

GPU 为 ai 主机空闲物理 GPU 2；float32 图像/映射对外接口，float64 边权、矩阵自由 PCG 和隐式伴随。32 张训练图像来自 high32 seed55101，8 张保留图像来自 seed99317。目标形变参数在训练时不进入损失；只最小化单次 512² moving 图像经最终映射 warp 后与 fixed 图像的像素均方误差。warm start 为 257² 上经过 300 步训练的 18 个增益，其余1025²响应重新在本网格上算。batch 1，Adam 学习率0.01，另起空优化器状态，训练 300 步。先做相同初始化的 10 步 smoke，验证端到端循环后重新从 warm start 跑正式 300 步，不把 smoke 的 10 步叠加成 310 步。

每步前向包含图像光度估计、18维 latent、正边权构造、全原网格 PCG、512² query/warp、MSE；VJP 经图像损失、查询插值、无轨迹隐式 PCG 伴随，更新 18 增益。完整 32/8 例评价在训练前后分别进行，训练时间不含预计算和初末评价。所有300步检查原三角形有向面积和真实线性残差，梯度非有限立即报错。PyTorch CUDA allocated 的峰值包含驻留的32+8图像及层 buffer，但不是驱动总占用。

| 度量 | 初始 257² 权重迁移 | 1025² 继续训练 300 步 |
|---|---:|---:|
| 保留 image MSE | 0.000098950 | 0.000099564 |
| 保留 query-map RMSE | 0.000880146 | 0.000877197 |
| 保留所有原面 μ RMSE | 0.042789 | 0.039141 |
| 保留最大原面 $|\mu|$ | 0.327171 | 0.327608 |
| 保留最小原面 $\det J$ | 0.559063 | 0.557620 |
| 高频振幅率 | 0.80509 | 0.82871 |

预计算13.23秒、峰值已分配7.60 GB；训练本身111.52秒，中位完整 forward/VJP 166.17/195.07 ms，峰值已分配1.10 GB。300步训练中最小原面有向面积比0.5303、最大真实前向/伴随相对残差 $9.80\times10^{-11}$ / $9.90\times10^{-11}$；梯度全部有限。评价中的最小面积是8张保留图像；训练期间最小面积来自随机批次，两个集合不同。10步 smoke 的训练段3.76秒、峰值1.10 GB，结果与正式长跑的单位步时间一致。

上述是原始18响应全批量预计算版本。后续[22 节](22_streamed_response_precompute.md)把响应逐列流式求解，并**独立重跑同样300步**：预计算峰值降至1.045 GB、时间12.81秒；训练峰值1.100 GB、时间111.60秒，最终保留图像/map指标与旧版本在记录精度内一致，18个最终增益最大绝对差$2.34\times10^{-9}$。这才是目前默认的低冷启动显存配置。

精度结论必须克制：继续在百万点网格训练使 map 和 μ 指标有**很小**改善、图像 MSE 却轻微变差；这更像既有18维表示/图像估计误差的局部权衡，不是增加控制顶点自动提升配准精度。1025²的预计算仍是显存和冷启动瓶颈；它占用的7.60 GB不能以训练峰值1.10 GB掩盖。此次只有合成已知频率族，没有摄影内容继续训练、未知频率目标或实际配准任务，不能宣称广泛泛化。
