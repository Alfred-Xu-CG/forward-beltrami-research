# 三路线同GPU、同257²主要控制尺度的冻结层对照

## 要排除的混淆

早期Route B双细网格精确组合的image-trained forward/VJP记录在Element CPU，而Route A8、C主要记录在AI GPU；不能直接把这些毫秒排列为算法排名。因此将已冻结的三个图像训练检查点，在**同一个AI主机物理GPU2**、同一 high32 seed99317 的8张保留图、512²图像/query、batch1上重新加载。A8、B均从原训练保存的encoder权重出发，用学习率0的5个优化步骤测包含网络/解码/最终一次图像warp/loss的forward和对可训练参数的VJP，排除首步取中位，确认评价前后参数输出不变。C用可复用PhotometricSpectralTutteLayer装入原300步18增益，以5个重复测完整图像loss forward和对增益及两输入图像的VJP。三个VJP的**参数维数不同**；C还算了输入图像梯度，不能把表中数值归结为求解器核的纯性能。所有CUDA计时同步。峰值是PyTorch allocated，A8/B常驻32+8图，C常驻8图，故峰值并非完全相同内存口径。

*B的复合一般有超过原131072面的实际仿射分片，其$\mu$是在原源面重心应用两个因子Jacobian链式法则，来自既有同检查点独立评价；不是对完整叠加分片的精确面积积分。B原始GPU计时脚本重算了两个因子全部面的最小面积，并且保留image/map与Element CPU旧结果一致到显示精度。A8和C在各原面计算面常数$\mu$；C面积与$\mu$分别是全部8例的原面扫描。像素误差定义为512²逐像素平方残差均值，map RMSE是512²查询点两坐标误差平方均值开根。A8的0.8 QC cap在此8例初始map均满足，但这仍是条件性的；B全局拓扑由两因子各自正面积与边界及精确连续组合得到，不是该重心$\mu$扫描的结论；C全局拓扑由正边权精确平衡定理加浮点全面检查得到。

读法：在本8例上，B运行最快，却没有达到A8/C的图像或位置精度；不能只比较毫秒。A8图像/map最准，但VJP和显存较高。C的图像/map不及A8，却有更低面$\mu$误差、更大的面积余量和较低峰值内存。C还需一次约1秒的响应预计算，A/B的模型加载和静态query准备另计；此表均不包含这些冷启动成本。不能依据单一指标宣布通用赢家。B的高频真振幅仍未由image-trained encoder恢复，虽直接latent oracle说明其表示本身有能力；详见[02节](02_alternating_factorization.md)。
