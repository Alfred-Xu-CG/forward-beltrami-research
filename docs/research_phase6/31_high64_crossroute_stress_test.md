# 三路线在同一64周期细节目标上的冻结层压力测试

## 为什么另加这张表

主[257²同GPU表](25_same_gpu_257_crossroute.md)使用32周期形变，257²控制每周期已有8个节点；[29节](29_route_a_fine_space_audit.md)发现A的1025²细空间在这个目标上对图像收益贡献不大。[30节](30_route_a_high64_fine_control_decisive_test.md)把周期数加倍、位移幅值减半，控制一阶变形强度，同时使257²节点每周期只剩4个、1025²有16个。真映射连续正定向且边界恒等；在512²图像每周期8像素。本节把 **同一个** high64 测试数据和同一AI物理GPU2用于A/B/C冻结模型；这不是新的三路线重训比赛。

共享生成器 `make_dataset(..., target_family="high64")` 沿用high32纹理、随机低频系数和同一个细系数随机数，只令频率32→64、细幅值乘0.5。测试seed99317、8张；无一模型在high64上重新训练，权重分别来自各自的high32训练。A最初的high64数据在GPU上从high32图重采样，后改为共享生成器在CPU上生成再搬到GPU；同8例的A image MSE仅$8.982190\times10^{-6}\to8.982180\times10^{-6}$，map和$\mu$也只在输出末位浮动。表中A采用**共享生成器重测**，B/C本来也用该生成器。另有新seed1170031共128例的A共享重测见30节原始JSON，不能当作B/C也在128例上验证。

A与C的输出在固定网格每个面上仿射，所以表中的面$\mu$扫描是全原面；B的精确组合会将这些面进一步切开，表中计算的是**源网格每个面重心的精确链式Jacobian**，不是对全部叠加分片的解析面积积分。B的拓扑保证来自两个因子各自固定边界、全部正面及精确连续组合，不能从重心det本身推出。A模块对输入QC cap和输出所有面做fail-closed检查；这8例前提均成立。C真平衡解来自全边正导纳定理，实际float64 PCG仍独立扫全部面及真实残差（最大$2.26\times10^{-11}$）。三者共用512²图像但VJP输出范围不同：C包含对两个输入图像及18增益的梯度，A/B主要是图像编码器参数；A还计入完整细面证书。峰值allocated的常驻数据/预计算范围不同，不能用小的时间或显存差作普适复杂度排名。

C在257²和1025²同一high64测试上的image MSE分别0.0001063687、0.0001063639，map RMSE分别0.0009026998、0.0009027003；加密控制基本没有改善位置。其输出最大$|\mu|$仅约0.096，反映当前最高32周期的18模态及128²光度拟合几乎未恢复64周期导数；面$\mu$误差1025²仍0.13749。此结果不能推广为“全边正导纳不能表示64周期映射”；[26节](26_positive_conductance_inverse_diagnostic.md)已显示另一个高频目标下全边正权有强表示潜力。B有1,050,625个细因子顶点及便宜的链式VJP，却也未由当前high32训练的image encoder恢复high64；不能把训练失败当成组合表示的数学不可能。

在这张**特定、未见过频率的**冻结测试上，A同时取得最小image、map和$\mu$误差，B最省前向时间，C最有面积裕度且比A低显存。A细空间相对事后257²P1投影在8例图像/MAP/面$\mu$均逐例改善，但绝对误差距离真映射1025节点插值参考很远；增加模型的细节推断能力仍是主要开放问题。该结论不替代high32或照片内容结果，尤其A在照片96例的面$\mu$会恶化。
