# Route A：1025²细反馈到底使用了多少超出257² P1的细节？

## 一个必要的表示消融

单凭输出有1,050,625个控制顶点、且这些顶点有非零更新，不能说明新增细顶点是精度提升的主要来源。原 A8 两次细反馈只保留16个二维正弦提议模式，局部安全系数又由邻面几何决定；这种结构可能主要移动原257²网格顶点，细网格额外的形变部分很小。因此把最终细映射 $F$ 分解为：

1. 取 $F$ 在原257²节点的值，记 $R F$；
2. 在原257² SW–NE 网格上作P1延拓，再用严格嵌套的三角形重心插值把它表示在1025²顶点上，记 $P(RF)$；
3. 残差 $F-P(RF)$ 是最终映射**不能仅靠其257²节点值和粗P1插值恢复**的分量。

$P(RF)$ 仅为事后分析投影。其拓扑不能从 $F$ 是同胚自动推出；本节另外对投影后全部1025²原面算有向面积，并检查固定边界。不能把该消融偷换成 A 层的新结构性保证。真正的 $F$ 仍由细反馈的逐步安全构造和完整面检查保证。`base` 则是反馈前原257² A8图的**精确1025² P1细分**，作为相同连续映射的基线。

所有最终图像只在512²像素$query$采样一次。image MSE是平均像素平方残差；map RMSE是两个坐标的查询点均方根；顶点/查询“fine-only RMSE”是 $F-P(RF)$ 每坐标平方平均开根。高频合成保留8例使用原 A8 训练权重、两次fine pass、内部cap0.8。照片96例使用同权重、六张scikit-image公开灰度照片各16个已知合成high32变形；因30/96初始粗图不满足0.8 cap，照片分支同时对base/投影/fine采用同一个粗层identity-to-initial安全homotopy、内部cap0.795。设备AI物理GPU2、float32、实际1025²控制网格；本节不是额外训练。实验设置与最初A细层见[24节](24_exact_coarse_to_fine_neural_layer.md)。

| 目标集合与输出 | image MSE | map RMSE | 全细面最小面积比 |
|---|---:|---:|---:|
| 合成8例：base精确细分 | $1.84785\times10^{-5}$ | 0.00040936 | 已知粗图细分，详见24节 |
| 合成8例：最终F的257²限制再P1延拓 $P(RF)$ | $8.46250\times10^{-6}$ | **0.00026848** | 0.20434 |
| 合成8例：完整1025²细反馈F | **$8.29604\times10^{-6}$** | 0.00026864 | 0.15533 |
| 照片96例：base精确细分 | 0.00457513 | 0.00117254 | 已知粗图细分，详见24节 |
| 照片96例：$P(RF)$ | **0.00355460** | **0.00098863** | 0.06894 |
| 照片96例：完整F | 0.00362272 | 0.00101123 | 0.05577 |

合成8例从base到F的image MSE收益为 $10.18246\times10^{-6}$，其中 $P(RF)$已提供$10.01600\times10^{-6}$，约98.4%；真正只存在于细空间的最终增益约1.6%。map RMSE中投影略优于F，二者差很小。$F-P(RF)$在全部1025²顶点的每坐标RMSE为$3.16\times10^{-5}$，最大逐分量$7.63\times10^{-4}$，512²查询每坐标RMSE$2.75\times10^{-5}$，并非字面上零。

照片96例更严厉：$P(RF)$比完整F的总体image和map都好；逐例81/96的image、89/96的map由投影改善。其细空间残差顶点RMSE$8.20\times10^{-5}$、查询RMSE$7.08\times10^{-5}$，最大逐分量0.001232，因此“细部分不存在”也不对；更准确说是**存在但对这批图像任务大多无益甚至有害**。所有8+96投影实例的全原面最小面积均正、边界继承恒等，故这些具体投影也是同胚；没有证明任意有效F下都如此，也不能把投影当作无需检查的通用层。

## 对研究目标的影响

该消融修正了“1025²细控制顶点带来主要精度提升”的过强解释。当前A层确实输出1025²固定P1同胚、有1025²前后向与多步训练，但在本节已测high32/照片目标中它对保留精度的主要贡献是**从细尺度图像反馈中提取出对粗257²顶点也可见的改动**。这不满足“本节目标需要1025²独立细控制”的强证据。随后[30节](30_route_a_high64_fine_control_decisive_test.md)按事先提出的判别要求构造64周期目标，确实观察到细空间在8例和独立128例上有稳定的额外image/map收益；两节针对不同频率，并不矛盾，也不能把30节的结果外推为任意图像内容泛化。

诊断开关是 `tools/phase6_exact_coarse_fine_feedback.py --coarse-restriction-audit`。原始逐例 JSON 为 `raw_results/a8_exact_refine1025_coarse_restriction_heldout8_gpu2.json` 与相应 `photo6`、`photo96` 文件。脚本不改变原层或训练，仅在评价期计算 $P(RF)$ 与各项指标。
