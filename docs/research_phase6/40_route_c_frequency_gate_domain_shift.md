# Route C：中性频率响应能否充当细频带门控？

本节是针对 [37 节](37_route_c_photographic_domain_transfer.md) 发现的矛盾所作的**诊断**，不是一个已经训练、已经部署的频率门控神经层。问题是：64 周期导纳模态的训练增益有利于合成 high64 映射的面导数精度，却损害摄影内容上的 high32 面导数精度。能否仅凭输入的固定/移动图像判断应否激活 64 周期？本节测量目前 Route C 层在所有模态增益为 1 时的图像反演系数，但不进行随后的大网格正问题求解。因此这里的指标只描述**系数识别**，不宣称门控后的映射精度、拓扑或完整 layer 速度。

## 1. 可复算的诊断量

取单位方形、1025×1025 控制顶点网格，导纳基的频率集合为 $K=\{1,2,4,8,16,32,64\}$。每个频率有水平、竖直、对角三种边模态，共 21 个系数。它们的准确边位置三角函数见 [`PhotometricSpectralTutteLayer.prepare`](../../src/qcopt/neural_bijection/dense/photometric_conductance.py)；本节所有实验均为同一套基，且可学习增益 $g_j=\exp(3\tanh a_j)$ 的原始参数 $a_j=0$，所以 $g_j=1$，没有加载训练权重。

在空间边长为 $M$ 的光度拟合网格上，令 $I_f,I_m$ 为固定/移动图，$r=I_f-I_m$。预计算的第 $j$ 个一阶形变响应为 $R_j(q)\in\mathbb R^2$，来源是在中性导纳处对边权模态作一次隐式微分并解线性系统。设计矩阵列为 $D_j(q)=\nabla I_m(q)\cdot R_j(q)$。令 $Q=M^2$、$D\in\mathbb R^{Q\times21}$，计算

$$\widehat z=(D^\top D/Q+\lambda s I)^{-1}D^\top r/Q,\qquad s=\max\{21^{-1}\operatorname{tr}(D^\top D/Q),10^{-12}\},\quad\lambda=0.005,$$

然后逐系数作有界变换 $z_j=4\tanh(\widehat z_j/4)$。这里的 $I$ 是 21×21 单位阵；$s$ 是每个样本自己的平均设计列能量，用来使岭参数无量纲。图像梯度在 $M$ 网格上用相邻像素中心差分、端点复制求得。输出系数的顺序为三个方向各按 $K$ 排列。定义 64 频带能量及无量纲分数

$$E_{64}=\sqrt{z_{h,64}^2+z_{v,64}^2+z_{d,64}^2},\qquad S_{64}=E_{64}/\max(\lVert z\rVert_2,10^{-12}).$$

`S64` 只是候选统计量，不是目标映射的真实傅里叶能量，更不是正确增益的充分统计量。三组实验统一用 512×512 图像、CPU float32 图像与响应插值、float64 的 21×21 岭方程；响应预计算的大网格 PCG 使用 float64。控制网格 1025² 在这里用于预计算几何响应；逐例计分只调用 `_latent`，**没有**生成 1025² 输出图，也没有测 forward/VJP 时间。

## 2. 数据与成对条件

合成组为每族 128 例独立新 seed 1170031 的非自然纹理。high32 与 high64 都从相同随机图纹理和同一组低频系数生成，目标真映射为

$$F_*(x,y)=\big(x+a_x L(x,y)+a_f H_k(x,y),\ y+a_y L(x,y)+a_f H_k(x,y)\big),$$

其中 $L=\sin(2\pi x)\sin(2\pi y)$，$H_k=\sin(2\pi kx)\sin(2\pi ky)$。$a_x\sim U[0.005,0.015]$、$a_y\sim U[0.010,0.025]$、原始 $a_f\sim U[-0.002,0.0025]$；high32 取 $k=32$ 与原始 $a_f$，high64 取 $k=64$ 与 $a_f/2$，以保持细纹梯度量级可比。固定图由 `grid_sample` 在真映射上采样移动图得到。每一族的同编号例子使用同一随机种子与纹理，因此可作同编号的配对比较。

摄影组用四张先前未参与增益选择的 scikit-image 图像 `astronaut`、`coffee`、`chelsea`、`rocket`，RGB 先转亮度，再缩放到 512²、中心化并按标准差归一；每张有 8 组 seed 703231 的系数，总计每族 32 例。其目标映射用上述同一系数区间与 high32/high64 构式；同编号两族保留**相同照片、相同 $a_x,a_y$ 和未减半前的 $a_f$**，只替换细纹频率并把 high64 振幅减半。另有前期六张灰度照片的 96 个 high32 样本、seed 973031，作为不依赖这四张照片的内容对照。这里的“照片”只指源图像内容是真实摄影，形变仍是已知合成形变；不是现实配准的 ground truth。

## 3. 中性响应的分辨率实验

下表合成组 `AUC` 是从全部 $128^2$ 个 high64–high32 跨例配对计算的 $P(S_{64}^{64}>S_{64}^{32})$，平分并列；`配对`只比较同编号纹理/系数的 128 对。它们不等同于独立照片个数。`摄影32` 是四张新内容共 32 例的 $S_{64}$ 范围，尚未按图像内容做总体推断。

| 光度拟合网格 $M^2$ | 合成32 $S_{64}$ 中位/最大 | 合成64 $S_{64}$ 最小/中位 | 合成 AUC；同编号较大 | 摄影32 $S_{64}$ 最小/中位/最大 |
|---:|---:|---:|---:|---:|
| 128² | 0.001808 / 0.005035 | 0.000822 / 0.47824 | 0.99420；128/128 | 0.09984 / 0.21492 / 0.53191 |
| 256² | 0.000124 / 0.000350 | 0.000811 / 0.47962 | 1.00000；128/128 | 0.01613 / 0.12026 / 0.43090 |
| 512² | 0.000116 / 0.000350 | 0.000898 / 0.51781 | 1.00000；128/128 | 0.03797 / 0.16762 / 0.45222 |

在 256² 与 512² 拟合下，存在一个可完全分开**这 256 个合成样本**的阈值；然而这四张照片的所有 32 个 high32 样本，即使没有 64 周期目标形变，其分数也高于合成 high32 的最大分数。六张旧灰度照片另外 96 个 high32 样本在 256² 拟合下 $S_{64}$ 的最小/中位/最大为 0.05281/0.22942/0.60560，依然全部高于合成 high32 最大值。提高光度拟合分辨率不能消除这个**跨内容域的阈值错配**。该事实不能只归咎于岭回归或图像采样中的某一个环节；天然摄影的空间频谱、灰度归一、运动与图像梯度的交互都可能贡献。

## 4. 同一照片、同一形变系数的 high32/high64 比较

在 256² 拟合的四张新照片上，high64 的 $S_{64}$ 最小/中位/最大为 0.03105/0.51724/0.87313，high32 则为 0.01613/0.12026/0.43090。跨全部 $32^2$ 个 high64–high32 组合的描述性 AUC 为 0.87305；同照片同系数的 32 对中，28 对 high64 分数更大，中位配对差为 0.36273，但最差一对为 $-0.03663$。逐照片的配对胜出数为 `astronaut` 8/8、`coffee` 7/8、`chelsea` 5/8、`rocket` 8/8。两个族明显重叠，且 `chelsea` 的失序更多。因此，照片域中保留了一定的**频率相对排序信号**，但并非无错分类器；合成域直接迁移的绝对阈值已经被摄影 high32 全部击穿。四张照片且每张重复 8 次，跨例 AUC 不可当作 32 个独立内容上的置信证据。

六张旧灰度照片的 96 对同系数试验提供另一组内容复核。high32/high64 分数中位分别为 0.22942/0.43203，跨例 AUC 为 0.83963，配对高者有 79/96；中位配对差 0.11779，但最差一对为 $-0.15159$。逐照片配对胜出数为 `camera` 16/16、`coins` 10/16、`moon` 13/16、`page` 15/16、`grass` 9/16、`gravel` 16/16。它再次显示有明显但不完美的频率信号，且不同纹理内容有不同背景响应。其数据只用本节诊断，不用来调整已报告的 C 层训练增益。这里 `--count 1` 仅为让通用脚本产生一对不用于推断的合成占位样本；该文件的合成 AUC **不可解释**，只有摄影 96 对需要读取。

为了把“跨内容阈值不可直接迁移”与“任何摄影域阈值都无用”区分开，另仅用摄影样本训练**一个标量阈值**，按 $S_{64}>t$ 判 high64。候选阈值是训练分数的相邻唯一值中点和两端，选使训练 balanced accuracy（真 high32 判低与真 high64 判高的平均正确率）最大的点；在完全不参与选阈值的另一组照片上测试。六张旧灰度照片训练、四张新彩照测试时，$t=0.33340$，训练/测试 balanced accuracy 为 0.76563/0.79688；测试 high32 错报率 3/32，high64 召回率 22/32。反向以四张新照片训练、六张旧照片测试时，$t=0.20685$，训练/测试 balanced accuracy 为 0.84375/0.67708；旧照片测试 high32 错报率 55/96，high64 召回率 89/96。后一方向明显不稳定，且十张内容、两种灰度/彩色来源与这些已知形变，不足以确定部署阈值。这里仍未给正导纳求解器实际切换增益，因此 accuracy 不代表最终映射获益。

## 5. 已完成大网格输出上的事后分支选择

为了检查“频率判别”是否有实际误差意义，使用相同样本上**此前已经完整运行**的两种 C21 状态：旧18增益都采用训练值，只有64频带的三个增益或者回到中性1，或者采用 high64 训练值。逐例分数超过**另一摄影组**选出的阈值便选择训练64分支，否则选中性64分支；这是对两组现有完整1025²映射的**事后精确选择**，并非把两个映射作坐标插值，也没有重新计时或实现可导门控。两分支原始逐例文件中控制规模、拟合分辨率、真细振幅与样本顺序均经脚本核对；旧六照片评价文件的 `seed=99317` 是已在[37节](37_route_c_photographic_domain_transfer.md)说明的元数据笔误，实际生成种子为973031。

每个$\mu$ RMSE均先对所选择的逐例**全部1025²原三角形**$\mu$平方误差合并平均再开方，不是两组RMSE的线性加权。事后路由在high64合成族相对中性分支大幅改善，而在照片high32族相对全训练分支减轻面导数损害；但在这两个照片族上，**始终用中性64仍是面导数最佳**，在high64合成族上始终用训练64仍最佳。该简单门控尚未胜过按任务族挑分支的选择，也没有从单幅未知真实任务推得正确分支。路由后的最小原面面积比分别为0.65408、0.65538、0.47344（最后两行共用同一合成族最小值），均大于0；这是各已测分支在返回图上的事后证书，不是未来任意门控输出的无条件浮点保证。复算代码是 [`phase6_posthoc_frequency_gate_routing.py`](../../tools/phase6_posthoc_frequency_gate_routing.py)，汇总原始JSON为`raw_results/c21_posthoc_gate_routing_crossphoto.json`。

## 6. 解释边界和后续设计约束

1. 目前没有学出从输入图像到安全 64 增益的函数，也没有证明可从观测图像唯一识别高频位移。光度问题有孔径和纹理歧义；这里的系数只来自中性响应线性化。
2. 合成数据上 AUC 接近 1 不得推断到真实摄影内容；不同照片中的 8 个形变变体并非 8 张独立照片。任何阈值/归一化若用这些测试照片挑选，都必须另留未见照片再验证。
3. 即使能识别是否需要高频，仍须将条件增益送入正导纳层、在全部输出面检查正面积与 $\mu$，并测完整 forward、隐式 VJP 与显存。当前 `_latent` 诊断不提供这些证据；Route C 对**精确平衡解**的同胚定理来自正导纳和特定方形边界/三角结构（见[19节](19_square_boundary_tutte_theorem.md)），但有限容差、返回的 float32 顶点图还需独立的全原面正面积与边界证书。残差“足够小”若没有定量残差到面积余量的界，不能单独当作拓扑保证；`S64` 本身也不是保证。

一个尚未实现的**可导候选**是：先计算中性系数 $z^0$，再以 $S^\varepsilon_{64}=(\sqrt{\varepsilon^2+\sum_{r\in\{h,v,d\}}(z^0_{r,64})^2}-\varepsilon)/\sqrt{\varepsilon^2+\lVert z^0\rVert_2^2}$ 和 $\gamma=\operatorname{sigmoid}((S^\varepsilon_{64}-t)/\tau)$ 定义64频带系数 $z_{r,64}=z^0_{r,64}[1+\gamma(g^{\rm trained}_{r,64}-1)]$，旧频带沿用已训练增益。取$\tau>0,\varepsilon>0$使门控及其一阶链式梯度处处有定义，且全零系数时$S^\varepsilon_{64}=0$；随后仍以 $c_e=1+15\operatorname{sigmoid}(-0.8+\sum_jz_jB_j(e))$ 保持所有边导纳严格正，再解同一平衡系统并用隐式伴随回传。这里的结构论证只覆盖**精确解与符合边界假设时**的同胚，不是声称这个具体门控已有准确率、速度或浮点证书。下一实验应训练/验证$t,\tau$或图像条件门控，同时约束目标面导数误差并跨照片内容留出验证，不应拿本节四张/六张测试内容来反复调参。

可复算入口为 [`phase6_frequency_gate_diagnostic.py`](../../tools/phase6_frequency_gate_diagnostic.py)，摄影数据生成器为 [`phase6_eval_photographic_content.py`](../../tools/phase6_eval_photographic_content.py)，阈值迁移复算为 [`phase6_frequency_gate_threshold_transfer.py`](../../tools/phase6_frequency_gate_threshold_transfer.py)。原始逐例 `fraction64`、`energy64`、`energy32` 与设备、seed、响应残差均在 `raw_results/c21_neutral_latent_frequency_gate_*.json`；关键摄影成对文件为 `c21_neutral_latent_frequency_gate_photo_high64_pair_fit256_corrected_cpu.json` 与 `c21_neutral_latent_frequency_gate_oldphoto96_pair_fit256_cpu.json`。这里的统计量不代替原始文件。
