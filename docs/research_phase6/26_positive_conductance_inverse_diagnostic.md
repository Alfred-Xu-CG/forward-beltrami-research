# Route C：257² 正导纳的目标映射逆诊断（不是 neural layer）

## 问题与范围

固定一张单位方形的三角网格，以及已知的高频、边界恒等、正定向目标顶点映射 $Y^*$。能否找到每条活动无向边的正导纳 $c_e\in[1,16]$，使 $Y^*$ 接近该导纳对应的 Tutte 平衡映射？本节只回答**一张确定性 high32 合成目标图**的数值问题；没有从图像预测全部边导纳，也没有把这个逆优化称作快速、可微的 neural layer。

网格边集为 $E$，内部顶点集为 $I$，边 $e=\{i,j\}$ 的方向仅用于组装，结果不依赖所选方向。构造 $M(Y^*)\in\mathbb R^{2|I|\times |E|}$：对内部顶点 $i$ 的两个坐标，边 $\{i,j\}$ 在对应行填 $Y_i^*-Y_j^*$。于是平衡方程等价于 $M(Y^*)c=0$，即

$$\sum_{j:\{i,j\}\in E}c_{ij}(Y_i^*-Y_j^*)=0,\qquad i\in I.$$

为使不同分辨率的目标量级可比，优化器最小化 $\frac12\|h^{-2}M(Y^*)c\|_2^2$，其中 $h=1/(n-1)$，采用边界约束 L-BFGS-B 和解析梯度 $h^{-4}M^TMc$。这是一项**诊断性有界最小二乘**，不是可行性证书；终止在迭代上限时尤其不能声称找到了严格的 $Mc=0$。

随后完全绕开逆优化目标值，用所得到的导纳组装新的对称正定 Dirichlet 图 Laplacian $L_{II}(c)$，以原目标的边界值求解 $L_{II}(c)Y_I=-L_{I\partial I}(c)Y^*_{\partial I}$，报告该独立正问题所得 $Y(c)$ 相对 $Y^*$ 的最大坐标误差与 RMSE。另对 $Y(c)$ **所有原网格三角形**计算有向面积，除以单位原三角面积 $h^2/2$，报告最小面积比。这个检查只验证一张具体重建输出，绝非一般映射类的拓扑定理。

## 数值结果

在 AI 主机 CPU 上运行，`OMP_NUM_THREADS=4`、`OPENBLAS_NUM_THREADS=4`。目标取仓库 `phase6_fit_dense_map_oracle.py` 的 deterministic `high32` 场；边界保持恒等。边界下限1、上限16。两档都使用 double 精度。时间含组装、优化、稀疏直接重建，不含 Python 进程启动和 SSH。

| 原控制网格 | 顶点/三角形/活动边 | 迭代 / 状态 | 最大 $|Mc|$ | 正问题最大坐标误差 / RMSE | 重建最小面积比 | 总耗时 |
|---|---:|---|---:|---:|---:|---:|
| 97² | 9,409 / 18,432 / 27,454 | 1,299 / 收敛 | $2.82\times10^{-13}$ | $6.97\times10^{-12}$ / $2.73\times10^{-12}$ | 0.65231 | 7.58 s |
| 257² | 66,049 / 131,072 / 196,094 | 3,000 / 达迭代上限 | $3.78\times10^{-11}$ | $1.09\times10^{-8}$ / $3.70\times10^{-9}$ | 0.39058 | 129.08 s |

257²的导纳范围实际上为 $[1.000000006,10.53913]$，满足指定正区间，但优化器明确报告 `optimizer_success=false`，因而应称为高精度近似重现而不是严格可行性证明。完整优化历史均在原始 JSON 中。

较早的 257² 线性规划试验达到 300 秒时间限制，只能说明那个可行性求解配置未完成；与本次最小二乘近似结果并不矛盾。本次结果表明：该目标下 Route C 的全边正导纳表示能力并不是明显的瓶颈。真正的 neural-layer 难点转移到如何从图像或低维 latent **快速**得到合适导纳，以及如何低显存地做正问题与反向传播。196,094 个边自由度的逆优化 129 秒，不能拿来替代一次 layer forward。

## 复现与限制

脚本 `tools/phase6_conductance_bounded_least_squares.py`；原始记录 `raw_results/conductance_bounded_ls_97_high32.json` 与 `raw_results/conductance_bounded_ls_257_high32.json`。单目标、边界恒等、固定网格、固定导纳界；不证明一般高频映射可由正导纳表达，不证明低维网络能学会导纳，也不证明某种近似线性求解的拓扑安全。正导纳 Tutte 定理适用于**精确平衡解及其边界/网格假设**；残差小本身不构成无翻折保证。对所重建的具体浮点输出则做了全三角形的正面积扫描。
