# Route C：只提高控制网格分辨率不能修复照片内容域外误差

## 受控问题

已经在257²控制顶点上完成 image-to-latent 300步训练的18模态正导纳层，面对不同照片内容的已知合成 high32 形变时，图像/位置误差较大。若把**同一模型权重、同一128²光度拟合、同一512²图像及query、同一96例**仅迁移到1025²控制顶点，是否明显改善？这检验“细网格离散误差是主因”这一可证伪假说；不重新训练、不修改频率字典。

六张scikit-image灰度照片 camera、coins、moon、page、grass、gravel，每张16个已知合成目标，共96例；照片内容是真的公开照片，但目标变形是合成的，不是临床/自然图像真实对应关系。移动图为照片，固定图为按真映射采样后的照片。257²有66,049控制顶点、131,072原三角形；1025²有1,050,625顶点、2,097,152原面。512²最终图像有262,144个query；128²只用于估计18维图像条件latent。两档均以float32图像、float64正导纳平衡PCG、真实相对残差约$10^{-10}$运行，AI主机物理GPU2，batch1；前后向测热身后3次中位，计时包括光度推断、全网格平衡解、最终warp/loss及梯度到输入两图和增益。流式response预计算另计，峰值allocated包括常驻96例图像，不与之前只常驻8例的数值直接比较。

像素 MSE 是96例和每例512²像素的平方残差均值；map RMSE是512² query两坐标均方根。面Beltrami RMSE是各原面中心的复数$\mu$差的平方平均开根（目标解析Jacobian由已知合成系数计算）；面积比是所有原面仿射Jacobian行列式最小值。正导纳精确解的拓扑理论及有限精度的全原面检查见[19节](19_square_boundary_tutte_theorem.md)。

| 控制网格 | image MSE | map RMSE | 面$\mu$ RMSE | 最小面积比 / 最大$|\mu|$ | forward / VJP | 运行峰值 | 冷预计算时间 / 峰值 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 257² | 0.03254356 | 0.004913075 | 0.1119912 | 0.59545 / 0.26802 | 30.88 / 31.58 ms | 525 MB | 1.18 s / 471 MB |
| 1025² | 0.03254052 | 0.004912870 | 0.1119511 | 0.59661 / 0.27614 | 164.58 / 194.34 ms | 1,351 MB | 13.95 s / 1,279 MB |

总体 image MSE 仅减少$3.04\times10^{-6}$（约0.0093%），map RMSE减少$2.05\times10^{-7}$（约0.0042%），面$\mu$ RMSE减少约0.000040；在逐例层面，1025²优于257²的例数分别是image 59/96、map 43/96、面$\mu$ MSE 48/96，说明总体微小改进也不是一致改善。六张照片各一例的先导对照同样几乎不变。前向约5.3倍、VJP约6.2倍、流式预计算约11.8倍更慢，不能把加密网格当成本域泛化的解决方案。

这不是“1025²正导纳层无法表示细节”的证明：另一个已知目标的全边正导纳逆诊断在257²已做到高精度近似重建，见[26节](26_positive_conductance_inverse_diagnostic.md)。本实验只说明当前**18模态、固定训练权重与图像光度推断**在照片内容上的误差几乎不受控制网格离散化影响。因此下一步应优先改善内容鲁棒的latent估计或边权表达，同时继续保持全边正导纳和全网格同胚输出，而非仅把已有18模态线性系统解得更细。

复现：`tools/phase6_scale_photometric_layer.py --photo-variants 16 --side 257` 或 `--side 1025`，同一检查点 `checkpoints/c_photometric_calibration_mean0005_300.pt`；原始逐例 JSON 为 `raw_results/c_photometric_photo96_{257,1025}_gpu2.json`，先导6例为相应 `photo6` 文件。脚本原有 synthetic high32 模式保持默认不变；新参数只选择既有公开照片数据生成器。
