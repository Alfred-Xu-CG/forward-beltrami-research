# Route A8：逐面 QC 限制下的稠密 P1 谱反馈

## 1. 问题、定义与输出

A7 的强光度反馈能提高图像配准和细频振幅，但自由增加反馈强度会使某些三角形的准共形畸变趋近于退化。本节探索能否在**生成顶点坐标的前向计算中**限制该畸变，而不靠事后的 fold repair、全局方程求解或对粗网格结果反复插值。

源域为单位正方形，控制网格有 $N=257$ 个顶点/边，采用固定西南—东北对角线，每个小方格分成两个三角形，因此有 $N^2=66049$ 个控制顶点和 $2(N-1)^2=131072$ 个三角形。一个顶点映射 $F$ 在每个三角形上由 P1 仿射延拓；其固定的原网格面 Jacobian 记为 $J_t\in\mathbb R^{2\times2}$。输入是 $512^2$ 的固定、移动图像和由小型 CNN 预测的多尺度 latent。输出是 **原 257² 网格上的 P1 映射**，并只在最后将它查询到 512² 图像位置，采样移动图像一次。这里的 512² 是 query 数量，不是控制点数量。

把面 Jacobian 的共形和反共形复导数定义为

\[
\alpha_t=(J_{11}+J_{22}+\mathrm i(J_{21}-J_{12}))/2,\qquad
\beta_t=(J_{11}-J_{22}+\mathrm i(J_{21}+J_{12}))/2.
\]

当 $\alpha_t\ne0$，Beltrami 系数为 $\mu_t=\beta_t/\alpha_t$，有 $\det J_t=|\alpha_t|^2-|\beta_t|^2$。因此 $|\mu_t|<\kappa<1$ 蕴含 $\det J_t>0$。注意反向推理不能从所有控制点上局部采样的 $|\mu|<1$ 得到全局 homeomorphism；这里使用的是**全部原三角形**的分片 Jacobian 与固定一一对应的凸边界。

## 2. 解析局部步长与证明

A8 先由 A6 生成原网格 P1 映射 $F_0$。给定当前位置的固定/移动图像残差，使用局部二维法方程得到位移建议，然后通过零边界 DST-I 保留联合能量最大的 16 个二维模式；这一步的公式和边界意义见 [A7 说明](10_spectral_feedback.md)。A8 使用两个反馈 pass，每 pass 的建议 gain 为 1；它不是图像反复 warp。只改变原网格内部顶点，按行列奇偶把顶点分为四种颜色。同一颜色的顶点不共享三角形，可以并行更新。每个点的建议向量先被双曲正切限制为有限值 $d_v$。

对一个被更新的顶点 $v$，其任一 incident triangle 的另外两点在当前颜色更新时固定。令 $\phi_v$ 为源网格上的 P1 节点基函数，则沿步长 $s\in[0,1]$，

\[
J_t(s)=J_t(0)+s\,d_v\otimes\nabla\phi_v .
\]

由上式得到复线性的 $\alpha_t(s)=\alpha_{t,0}+s\alpha_{t,1}$、$\beta_t(s)=\beta_{t,0}+s\beta_{t,1}$。如果当前映射已满足统一阈值 $|\mu_t(0)|<\kappa<1$，定义正裕度

\[
m_t=\kappa|\alpha_{t,0}|-|\beta_{t,0}|>0,\qquad
h_t=\kappa|\alpha_{t,1}|+|\beta_{t,1}|\ge0.
\]

令安全比例 $0<\eta<1$。对 $h_t=0$ 的面不加约束；其余面限制

\[
s_v\le\min\left(1,\ \eta\min_{t\ni v}\frac{m_t}{h_t}\right).
\]

三角不等式给出

\[
\kappa|\alpha_t(s)|-|\beta_t(s)|
\ge m_t-s h_t \ge (1-\eta)m_t>0.
\]

所以每一步被更新面仍有 $|\mu_t(s)|<\kappa$ 且 $\det J_t(s)>0$；未触及的面不变。依次完成四个颜色和两个 pass 后，所有原面仍正向，边界顶点保持原位。对一个平面三角盘，固定一一对应的凸矩形边界，加上全部面的正向局部 P1 映射，可用覆盖度/平面度数论证得到整个域的 homeomorphism。由此 A8 的主要硬保证不是“有限个 query 未折叠”，而是原控制三角网格的 P1 homeomorphism。

但是，固定 $\kappa$ 的保持定理有**输入前提**：A6 初始映射必须已经满足每面的 $|\mu|<\kappa$。若有初始坏面，代码把负裕度截为零，含此面的顶点在相应步骤不动，因此不会神奇地把该面修复到阈值以下；仍须单独报告输出是否满足固定 QC cap。无论此固定 cap 前提是否成立，只要 A6 输入本身为正向 P1 homeomorphism，坏面被冻结、其余面按正裕度约束，输出仍保持正向。在浮点执行中，所有面仍须数值检查，严格不等式的数学证明不等于机器计算的绝对证书。

另设初始图的最小有向双面积为 $a_{\min,0}>0$，给两个 pass 共用的面面积 floor $a_*=\rho a_{\min,0}$，实验取 $\rho=0.8$。一个顶点移动造成的该面面积损失记为 $\Delta a_t(d_v)$，它对位移线性。若损失为正，再施加

\[
s_v\le\frac{\min(\eta a_t,\ a_t-a_*)}{\Delta a_t(d_v)}.
\]

它与 QC 步长取最小，因而每一步保持 $a_t'\ge a_*$。这不是在已生成的 map 上事后寻找步长修复：latent 与图像残差先产生受限建议，局部解析门控是 decoder 的组成部分。它也不需要全局 sparse solve。代码中对零分母采用有界写法；零建议处的复数模长使用具有有限零点次梯度的范数实现，早期直接平方和开根导致训练参数非有限，已被专门测试捕获并修复。

## 3. 实验协议与指标

路线 A8 使用 A6 QC-tail 检查点作共同初始编码器，训练 32 个 high32 合成图像对，固定随机种子 55101，batch 2、Adam 步长 0.001、1000 个更新，GPU 为 AI 主机空闲物理 GPU 2，float32。两个 pass/gain 1/阈值 $\kappa=0.8$ 基于**训练 32 例**的图像损失、QC 上限和最小面积约束选择。面积 floor 0.8 则是在检查了 712031 的 128 例诊断结果后定下，因此 712031 不应被称为完全独立的最终确认；827031 也在前期无面积 floor 的 A8 试验中已被看过。保留集 8 例随机种子 99317 已用于方法迭代。最终才首次评估的 939031 这组 128 例是本次更有力的新种子检查。所有这些评价均在相应检查点训练完成后、无参数更新下计算，但方法选择有适应性，不能把它们当作三次预注册独立验证。

图像 MSE 是最终 warped moving 与 fixed 图像每像素平方差平均。query-map RMSE 是预测和解析目标的二维坐标平方差平均再开方。面 Beltrami RMSE 是对所有原网格面及样本等权平均 $|\mu_t^{\rm pred}-\mu_t^\star|^2$ 后开方；它**不是**面积加权指标。最大 μ 模长是所有预测面中的最大 $|\mu|$。最小面积比是预测面有向双面积除以源面有向双面积的最小值。高频振幅恢复率在每个 fresh 集上定义为

\[
r_{\rm fine}=
\frac{\sum_{i=1}^{M}\sum_{c\in\{x,y\}}\hat a_{ic}a_i}
{\sum_{i=1}^{M}\sum_{c\in\{x,y\}}a_i^2},
\]

其中 $a_i$ 是目标 $\sin(64\pi x)\sin(64\pi y)$ 位移项的已知系数，$\hat a_{ic}$ 是预测控制顶点位移在同一函数上的正交投影。目标解析 map 只用于**评估**，image-only 训练损失没有目标 map 或目标 μ。

## 5. 三组 fresh 128：收益、代价与前提

以下 A7/A8 均为训练完成后固定参数评估；每一行有 128 个未参加参数拟合的合成图像对，每对输出 131072 个原网格面。712031 和 827031 是重复使用的诊断种子，939031 才是最后新的确认种子，故不能把三组当成统计上独立的盲测。每组 A8 的初始 map 逐样本都满足 $|\mu|<0.8$：128/128，因此固定 cap 保持定理在**这些数据**上有前提。三组 A8 最终没有 $|\mu|\ge0.8$ 的样本，也没有非正面积面。它不是对任意将来图像的固定 cap 保证。

| fresh 种子/模型 | image MSE | query-map RMSE | 面 μ RMSE | max μ 模长 | min 面积比 | 高频振幅率 |
|---|---:|---:|---:|---:|---:|---:|
| 712031 / A7 | 8.571e-5 | 8.140e-4 | 0.12766 | 0.786 | 0.119 | 0.511 |
| 712031 / A8 image-only | 4.129e-5 | 5.863e-4 | 0.13902 | 0.793 | 0.101 | 0.754 |
| 827031 / A7 | 8.199e-5 | 8.027e-4 | 0.12478 | 0.858 | 0.0917 | 0.511 |
| 827031 / A8 image-only | 3.893e-5 | 5.723e-4 | 0.13253 | 0.796 | 0.130 | 0.758 |
| 939031 / A7 | 8.613e-5 | 8.088e-4 | 0.12514 | 0.814 | 0.104 | 0.506 |
| 939031 / A8 image-only | 4.449e-5 | 5.954e-4 | 0.13962 | 0.793 | 0.106 | 0.743 |

三组平均图像 MSE 约从 A7 的 8.46e-5 降到 A8 的 4.16e-5，平均 query-map RMSE 从 8.09e-4 降到 5.85e-4；高频振幅率从约一半升至约四分之三。与此同时，A8 的面 μ RMSE 在每组都**高于** A7：改善 image alignment 与 fine amplitude 不等于重现目标 Beltrami 几何。这是当前主要剩余差距。最差面积比并非总随 image loss 单调变化，应继续逐面监测。A8 硬 cap 0.8 只是对满足前提的初始 P1 map 逐面保持自身畸变上界；目标真实 μ 的逐面逼近仍是另一个任务。

一个必要的失败样本来自**未重训**的 A6 编码器：fresh seed 827031 的初始最大 μ 为 0.8274，已越过 0.8；冻结 A8 的最终最大值仍是 0.8274。故早期只报告“有 QC cap 更新”而未检查输入前提会构成错误结论。image-only 重训恰使这组三个 fresh 集的初始最大 μ 均低于 0.8，但这只是经验观察，绝非全输入定理。直接面积安全仍使初始正向的输出保持 homeomorphism。

## 6. 实现、可微性和未闭合问题

### 更大控制网格与反向重算

另用**未训练、零输出 head 的编码器**只测系统扩展性；这不是 513²/1025² 的精度验证。固定图像为 512²，包含 CNN、两次 QC-safe 反馈、最终 512² query 与 image warp 的完整 forward/VJP，前后都做 GPU 同步，先热身，再取 257² 的 15 次或 1025² 的 8 次中位数。checkpoint 版本在反向时重算每个完整局部 refiner pass 的中间量；9² 测试比较同输入的输出逐元素相等、一阶 VJP 在容差内相等。它保留数学输出，但加大计算量。

| 控制侧、batch | 普通 forward/VJP | 普通 peak allocated | 重算 forward/VJP | 重算 peak allocated |
|---|---:|---:|---:|---:|
| 257²、2 | 28.5 / 76.8 ms | 481 MB | 36.2 / 100.1 ms | 339 MB |
| 513²、1（仅 3 次） | 31.6 / 60.0 ms | 904 MB | 33.1 / 78.1 ms | 663 MB |
| 1025²、1 | 65.9 / 155.8 ms | 3359 MB | 74.2 / 195.3 ms | 2455 MB |

这些数字是一个空闲 A6000 上的 PyTorch allocated，不包括驱动上下文和未被 PyTorch 管理的进程内存；1025² 是 1,050,625 个**控制顶点**，不是 query。重算约节省 27–30% 的峰值分配，却使 VJP 增加约 25–30%；因此不是无代价的“加速”。大网格的所有原面在本次未训练样本上也经数值检查为正，但没有训练后精度数字。若批量训练或临床图像需要更大显存，应继续试分颜色重算、自定义局部 VJP 或分块图像查询，并在相同精度下比较总训练时间。

实现是 src/qcopt/neural_bijection/dense/qc_radial_relaxation.py、spectral_feedback.py；训练和评估入口是 tools/phase6_train_a7_feedback.py、phase6_test_a6_feedback.py。小网格测试 tests/test_phase6_qc_radial_relaxation.py 比较 $\alpha,\beta$ 与直接 $\mu$，检查全部原面、面积 floor、边界、随机方向的中心差分 VJP、零位移有限 VJP，并保留输入超 cap 时不会误报“已修复”的反例。257² 全训练真正将图像损失回传到 CNN，未保存线性求解轨迹，因为这里没有全局线性求解。top-k 模式选择和局部最小步长只在分支/频率排序不切换处有普通导数；在切换处 PyTorch 选取分段导数，因此不能声称处处光滑或高阶导数可靠。

原始逐样本数组、所有参数与时间在 docs/research_phase6/raw_results/a8_*.json；两个重训编码器在 docs/research_phase6/checkpoints/a8_*.pt。仍未完成的关键证据是：真实临床/自然图像分布上的泛化，面 Beltrami 误差与采样目标 P1 离散化 floor 的差距，更大 batch/513²+ 训练的实际显存，以及 image-to-latent CNN 对任意输入保持固定 $\kappa=0.8$ 前提的构造。它是一个在目标 257² 控制规模上**确实训练过**的原网格 P1 homeomorphism layer，但不是通用 forward Beltrami 方程的精确快速求解器。
