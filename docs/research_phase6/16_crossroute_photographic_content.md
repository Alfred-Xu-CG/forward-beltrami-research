# 三路线冻结层在摄影内容上的共同检验

## 协议

沿用 [A8 摄影内容实验](14_photographic_content_and_initial_qc.md) 的完全相同96例：六张 scikit-image 摄影/扫描灰度例图，每图16个由新种子973031生成的 high32 解析形变，移动图像为例图，固定图像由真坐标采样得到。所有检查点只经过此前32例合成纹理 image-only 训练，现不微调。控制侧257²顶点，每个因子131072原三角形；512²图像与262144查询点，batch2，AI主机空闲GPU2。

Route B 采用两个**各自257²**的凸单元 PL homeomorphism 因子，在连续坐标上精确顺序组合并只在最终采样一次图像；这不是17²稀疏控制层，也不是对组合后的512²输出再次做无保证的 P1 重插值。其查询位置是 $F_2(F_1(x))$，源三角形重心处链式 Jacobian 是 $DF_2(F_1(x))DF_1(x)$。复合在原网格面内也可能改变仿射分区，因此重心处 μ 误差只是采样误差指标；全局 homeomorphism 由两个因子分别全部原面正定向加固定边界证明，不能凭重心检查代替因子证书。

Route C 两种是同一个全细网格对称正 conductance / float64 正弦-PCG 解算器，差别只在图像边权编码器：普通逐边 CNN 与显式包含32周期方向的六频字典。其输出是原网格 P1 map，所有面 Jacobian 常值。每 batch 求解用真实相对残差检查，最终记录全部原面最小面积。Route A8 的数值直接取完全同源的摄影试验，不重新挑样本。

Image MSE 是最终 warped 与 fixed 图像逐像素平方差的96例均值；query-map RMSE 是96例所有512²查询的二维坐标差平方平均开根；Beltrami RMSE 是96例、每例131072源面重心的复数 μ 差模平方平均开根，B 用上述链式导数，A/C 用各自原网格 P1 导数。最小面积比是所有样本全部因子/原面中有向双面积相对于源面的最小值；B 两列分别对应第一个、第二个因子。

| 冻结 layer | image MSE | query-map RMSE | 重心面 μ RMSE | 最大采样 $|\mu|$ | 全面最小面积比 | 表示 |
|---|---:|---:|---:|---:|---:|---|
| A8 两次反馈 | **0.004166** | **0.001072** | **0.11592** | 0.9873 | 0.00869 | 原网格 P1；条件 QC cap，非无条件 |
| A8 + 初始 QC 同伦 | 0.004537 | 0.001165 | 0.11816 | 0.7995 | 0.06973 | 原网格 P1；无条件 cap0.8 |
| B 双细因子精确组合 | 0.021048 | 0.002852 | 0.16343 | 0.9519 | 0.01833 / 0.69477 | 精确 PL 组合 |
| C 普通 edge CNN | 0.043522 | 0.007697 | 0.16262 | 0.5983 | 0.20933 | 原网格 P1，正 conductance |
| C 六频边字典 | 0.015181 | 0.002116 | 0.12806 | 0.0967 | **0.86116** | 原网格 P1，正 conductance |

Route C 的两项最大真实相对前向残差分别为 $8.72\times10^{-11}$ 与 $1.17\times10^{-12}$，与要求的 $10^{-10}$ 一致；没有用“少量 CG 迭代自然安全”代替几何检查。B 两个因子的全体原面最小面积均正，但第一因子0.0183靠近退化，链式源重心最小 determinant0.0192；这比 image MSE 更应引起注意。A8 原样 OOD 部分初始未满足0.8条件，虽全部面正向，故表中的0.9873不能被涂成硬 QC cap 的成功。

按图像类型，三种 B/C 模型在草地与碎石等高频纹理上的 image MSE 都显著较高：B 为约0.0505/0.0477，C 普通为0.0937/0.0911，C 六频为0.0391/0.0291；A8 在同两类为0.0140/0.00704。简单的合成纹理训练无法外推到任意照片内容，尤其单通道图像配准有纹理/形变歧义。六幅例图不是独立临床病例，本实验只证明域外表现差异并暴露当前限制，不能证明真实应用鲁棒性。

复现脚本 tools/phase6_eval_crossroute_photographic.py；逐例和按照片结果在 raw_results/crossroute_B_C_photographic_content_high32_96_gpu2.json 与 raw_results/a6_a7_a8_photographic_content_high32_96_gpu2.json。B 的拓扑证书针对**因子**，A/C 针对**最终原网格 P1**；两者不能混写成“512²采样图都无折叠”。
