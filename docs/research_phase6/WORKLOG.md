## Route A — fixed-grid monotone construction

Question: Can a dense rectangular P1 map be generated from latent logits with no global linear solve, while guaranteeing a homeomorphism on the supplied fine triangulation?

Exact claim: On the standard lower-left to upper-right diagonal triangulation, define vertex images \(F(i,j)=(X_i,V_{ij})\), where \(X_0=0<X_1<\cdots<X_{N-1}=1\) and, for every column \(i\), \(V_{i0}=0<V_{i1}<\cdots<V_{i,N-1}=1\). The P1 extension maps the unit square homeomorphically onto itself. A row-wise analogue follows by swapping coordinates.

Assumptions: Complete rectangular triangulation, consistent face orientation, strictly realized coordinate inequalities, finite coordinates, shared boundary values on adjacent faces. The implementation uses normalized positive increments with a uniform floor and checks inequalities in the represented dtype.

Proof sketch: Within either triangle of a cell, the first output coordinate is affine in source \(x\) alone with positive derivative. The second output coordinate has positive source-\(y\) derivative: in the lower triangle it is the positive increment in the right column, and in the upper triangle the positive increment in the left column. Thus every affine face has positive determinant. More directly, \(X(x)\) increases from 0 to 1; for each fixed \(x\), \(y\mapsto F_2(x,y)\) is continuous, piecewise affine, strictly increasing from 0 to 1. Therefore every target \((u,v)\) has one preimage, found first from \(X(x)=u\), then from \(F_2(x,y)=v\). Compact-to-Hausdorff continuous bijectivity gives a homeomorphism.

What falsifies it: A face with zero/negative represented determinant, noninjective vertical fiber, failed boundary coverage, or a finite-precision collapse at intended resolutions.

Smallest decisive test: Random and extreme float32 logits on 17² and 257² grids; independent signed face-area check; first-order directional finite difference for VJP; then time a 257² forward and backward.

Prior work: Phase V's fixed-grid positive Tutte decoder and exact composition implementation provide comparators. This explicit triangular family is deliberately more restricted than unrestricted Tutte weights; expression on cross-coupled targets must be measured, not assumed.

## Route B — local patch maps and exact composition

Question: Can many independent small homeomorphisms supply dense-grid details while avoiding a global matrix solve and preserving a certified PL composition?

Exact claim: Partition selected nonoverlapping square patches of the fixed grid. In each patch, fix its boundary pointwise and map each interior vertical column by strictly increasing y values with x unchanged, or each interior horizontal row by strictly increasing x values with y unchanged. Outside the patches use identity. The P1 map of each layer is a homeomorphism of the full square. Compose vertical and horizontal layers on shifted patch partitions; the exact continuous composition remains a PL homeomorphism, generally on a refinement rather than the original triangulation.

Assumptions: Patch side divides the full-grid cell count at offset zero; other offsets select only complete nonoverlapping patches and leave uncovered strips unchanged. Interior updates use normalized positive increments with a represented-dtype floor, patch boundaries remain exactly equal to identity, and all layers share the same oriented source triangulation. The source for a later map is still the unit square; query points are dynamically located in that map's triangles.

Proof sketch: A vertical patch map holds x fixed and gives each vertical fiber a strictly increasing continuous P1 y map with endpoints fixed. It is therefore a homeomorphism of its patch, equal to identity on its boundary. Horizontal patches are the coordinate-swapped case. Disjoint patch maps glue to an identity map outside patches, yielding a global homeomorphism. Composition preserves homeomorphism; finitely many PL maps have a finite common-refinement partition on which the composition is affine.

What falsifies it: A collapsed represented increment, mismatch along patch boundary, negative face determinant in an output layer, incorrect dynamic point location, or an unbounded practical cost when queries pass through many layers. Sampling the composition at original vertices and reinterpolating is not covered by this claim.

Smallest decisive test: Two shifted 17² patch layers on a 33² mesh, one vertical and one horizontal, with random and extreme logits; direct face-area and boundary checks; finite-difference VJP; compare exact coordinate composition with direct per-layer evaluation. Then 257² control/512² query forward and backward, and image registration on the same target as Route A.

Prior work: Reuse Phase V's `StructuredDenseQueryTable.interpolate_points` and `compose_control_maps` for exact dynamic query evaluation. This route's latent-to-map construction is local and solve-free; batched local positive-Tutte solves remain a separate variant to test if the explicit patches lack expressive power.

Implementation state: `LocalPatchMonotoneLayer` uses per-patch positive increments in only interior rows/columns and leaves each patch boundary pointwise fixed. Offset-zero and half-patch-offset layers can be composed with `LocalPatchComposition`, which uses the existing dynamic query locator. Three focused tests pass, including random 33² patch layers, two-layer VJP through exact composition, and extreme finite float32 logits on a 257² grid with 16-cell patches. A 17² control / 32² query / two-layer CPU smoke ran successfully.

Main-scale Route B measurements on AI RTX A6000 GPU 3 (freshly 11 MiB used, zero utilization before the jobs), float32, 257² control / 512² queries: two layers, batch 1, 115,440 latent scalars per sample gave median forward 2.70 ms and VJP 2.34 ms, peak CUDA allocated 85.8 MB. Four layers, batch 2, 230,880 latent scalars per sample gave median forward 6.93 ms and VJP 5.87 ms, peak 238.0 MB. These include patch decoding, dynamic point location and a coordinate map loss, not image encoder/warp. Minimum signed-area ratios per layer exceeded 0.23; no original-grid P1 certificate is implied for the composition. Raw repeat arrays are in `raw_results/routeB_patch257_512_ai_gpu3_*.json`.

Image-only training on the same synthetic pair and analytic target as Route A used a small convolutional encoder, 257² patch layers, 512² images, batch 2, Adam 0.003. Two layers over 300 steps improved image MSE 0.0294455→0.0128848, final query-map RMSE 0.0201273, peak CUDA allocation 177.1 MB. Four layers over 500 steps improved image MSE 0.0294226→0.00911557, map RMSE 0.0194510, peak 258.0 MB. Every individual layer had a positive observed minimum face-area ratio; the exact composition theorem supplies continuous topology conditional on represented layer validity. The four-layer image objective is near Route A's result, but its map RMSE is substantially worse: registration texture ambiguity and patch-fixed lines matter. Raw step records are in `raw_results/routeB_patch_train257_512_ai_gpu3_*.json`. This is one synthetic pair family, not a general accuracy ranking.

## Route C — fine-grid positive-conductance structure

Question: Can a shared fine-grid positive-conductance baseline be updated from hierarchical latent variables and solved with exact algebraic structure fast enough for forward/VJP, without storing the dense inverse or turning a coarse interpolation into a topology claim?

Exact claim for the first implementation: Let the full fine-grid Dirichlet conductance matrix be (A_0\succ0), let (f_0) be its exact solution at a fixed ordered square boundary, and select (k) full-mesh edges. The (r)-th selected edge has an interior incidence column (u_r\in\mathbb R^{n_I}), full-edge baseline difference (d_r=f_0(p_r)-f_0(q_r)\in\mathbb R^2), and positive increment (\delta_r>0). Put (U=[u_1,\ldots,u_k]), (D=\operatorname{diag}(\delta)), (W=A_0^{-1}U), (G=U^\mathsf{T}W). Then the exact updated interior map is

\[
f_I=f_{0,I}-W(D^{-1}+G)^{-1}d,
\]

where the rows of (d) are the full-edge differences (d_r). This includes boundary-adjacent selected edges because the full-edge differences account for the changed Dirichlet right-hand side. It is algebraically equivalent to solving ((A_0+UDU^\mathsf{T})f_I=b_0+\Delta b); every updated edge remains positive. The same (W,G) are reused for all latent batches. No full (A_0^{-1}) is stored, only (n_I k) columns and a (k\times k) Gram matrix. Autograd through the small SPD solve and matrix product supplies a first-order VJP; compare it against an independent full sparse solve and finite differences.

Assumptions: (A_0) is the Dirichlet graph Laplacian on the **same** complete 257² triangular mesh; all baseline active conductances are positive; the square boundary stays fixed and satisfies the existing Tutte geometric hypotheses; selected edge incidences and signs use the same indexing as the assembled matrix; the positive increment and baseline solution are represented accurately enough to preserve the observed face-area margin. The exact-arithmetic Tutte conclusion is not automatically a floating-point certificate.

What falsifies it: A sign/right-hand-side error on an interior-boundary edge, disagreement with a freshly assembled sparse solve, VJP mismatch, dense W storage or k³ small solve overwhelming the baseline, or a negative represented face on the returned fine-grid P1 map. Large smooth conductance changes will generally update many edges, raising rank; this must be measured instead of hidden.

Smallest decisive test: On a 9² grid, include both interior-interior and interior-boundary selected edges, compare to independent SciPy sparse solve with residual and map error, finite-difference the latent gradient, and check every face. Then measure k=16/64/256 on 129² and 257², including shared precomputation and reuse, forward/VJP and memory. Separately test a coarse latent affecting a block of fine edges and report its actual algebraic rank. If low-rank is inadequate, implement and compare an exact block/Schur option rather than stopping at a rank objection.

Prior work: Phase V's `MatrixFreeSymmetricTutteLayer` provides the full positive-conductance CG comparator and implicit VJP. Its old `woodbury_row_update` applies to directed row changes and is not this symmetric edge-increment construction. The matrix identity is classical Sherman–Morrison–Woodbury; the research question here is whether a reusable fine-grid baseline and physically useful update family give an actual neural-layer advantage at required resolution.
