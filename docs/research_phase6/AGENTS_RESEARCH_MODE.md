# Phase VI 执行规范：Dense Homeomorphism Research Mode

## 核心约束

1. 以稠密矩形三角网格上的快速、可微、低显存 PL homeomorphism layer 为目标。每条理论调查、测试或优化都须说明它如何推动此目标。
2. 控制网格分辨率与图像/query 分辨率分别写明。257² 指 **66,049 个控制顶点**，不得用 257² 个采样点代替。
3. Route A 显式细网格构造、Route B 精确多层组合、Route C 层级正 conductance 是实现候选。至少两种机制须推进到 257² forward/VJP；不得将全部时间耗在 Woodbury 的低秩障碍或反例上。
4. 数学命题先列假设及结论，再写代码。关键证明、隐式 VJP 和性能排名接受独立复核；普通代码变更采用常规测试，不为每次实验创建额外审计层。
5. 输出固定网格 P1 与精确 PL 组合分开报告。组合后顶点重采样不能继承组合的 homeomorphism 保证。
6. 正 conductance、SPD、残差、三角形正面积、全局单射以及有限精度安全性是不同性质。禁止把其中一个当成另一个的证明。
7. 不把 AMG 近似解当作本轮 multilevel 表示路线。若使用迭代法，需给出解误差与几何有效性的具体判据；允许将其作为公平基线。
