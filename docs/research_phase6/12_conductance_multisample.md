# Route C：正 conductance 的多样本图像层验证

## 目的与构造

[Route C 的求解器和隐式 VJP](09_sine_pcg_and_conductance_synthesis.md) 已在 257² 控制网格完成独立数值验证，也能对单幅图像逐样本优化边权。但单样本结果不回答“一个 CNN 能否从新图像预测不同的细边权”。本节用与 Route A8 相同的 high32 合成图像协议、32 个训练/8 个保留样本，检验真正的 image-to-conductance 泛化。

控制网格有 $257^2=66049$ 个顶点、131072 个三角形，边集合含 197120 条水平、竖直和东北对角边。3090 参数的三尺度上下文 CNN 在每个细边中点抽取粗、细两组图像特征，产生标量 logit $z_e$。边权被严格约束为 $c_e=1+15\sigma(z_e)\in(1,16)$。固定单位正方形凸边界，内部顶点坐标满足正权重平衡方程

\[
\sum_{j:(i,j)\in E}c_{ij}(Y_i-Y_j)=0\quad(i\ {\rm 为内部顶点}).
\]

正 conductance 和固定凸边界给精确实数平衡解的 Tutte 型原网格 P1 homeomorphism。实现用 float64 正弦预条件 CG 达到真实相对残差不超过 $10^{-10}$，再将坐标转 float32，查询到 $512^2$ 图像点并只采样一次移动图像。有限精度输出另外逐面检查有向面积；不能只凭权重正就把任意未收敛迭代叫作 homeomorphism。反向传播通过隐式伴随线性解，不存前向 Krylov 轨迹。

## 数据、损失与指标

训练数据是随机种子 55101 生成的 32 个 high32 图像对；保留集 8 例种子 99317，batch 2、Adam 学习率 0.003、1000 次更新。解析目标坐标和 Beltrami 系数只用于事后评估，不进入训练。第一组目标是最终图像每像素 MSE。第二组加 $100E_\nabla$，其中

\[
R=I_m(F(x))-I_f(x),\qquad
E_\nabla=\tfrac12\operatorname{mean}(\Delta_xR)^2+
          \tfrac12\operatorname{mean}(\Delta_yR)^2.
\]

$\Delta_x,\Delta_y$ 是相邻图像像素的残差差分，不是目标 map 导数监督。query-map RMSE 是预测与解析目标的二维位置平方差平均再开方；面 μ RMSE 是预测和**解析目标**复 Beltrami 系数在原网格全部面上等权的平方差平均再开方；最小面积比和最大 μ 模长从全部预测面取极值。高频振幅率是预测位移在已知 $\sin(64\pi x)\sin(64\pi y)$ 基上的最小二乘投影斜率，公式见 [A8 说明](11_qc_capped_spectral_feedback.md)。它不是训练监督。

## 新样本与结论边界

另在训练完成后才首次用于 C 路线评价的种子 939031 上测 128 例。像素组的 image MSE 为 0.0008688、query-map RMSE 0.002673、面 μ RMSE 0.13850、细频振幅率 $1.5\times10^{-5}$。加 $100E_\nabla$ 组分别为 0.0008088、0.002535、0.13124、$6.8\times10^{-4}$，最大 μ 模长 0.248、最小面积比 0.548，最大真实前向残差 $9.69\times10^{-11}$。图像残差梯度项有小幅收益，但几乎没恢复已知的 32 周期细节。

同一 128 例中，A8 的细频振幅率约 0.743、image MSE $4.45\times10^{-5}$，但 A8 使用不同的 1024 参数 encoder、显式局部反馈和拓扑机制，不能将质量差直接归因于正弦-PCG 求解器。此前直接用目标坐标优化 C 的所有边 latent 可以在难例拟合高频，因而目前最有证据的瓶颈是**从图像 amortized 地推断全边正权重**，不是数学上所有正权重的表达能力不足。延长同一 CNN 和相同像素/残差损失没有当前证据支持；应改试携带细频相位和幅度的边权参数化，或使用拓扑安全的教师层做蒸馏，同时保留正权重和完整细网格求解。

复现入口为 tools/phase6_train_c_multisample.py；逐样本数组、参数、残差、时间在 docs/research_phase6/raw_results/c_sine_pcg_context_multisample32_*.json，权重在 docs/research_phase6/checkpoints/c_sine_pcg_context_multisample32_*.pt。

## 教师梯度监督的受控失败

为了区分图像损失与网络表示两个瓶颈，固定已训练 A8，把它在相同 32 张训练图像上产生的 **预测** 顶点坐标当作教师；教师不访问测试集，也不提供解析目标 map。C 的损失额外包含教师 P1 map 的水平/竖直细边差分平方误差，权重 0.1。C 的测试时输入仍只是图像，输出仍由自身正 conductance 线性方程得到。1000 步以后保留集 image MSE 0.000854、map RMSE 0.002596、面 μ RMSE 0.1436，而 32 周期位移振幅率约 -0.000126。教师监督使边导数损失下降，但细频仍基本消失；这排除“像素损失缺少显式导数监督”作为唯一原因，不排除更强的编码器或不同边权基。

为定位网络产生的 conductance 频谱，取预定训练例 29，分别把每类边权排成水平、竖直、斜边数组，在内部 32×32 傅里叶 bin 附近统计能量占该类边权去均值总能量的比例。直接用目标坐标拟合的 197120 条自由边权在三类边上分别约为 0.210、0.397、0.157；像素 CNN 约 $4.9\times10^{-6}$、图像残差梯度 CNN 约 $1.8\times10^{-5}$、教师梯度 CNN 约 $1.4\times10^{-6}$。该统计是单例表示诊断，傅里叶能量比不是配准精度或一般性不可能定理。具体数组与频率定义见 raw_results/c_edge_spectrum_trainitem29.json。
