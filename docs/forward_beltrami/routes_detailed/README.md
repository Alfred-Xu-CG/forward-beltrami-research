# Detailed route monographs

These files are written as self-contained technical notes rather than progress
bullets. Each note follows the same order: problem class, mathematical model,
discrete unknowns, forward algorithm, backward derivative, topology statement,
complexity, experiments, and unresolved theorem.

Read `00_common_notation_and_acceptance.md` first, then the route of interest.
The route letters match `docs/forward_beltrami/route_status.md`.
