# 稀疏光度提示＋稠密安全 P1 更新：速度略降、128周期几何明显失真

## 要回答的问题与不变量

最终输出保持4097²控制顶点、33,554,432个原三角形的一张固定网格P1地图，所有细顶点仍经同一个四颜色安全更新和最终逐面证书。只改**产生 latent 提示**所用的空间采样密度：在当前地图的嵌套子格上计算局部四视图正规方程，按物理位移单位把提示归一到4097²网格，再双线性插值成完整细 latent。该插值发生在尚未施加拓扑层的**提示/latent**上，不是对输出地图作普通插值；故拓扑契约本身未放松。

具体对照为：每个控制顶点都计算提示（full），或在513²、1025²、2049²子格计算后插值；对最后一级又试2048²个奇—奇“新顶点”子格，避免只取继承的偶—偶点。提示不是P1地图，插值无需单射，但其几何信息会受取样和窗口物理尺度影响。原局部窗口是3个**提示格点**，因此缩小提示网格也改变了物理平均半径；另试1025²提示时窗口改为1。所有候选同用已训练的编码器/细增益，不重新训练，故只能检验**零重训替换**，不能推断重新训练的上限。

实验为16例开发seed20270215、`high128`、512²图像/查询、四幅独立纹理，同一真实形变，float32，AI远程空闲RTX A6000，PyTorch2.5.1+cu124。query-map RMSE是全例全查询二维欧氏误差的均方根；mode RMSE是128周期位移投影系数误差；forward包括编码器、全部P1层、最终512²地图查询与图像采样，VJP再对图像MSE反传到全部编码器及增益。时间为batch1五次CUDA同步热态中位，峰值为CUDA allocated，注意16例数据在GPU上常驻使其并非仅模型的必要内存。第一轮通常有额外warmup开销，已从中位数自然排除。所有组别的16张地图都通过最终证书；下表精度均为16例合并值，性能为首例batch1。

对四通道独立噪声 \(\sigma=.001\)，同一16例的full map RMSE约 \(1.741\times10^{-4}\)，2049²偶—偶约 \(1.593\times10^{-4}\)，表面上总误差稍降；但指定模态误差从约 \(6.51\times10^{-6}\) 升到 \(6.44\times10^{-5}\)，是严重的细节牺牲，而不是稳健化。奇—奇子格在无噪声时已显著偏差；其直接插值会改变密集残差的相位和活动面，不能把此一变体代表所有稀疏取样方案。

即使输入图像只有512²，\(I_m(f(x))\) 与光度残差作为**控制坐标**的函数，仍会随子像素采样位置及当前细地图变化；把它仅在偶—偶点估计再双线性外推，不能保证恢复新顶点所需的提示。此例中特定128周期只有四个图像像素/周期，513²提示刚够采样却没有足够冗余应对梯度/残差相位和局部窗口；2049²虽密得多，也丢失了关键增量。该诊断支持“细网格的生成运算可并行、可微且低成本”与“提示必须按足够空间带宽产生”分开设计；不能因为图像分辨率小，就不经证据地把其 latent 提示降到同尺度。

这里的阴性结论限定于当前**双线性提示插值、预训练权重、局部光度正规方程和high128目标**。它不排除带频带分解/反混叠、不同相位联合采样、可训练上采样或任务先验的低分辨率 latent，也不否定本轮已证明的 coarse-to-fine P1 安全构造。[探针代码](../../tools/phase7_feedback_scale_probe.py)含`--hint-control-side`与`--hint-final-odd-sublattice`以复算；若后续寻求速度，下一步应明确成本分解与误差频谱，再训练一个保持细带宽的提示生成器，而不是直接减少采样点。
