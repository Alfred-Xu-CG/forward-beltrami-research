# 光流提示依赖与纹理鲁棒性的两种训练干预

## 先隔离失配来源

[文档51](51_shared_flow_cue_cross_route_and_texture_shift.md)表明，有局部位移提示的编码器在标准纹理上准确，但在六光斑稀疏纹理上地图误差接近恒等图。为了问“网络对提示通道依赖多大”，固定同一个已训练的1025²混合层权重，只在推断时把提示特征 $h_x$ 乘上0；固定/移动图像、坐标通道与解码器都不变。这是**训练外输入干预**，不是重新训练一个无提示网络，也不是因果上仅移除提示影响，因为第一层滤波器的联合特征分布也随之偏移。

| 新128纹理 | 原提示输入的image MSE / map RMSE | 同权重，提示乘0的image MSE / map RMSE |
|---|---:|---:|
| `standard` | .00010419 / .00129863 | .00799384 / .01051566 |
| `spots` | .00001274 / .00891357 | .00007192 / .01051790 |

在这组权重上，去掉提示后两种纹理的地图误差都约 .0105，接近恒等图的 .01025；因此网络确实高度依赖这个通道。不过在 `spots` 上，原提示仍比直接遮掉提示略好，不能简单说“光流特征单独导致全部分布外错误”。更准确的边界是：仅见过一种纹理生成机制的整套图像编码器没有在低纹理场景中找到可靠替代线索，且图像 MSE 在稀疏内容下不能充分约束真实位移。

## 两个小干预，共同的257²验证

沿用17²粗 patch＋各级新顶点的混合安全解码器；仍然只有32张不同真地图、512²图像、257²控制顶点、1000步 image-only Adam、batch2，未见过128张真地图 seed939031。`drop50` 训练时每个 batch 以独立随机流 50% 概率把两个光流特征通道置零；评价时始终使用完整提示。训练地图取样随机流与原实验相同，额外 dropout 使用另一随机流。`augcross` 不做 dropout，而对同一32张训练真地图再生成32对新的 `crosswaves` 移动/固定图，变成64个训练图像对；总训练步数和 batch 不变。因此每个标准纹理对被访问的次数相应减少。`spots` 未用于两种新模型训练，可以继续作为分布外压力测试；`crosswaves` 对 `augcross` 则不再是盲测。

| 257²模型 | 新128 `standard` image MSE / map RMSE | 新128 `spots` image MSE / map RMSE | 新128 `crosswaves` image MSE / map RMSE | 新128标准纹理最小 J / 回退 |
|---|---:|---:|---:|---:|
| 原完整提示 | .00014130 / .00166472 | .00001300 / .00892972 | .00096194 / .00196426 | .10285 / 0 |
| `drop50` | .00066810 / .00310188 | **.00000858 / .00361195** | .00248248 / .00315466 | .54731 / 0 |
| `augcross` | .00015996 / .00177701 | .00001006 / .00886737 | **.00081410 / .00184574** | .08771 / 0 |

`drop50` 大幅改善稀疏光斑的地图误差，却使标准纹理和新交叉波都显著退步；它不是全局更优模型。增加第二种训练纹理基本保持标准族精度、略改善交叉波，但没有改善尚未见过的稀疏光斑。两者都未解决低纹理区域的运动歧义，且只试一个 dropout 率、一个额外纹理族、一个训练种子。这些结果是确定下一步实验的诊断，不能当作自然图像泛化证据。后续如果继续研究该问题，应该引入匹配置信度/可辨识区域掩码、更多相互独立的图像来源和局部几何目标；不能通过对 `spots` 反复调超参数后还把它称为未见测试。

检查点：[原完整提示257²](checkpoints/phase7_hybrid_flow257_high32_image1000.pt)、[drop50](checkpoints/phase7_hybrid_flowdrop50_257_high32_image1000.pt)、[augcross](checkpoints/phase7_hybrid_flowaugcross_257_high32_image1000.pt)。运行入口和结果计算在[脚本](../../tools/phase7_train_forward_pyramid_image.py)，训练配置随每个检查点保存。输出拓扑的数学保证来自解码器的局部安全步骤和边界约束，与是否采用 dropout 或图像增强无关。
