# 16 个紧支撑细尺度模式：局部 latent 是否能在百万点网格上独立起作用

## 目标类和严格拓扑范围

[三全局模式实验](10_multimode_spectral_readout.md)仍让每个 latent 影响全域。为测试空间局部可控性，把单位正方形划成互不重叠的 4×4 小块 \(Q_{rc}\)，每块边长 \(s=1/4\)。若 \(Q=[x_0,x_0+s]\times[y_0,y_0+s]\)，定义在该小块外为零、在内部为
\[
W_Q(x,y)=\sin^2\!\left(\pi\frac{x-x_0}{s}\right)
\sin^2\!\left(\pi\frac{y-y_0}{s}\right),\qquad
H_Q=W_Q\sin(256\pi x)\sin(256\pi y).
\]
零延拓的 \(W_Q\) 在小块界面保持 \(C^1\)；不同 \(H_Q\) 的非零内点支撑不相交。取
\[
F(x,y)=(x,y)+(a_x,a_y)B(x,y)
 +(1,1)\sum_{Q}c_QH_Q(x,y),
\]
其中 \(B=\sin(2\pi x)\sin(2\pi y)\)，\(a_x\in[0.005,0.015]\)、\(a_y\in[0.010,0.025]\)、16 个 \(c_Q\in[-0.0002,0.0002]\) 独立均匀。每个细模式在 257² 顶点上为零，在 1025² 控制顶点中出现真实的局部自由度。512² 是图像/查询分辨率，不能充当控制网格规模。

全系数盒的解析安全性无需事后筛样本。由于小块内部一次最多有一个 \(H_Q\) 非零，\(|\partial_xH_Q|,|\partial_yH_Q|\le256\pi+4\pi\)，因而 \(u=F-\operatorname{id}\) 的行绝对和满足
\[
\|Du\|_\infty\le4\pi(0.025)+2(0.0002)(256\pi+4\pi)
=r\approx0.6409<1.
\]
连续 \(F\) 与同规则三角剖分上的 P1 插值均全局 \((1-r)\)-co-Lipschitz、固定边界，故是 homeomorphism；逐面 \(J_T\ge(1-r)^2=0.12896\)。P1 面差商服从同一导数界，且沿任意两点连线分段积分保持 Lipschitz 界。这不是仅检查局部面积的替代论证。[目标生成器](../../tools/phase6_train_multisample_image.py)、[独立网格检验](../../tools/phase7_high128_resolution_diagnostic.py)。

保留 8 例 seed 99317 上，目标 1025² P1 全脸实测最小 \(J_T=0.74843\)。其对解析 \(F\) 的 512² query-map 向量 RMSE \(3.90\times10^{-6}\)、最大单坐标差 \(2.18\times10^{-5}\)；目标 257² P1 分别为 \(3.06\times10^{-5}\)、\(1.91\times10^{-4}\)。两者是目标采样插值误差，不是任意 257² 网络的已证最优下界。

## 无大系统的图像局部读出与固定网格正向层

冻结已训练的 257² 图像粗模型，经两次安全光度反馈得到 \(g\)。对每小块模式设 \(D_Q(q)=H_Q(q)[\partial_x I_m(g(q))+\partial_y I_m(g(q))]\)、\(R(q)=I_f(q)-I_m(g(q))\)。因为不同 \(H_Q\) 支撑互不相交，最小二乘正规矩阵的不同小块列交叉项为零；16 个系数可**并行逐个**由
\[
\widehat c_Q=\frac{Q^{-1}\sum_qD_Q(q)R(q)}
{Q^{-1}\sum_qD_Q(q)^2+10^{-12}}
\]
读出。这里 \(Q=512^2\) 是像素查询数；没有解 16×16，更没有解百万顶点系统。给定粗图与读出系数，[流式安全谱细化层](../../src/qcopt/neural_bijection/dense/spectral_p1_refinement.py)直接在嵌套固定三角网格上做 F1 或 F2 局部更新，输出**一张** 1025² P1 图，所有层保持身份边界和正向面。16 个基函数不预存为 16×百万顶点张量；VJP 时重算其值。此设计依赖手工窗口位置、频率和方向，不代表模型发现了真实图像的局部运动基。

## 测量及阴性信息

AI RTX A6000、PyTorch 2.5.1、float32、batch 2，保留 8 例 seed 99317、512² 图像/查询、1025² 控制顶点与 2,097,152 个面。模型在该 16 模式目标族上**从未训练**，只用旧单全局 high128 家族训练的 257² 粗图编码器；局部读出由图像残差直接计算。zero 对照将 16 系数全置零，其他流程完全相同。模式向量误差先把 x/y 位移投影到各个 \(H_Q\)，对 32 个投影系数的差求跨例欧氏 RMSE；另用目标 1025² P1 插值而非连续 \(F\) 作参照，剔除必然的控制网格插值衰减。整体 map RMSE 用 512² 查询点到解析 \(F\) 的欧氏平方均值开根，image MSE 为灰度像素差均方。

| 粗模型 / 细系数 | image MSE | query-map RMSE | 16 模式投影误差：对连续 \(F\) / 对目标 P1 | 全脸最小 \(J_T\) | 推理中位秒 |
|---|---:|---:|---:|---:|---:|
| F1 / 全零 | \(8.3984\times10^{-6}\) | 0.00034255 | 0.00066299 / 0.00059466 | 0.32196 | 0.0498 |
| F1 / 图像读出 | \(8.3311\times10^{-6}\) | 0.00034118 | 0.00009824 / **0.00007068** | 0.30686 | 0.0506 |
| F2 / 全零 | \(6.3533\times10^{-6}\) | 0.00030079 | 0.00065025 / 0.00058103 | 0.34320 | 0.0672 |
| F2 / 图像读出 | \(6.2881\times10^{-6}\) | 0.00029928 | 0.00007098 / **0.00002073** | 0.34225 | 0.0672 |

F1/F2 的 16 系数欧氏 RMSE 分别为 \(6.38\times10^{-5}\)、\(2.49\times10^{-5}\)。F2 的 128 例全新纹理/系数 seed 939031 评估更难：系数 RMSE \(4.01\times10^{-5}\)，对目标 P1 的模式误差 \(1.06\times10^{-4}\)，最小 \(J_T=0.20084\)，image MSE \(1.164\times10^{-5}\)，query-map RMSE 0.00041487。相对于该 128 例目标 P1 模式 RMS 0.00058152，它确实恢复了局部细节，但显著弱于 8 例结果；这可能与未见纹理和粗映射误差有关，**不能**选择性只报较好保留集。

把真实 16 系数作为仅评估用 oracle 输入时，在仍使用**网络预测的粗图**条件下，F1/F2 对目标 P1 的模式误差反而为 0.00010511/0.00003836，比图像读出差。原因候选是读出系数会补偿粗图在局部模式上的投影泄漏；因此这个 oracle **不是完整真实低频+真实细频映射**，不能据此判断读出优于真实系数。独立以解析目标的真实 257² 粗顶点和真实 16 系数输入两种安全层时，1025² 顶点对解析目标顶点 RMSE 均 \(1.36\times10^{-6}\)、最大单坐标差 \(3.64\times10^{-6}\)；该剩余主要来自粗 P1 插值无法还原低频 \(B\) 在新顶点处的曲率，而非细模式表示失败。安全层的精确可表达目标应是“真实粗图的 P1 精确细化 + 16 细模式”，另作对照核查。

batch 1 的整链图像损失 VJP 对编码器参数有限且非零；F1/F2 前向加反传约 0.478/0.495 秒，峰值 allocated 1.09/1.55 GB；batch 2 推理 allocated 峰值约 0.720/0.668 GB。不同 batch、图像编码、基函数评估和 topology update 均计在整链指标内；不可直接与只含谱 P1 refiner 的 [微基准](10_multimode_spectral_readout.md)速度混比。[完整评估脚本](../../tools/phase7_evaluate_spectral_image_refinement.py)。

## 解释边界与下一步

这给出空间上各自独立的 16 个 image-derived 细控制系数，并在 1025² 真控制网格形成无折叠 P1 图；但这是固定 4×4 tile、固定 128 周期的**16 维子空间**，远不能称“覆盖绝大部分 homeomorphism”。小幅细运动的总图像 MSE 改进也很小，低频粗映射误差仍主导整体 map RMSE。优先改进：扩大粗图训练内容并在新纹理上重估局部读出；检查每 tile 的纹理条件数、读出偏差与目标幅度；允许不同频率、方向和自适应窗口，同时保存固定网格 P1 证书；与不用预设模式、在细网格自由 latent 上直接训练的同预算基线对比。对无纹理/遮挡区域的不可辨识性必须单列，不可由拓扑层保证。

补充前述“可表达目标”核查：同 8 例 F2 的全顶点欧氏 RMSE 为 \(2.35\times10^{-8}\)、最大单坐标差 \(5.96\times10^{-8}\)，属于 float32 舍入；而与解析 1025² 样本的 \(1.36\times10^{-6}\) 差距确实来自粗图曲率插值。[核查脚本](../../tools/phase7_high128_resolution_diagnostic.py)。

### 仅用图像损失训练局部读出增益的阴性结果

把 16 个非负 gain 加到一次局部最小二乘系数上，并且**只以 512² 图像像素 MSE**经 1025² F2 层反传训练；冻结扩大训练后的 F2 粗 CNN。训练 256 个纹理/系数 seed 77557、测试全新 128 个 seed 939031，batch4、Adam 学习率 0.01、eps \(10^{-12}\)、400 步，AI A6000 GPU7、float32。训练细层启用梯度重算以降低显存；峰值 allocated 约 1.71 GB、每步中位 0.299 秒。gain 从 1 变为均值 1.1097（范围 1.1002–1.1200），但新 128 的 image MSE 仅由 \(6.52108\times10^{-6}\) 到 \(6.52039\times10^{-6}\)，query-map RMSE 由 0.000326078 到 0.000326065，几乎不变；真实 16 模式系数向量 RMSE **从 \(3.40\times10^{-5}\) 恶化到 \(6.35\times10^{-5}\)**。这不是完全没有参数或梯度变化，而是当前图像目标不能把光度改进等同细运动恢复；需要独立运动参照或更有效的多纹理可辨识设计。[训练脚本](../../tools/phase7_train_tile_readout_gain.py)。

### 扩大粗图训练集与额外光度迭代的消融

沿用单全局 high128 的 257² 训练目标，但把训练纹理从 32 增到 256、测试增到 128，旧检查点再 image-only Adam 续训 1000 步（batch 4、学习率 0.0003、512² 图像、两次 257² 安全反馈）；F1/F2 分别在 AI 空闲 A6000 上约 109/144 秒。测试 128 的粗图 query-map RMSE：F1 从 0.00044391 降到 0.00041173，F2 从 0.00039885 降到 0.00033211；image MSE 分别从 \(1.352\times10^{-5}\) 到 \(1.136\times10^{-5}\)、\(1.076\times10^{-5}\) 到 \(7.063\times10^{-6}\)。新粗图在 16 局部模式数据的全新 128 例上，F1 总 query-map RMSE 由 0.00047206 降到 0.00041924，模式对目标 P1 误差由 0.00013967 降到 0.00012085；F2 总 map RMSE 由 0.00041487 降到 0.00032608，但模式误差从 0.00010555 **略升**至 0.00010666。粗图整体改善不保证每个细局部模式也改善；仍需分开评价。

另一候选是重复“图像残差 → 局部系数最小二乘 → 安全细图”并在第二次图像 warp 后作新的线性化。用新 F2 粗图在原 8 例上比较一次与两次读出：image MSE \(3.38431\times10^{-6}\) 对 \(3.38365\times10^{-6}\)，总 map RMSE 0.000224731 对 0.000224712，**基本不变**；然而对目标 P1 的 16 模式误差从 0.00002947 **恶化**至 0.00007091，推理中位时长从 0.066 到 0.102 秒。第三次仍无整体改善，模式误差约 0.00007683。新 128 例上第二次读出也使模式误差从 0.00010666 升至 0.00012406，而 map RMSE 不变。因而对当前固定粗图，重复光度残差读出更像用错误的细 latent 补偿粗误差，并非提升真实细形变的有效迭代；不能只因像素损失略低就采纳。这是本阶段明确的**阴性优化结果**，保留在 [评估脚本](../../tools/phase7_evaluate_spectral_image_refinement.py) 的可选参数中供继续诊断。
