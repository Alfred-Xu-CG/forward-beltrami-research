# 固定网格 F1/F2 的目标依赖深度可达性：存在定理与速度问题分离

## 定义和已有拓扑事实

在单位正方形 \(\Omega=[0,1]^2\) 的固定规则三角剖分 \(\mathcal T_h\) 上，令
\[
\mathcal H_h=\{Y:\;Y_i=x_i\ (i\in\partial\Omega),\
A_T(Y)=\det(Y_j-Y_i,Y_k-Y_i)>0\ \text{对每个正向面 }T=(i,j,k)\}.
\]
这里的状态是全部顶点位置，不是连续流或多张 P1 图的复合。由固定且一一对应的边界及所有面正向，\(\mathcal H_h\) 对应固定连接关系的直线平面嵌入；全局单射需另用 [Lipman 的边界/度数定理](https://arxiv.org/abs/1310.0955)，不能只援引面面积。

[Luo, *Spaces of Geodesic Triangulations of Surfaces*, Theorems 1.4、3.5](https://link.springer.com/article/10.1007/s00454-021-00359-4) 对固定凸多边形与固定三角连接关系的嵌入空间给出路径连通、甚至可缩的结论。不过我们的正方形边界存在许多**共线细分顶点**，不能仅凭摘要便把“凸多边形”定理直接套用。为处理这点，直接使用 [Floater, *One-to-one piecewise linear mappings over triangulations*, Proposition 3.3 和 Theorem 6.1](https://doi.org/10.1090/S0025-5718-02-01466-7)：每张一一对应的 P1 图都能使每个内部顶点成为邻点像的**严格正权重**凸组合；反过来，对固定凸边界的一张正权重凸组合图，只要没有任何连接两个边界顶点的**内部划分边**整个被映到目标边界上，它便一一对应。后一条件正是不能随意丢掉的弱凸边界细节。

在本 SW–NE 规则网格上，任何连接同一方形边上的两个边界顶点的网格边，都只能是相邻点之间的**边界边**。可能的内部 boundary-to-boundary 对角边只跨相邻的两条方形边（分别位于左上角与右下角单元），其像在固定恒等边界下是方形内部的弦；因此没有违反 Floater Theorem 6.1 的划分边。这个检查对所有边长至少有两个小格的网格成立；单小格网格没有内部顶点，结论平凡。故此处的路径连通不是未核实的“严格凸外边界”类比。

更具体地，任取 \(Y^0,Y^1\in\mathcal H_h\)。由 Proposition 3.3 分别为每个内部顶点选一组全邻接正权重 \(w^0_{ij},w^1_{ij}\)，且 \(Y_i^k=\sum_jw^k_{ij}Y_j^k\)。对 \(t\in[0,1]\) 令 \(w(t)=(1-t)w^0+tw^1\)，边界恒等，并以 \(Y_i(t)=\sum_jw_{ij}(t)Y_j(t)\) 定义内部顶点。正权重与到边界的图连通性保证 Dirichlet 系统唯一可解，且解随 \(t\) 连续。Floater Theorem 6.1 加上刚核对的划分边条件，使每个 \(Y(t)\) 都是一一对应的固定网格 P1 图；边界取向不变，所以所有面保持正向。唯一性也给出 \(Y(0)=Y^0,Y(1)=Y^1\)。**这个全局线性系统只出现在路径存在性的证明里，F1/F2 的实际前向和 VJP 均不求解它。**

## 局部引理：足够近的两张合法图可以一次到位

固定一个 \(Y\in\mathcal H_h\)。F1 的一次 pass 依次处理四种 \((\text{行奇偶},\text{列奇偶})\) 颜色；同色顶点从不共面。给另一状态 \(Z\) 的顶点差 \(d_i=Z_i-Y_i\)，并在这次 pass 对每个内点设
\[
z_i=\operatorname{artanh}\bigl(d_i/(\alpha h)\bigr)
\]
（逐坐标）。若 \(\|Z-Y\|_\infty<\alpha h\)，该 logit 有限，未截断的原始运动恰为 \(d_i\)。

令 \(\delta=\min_T A_T(Y)>0\)，\(E=\max_{(i,j)\in\mathcal T_h}\|Y_j-Y_i\|_2\)。四颜色过程中，一些顶点已取 \(Z_i\)，其余仍取 \(Y_i\)。面面积是顶点坐标的连续多项式，因此存在 \(\eta_1(Y)>0\)，只要 \(\|Z-Y\|_\infty<\eta_1\)，**每一种**混合状态的面积均至少 \(\delta/2\)。对当前面的一位待更新顶点，另一条对边不动，其位移对面积的不利变化最多是对边长度乘 \(\|d_i\|_2\)，在足够小邻域可由 \((E+O(\eta_1))\sqrt2\,\|Z-Y\|_\infty\) 控制。进一步取
\[
\|Z-Y\|_\infty < \eta(Y)
\quad\text{使}\quad
\eta(Y)<\alpha h,\qquad
(E+O(\eta(Y)))\sqrt2\,\eta(Y)<\gamma\delta/2,
\]
就使 F1 径向安全尺度在每个面上**恰为 1**，于是四颜色 pass 精确输出 \(Z\)。这是有限维开集与严格不等式的局部结论；未声称一个不依赖 \(Y\) 的统一半径。此处须取无固定面积下界的理论版本 \(\rho=0\)；若实现强制 \(J_T\ge0.05\)，则所有 \(J_T<0.05\) 的合法目标显然不在可达集合中。

F2 有类似但非同一的局部引理。令 patch 边长为 \(p\) 个单元，四种半 patch 偏移的严格内部顶点并集覆盖每个全局内点。给每个目标顶点指定**首次覆盖它的 pass**，只在该 pass 输入 \(d_i=Z_i-Y_i\)，其余 pass 对它输入 0。每个 patch 的原始跨度是 \(rph\)，所以 \(\|d_i\|_\infty<rph\) 时有有限的 \(\operatorname{artanh}(d_i/(rph))\)。单面面积对同时移动的几个 patch 内点是
\[
A_T(s)=A_T(0)+sL_T+s^2Q_T,\quad
C_T=(-L_T)_++(-Q_T)_+.
\]
因为 \(L_T=O(\eta)\)、\(Q_T=O(\eta^2)\)，且四 pass 的全部混合状态在 \(Z\) 足够接近 \(Y\) 时保留正面积，能使每个受影响面 \(C_T<\gamma A_T(0)\)。取 F2 的 **minimum_jacobian=None** 版本，patch 安全尺度便恰为 1，四 pass 后精确得到 \(Z\)。这使用了 patch 内同时移动相邻顶点的二次界，不是 F1 单点线性界的换名。实际代码现允许 \(\rho=None\)；17² 小形变回归测试用独立解析目标验证了四 pass 精确到位。

## 定理：允许目标依赖的重复次数，任意固定网格合法状态均可到达

由上节对 Floater 定理的适用性核对，\(\mathcal H_h\) 在本固定恒等边界 SW–NE 网格上路径连通。取 \(Y^\star\in\mathcal H_h\) 及所构造的连续路径 \(Y:[0,1]\to\mathcal H_h\)，满足 \(Y(0)=\operatorname{id}\)、\(Y(1)=Y^\star\)。紧致时间区间上的路径像是 \(\mathcal H_h\) 的紧子集，故
\[
\delta_\star=\min_{t\in[0,1],T\in\mathcal T_h}A_T(Y(t))>0.
\]
上面两个局部引理的安全邻域可沿紧路径取有限覆盖；由路径一致连续性，存在有限时间分割 \(0=t_0<\cdots<t_K=1\)，使每对相邻状态满足局部引理。于是：

1. **F1**：从恒等开始，在这张**同一固定网格**连续运行 \(K\) 次四着色安全 pass，适当有限 latent 可使末态精确等于 \(Y^\star\)。
2. **F2**：当 \(p\) 为偶数、\(p\mid(N-1)\) 且四偏移 patch 覆盖全部严格内点时，连续运行 \(K\) 次四-pass patch 周期，同样存在有限 latent 使末态精确等于 \(Y^\star\)。

两种结论均为**实数精确算术、无额外固定面积下界、目标依赖深度**的表示存在性；并非当前 seed 5/17、每级一轮、\(\rho=0.05\) 的已训练网络覆盖整个 \(\mathcal H_h\)。也不保证 \(K\) 随网格尺寸、多面薄度或目标复杂度有可接受的上界。路径的存在性证明可借助全局线性系统；这不意味着用于每次网络推理的 F1/F2 解码器需要解该系统。若从已知目标构造 latent，可能仍需昂贵路径计算；“表示存在”不等于“可快速编码”。

## 与 continuum 逼近的推论及研究价值

对任何边界恒等、正向且导数有正奇异值下界的 \(C^{1,1}\) 微分同胚 \(F\)，足够细时 \(I_hF\in\mathcal H_h\) 且 \(\|I_hF-F\|_\infty=O(h^2)\)，如 [细化命题](01_refinement_reachability.md) 所推导。将上一个固定网格命题应用于每个 \(I_hF\)，得到 F1/F2 的**深度不受统一限制**的 continuum \(C^0\) 逼近结论，即使事先没有给出统一正则同伦。反过来，[细化命题](01_refinement_reachability.md) 的额外统一 isotopy 假设可在固定起始网格建立一个与最终 \(h\) 无关的 seed 步数，并使逐级工作量接近线性；这是更实用但更窄的复杂度结论。

因此，下一阶段真正应问的不是“安全局部字典是否理论上完全无法到达合法 P1 图”，而是：对图像任务分布，如何得到**短、可预测、好训练**的 coarse-to-fine 路径？如何用每次可同时移动相邻顶点的 F2、而非仅逐点的 F1，减少 \(K\) 对细网格尺度的依赖？如何在保持严格原网格 P1 保证时，把光度反馈放在合适的粗层，避免固定物理位移需要 \(O(h^{-1})\) 次细网格局部步？这些是当前速度和训练的开放问题，而非上述存在命题的推论。
