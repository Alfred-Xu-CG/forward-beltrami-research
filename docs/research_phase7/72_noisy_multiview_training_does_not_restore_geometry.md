# 含噪四视图的 image-to-latent 再训练：光度目标与几何目标仍分离

## 问题与固定协议

前一轮[通道/噪声剂量实验](70_multiview_channel_count_noise_tradeoff.md)发现，四幅独立纹理观测在无噪声时将4097²固定P1层的 query-map RMSE降至约 \(1.52\times10^{-5}\)，但固定/移动图像各自加独立标准差 \(\sigma=.001\) 的像素高斯噪声后升至约 \(1.73\times10^{-4}\)。问题是：**只用含噪图像残差对原有细层 latent 增益继续训练**，能否恢复几何，而不看地图真值？

固定已有单图像训练的1025²编码器和粗两级权重；2049²、4097²各一次局部四视图正规方程提示、四颜色安全顶点更新，完整原网格4097²=16,785,409顶点/33,554,432三角形，图像与最终评价查询512²；float32，AI主机空闲RTX A6000，PyTorch2.5.1+cu124。以干净单视图训练所得两个细级增益 \((0.90544,2.01760)\) 初始化，仅优化这两个标量，不改拓扑模块、图像编码器或数据生成器。训练32例seed55101、batch1、300次Adam随机样本更新，损失为四通道固定/变形后移动图像的像素MSE乘 \(10^6\)（乘常数只改梯度尺度），**不使用真地图**；训练的固定/移动各通道均加独立 \(\mathcal N(0,.001^2)\) 噪声。新128例seed20270317没有用于训练或调参；同时用未再训练的细增益做匹配对照。实现为[规模探针](../../tools/phase7_feedback_scale_probe.py)，[训练检查点](checkpoints/phase7_extra_gains_4097_multiview4_noise001_image300.pt)可复现。

## 结果

训练300/300步最终安全接受，细增益变成 \((1.11930,2.22417)\)；第一步细增益梯度最大绝对值0.0111且有限，训练中位步时0.573s，CUDA allocated峰值13.819GB。新128例统计如下；query-map RMSE是每例512²查询点预测/真值的二维欧氏误差先平方平均再在128例合并开方；mode RMSE是两坐标位移在指定128周期正弦模态投影系数的误差；image MSE在全部四通道和像素上平均。

| 新128例，\(\sigma=.001\) | image MSE | query-map RMSE | 128周期 mode RMSE | 最小原面 \(J\) / 回退 |
|---|---:|---:|---:|---:|
| 干净数据训练的原细增益 | 7.41900e-7 | **1.72120e-4** | 6.49344e-6 | .049536 / 0 |
| 含噪四视图 image-only 再训练300步 | **7.40929e-7** | 1.72761e-4 | **4.90440e-6** | .049670 / 0 |

可见新的光度误差略低，特定模态投影更准，但整体几何RMSE略**更差**约0.37%；没有恢复无噪声四视图的几何水平。不能说这两个增益“完全没有学习”：参数明显改变，训练/留出图像MSE和特定模态也改变；更准确的结论是**仅两个全局细级增益加含噪图像MSE，在本协议下未产生总体几何收益**。这不是“所有含噪训练均不可能有效”的证明；更丰富的空间噪声模型、先验或监督依然待测。

在同一16例开发集上，单纯把原两个细增益共同减半，把 map RMSE 从约 \(1.74\times10^{-4}\) 降至 \(1.56\times10^{-4}\)，却使模态RMSE从 \(6.51\times10^{-6}\) 升至 \(5.00\times10^{-5}\)。把两幅提示图先做 \(\sigma_{\rm blur}=.5\) 像素高斯模糊，随后把细增益共同放大1.5或2倍，map RMSE约 \(1.34\times10^{-4}\) 或 \(1.33\times10^{-4}\)，但模态RMSE约 \(1.01\times10^{-4}\) 或 \(1.09\times10^{-4}\)。这些开发集调参是**噪声—细节折中诊断**，没有在新128例上选优，也不构成稳健算法。

核心教训是把[精确P1单视图不可辨识反例](71_single_image_exact_p1_nonidentifiability.md)、多视图可观测性与噪声统计同时放进实验设计。安全的多尺度P1输出机制已经可以处理4097²及完整VJP，但观测信息与损失设计没有同步解决；拓扑正确不是几何准确的代名词。
