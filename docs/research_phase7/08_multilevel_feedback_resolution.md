# 百万控制点上的分层图像反馈：尺度瓶颈与细层收益审计

## 研究问题与数学构造

目标输出始终是 \(1025\times1025=1{,}050{,}625\) 个**控制顶点**、\(2{,}097{,}152\) 个原网格三角面的一张 P1 图；\(512^2\) 只表示图像/查询数。F1 和 F2 原先把两次局部光度安全更新都放在最终 1025² 网格。F1 单顶点径向原始跨度 \(2h\) 随 \(h=1/(N-1)\) 缩小，F2 的 patch 位移跨度 \(0.5\,p h\)（\(p=8\)）也缩小；即使提高 logit 幅度，面积约束仍限制细网格上的单次物理运动。若保留固定两次反馈，不能指望从 257² 直接放大到 1025² 后保持同样修正能力。

因此测试如下严格正向分层式。令 \(D_{\le257}\) 是同一 F1 或 F2 decoder 截至 257² 的部分，\(R_{257}\) 是依据固定/移动图像生成光度提示并由四着色面积安全层施加的一次更新，\(P\) 是相邻规则剖分的精确 P1 细化，\(U_{513},U_{1025}\) 是原先的细尺度 latent 更新：
\[
Y_{257}=D_{\le257}(z_{\le257}),\qquad
\widetilde Y_{257}=R_{257}^{\,2}(Y_{257};I_{\rm fixed},I_{\rm moving}),
\]
\[
Y_{513}=U_{513}(P\widetilde Y_{257},z_{513}),\qquad
Y_{1025}=U_{1025}(PY_{513},z_{1025}).
\]
F1 每个 \(U\) 是一次四着色新顶点更新；F2 每个 \(U\) 是四个交错 patch pass。两种 \(R\) 都直接修改当前固定 257² 顶点，接着 \(P\) 精确复制**同一连续 P1 函数**到嵌套细剖分，不是把若干连续同胚复合后危险地重新取样。由局部安全不变量、固定边界和嵌套精确细化，数学上对有限 latent 保持最后 1025² 原网格 P1 同胚；下表的最小面积只是 float32 实现核验。代码把“在中间层停止—反馈—继续”做成 decoder 的 [F1 continuation](../../src/qcopt/neural_bijection/dense/forward_p1_pyramid.py) / [F2 continuation](../../src/qcopt/neural_bijection/dense/patch_field.py)，小网格已测试分段与原完整 decoder 的**前向逐元素相等且 VJP 相等**。

如果 \(z_{513}=z_{1025}=0\)，最终 \(Y_{1025}\) 与 \(\widetilde Y_{257}\) 表示**同一个连续 P1 映射**，虽然输出的顶点数是百万；这不构成高分辨率细节的胜利。因此必须另测细 latent 的实际增量收益，不能只看控制点数。

## 实验设置与指标

训练数据复用 [high32 生成器](../../tools/phase6_train_multisample_image.py)：32 张训练图像对（seed 55101）、8 张独立保留图像对（seed 99317）；两张输入均为 512² 单通道，解析边界固定目标仅用于评估，训练损失为移动图像在预测映射下采样后的逐像素均方差。图像对先经 257² 已训练的 F1 或 F2 CNN 检查点产生前六/四个尺度的 latent；新增 513²、1025² 输出头零初始化。随后以 Adam 学习率 0.0002 在**整张 1025² 输出与完整反向图**上续训 200 步、batch 2、float32，全部实际训练步核对全脸 \(J_T>0\)。

保留 image MSE 定义为 \( (B\,512^2)^{-1}\sum_{b,q}[I_{\rm moving}^{(b)}(f_b(q))-I_{\rm fixed}^{(b)}(q)]^2\)。query-map 向量 RMSE 定义为 \(\sqrt{(B\,512^2)^{-1}\sum_{b,q}\|f_b(q)-F_b(q)\|_2^2}\)。最小 \(J_T\) 是所有原面像的有向双面积除以源面 \(h^2\) 的最小值。训练步时间为带同步的中位数；显存为 PyTorch CUDA 峰值 allocated/reserved，不等于整卡常驻占用。

## 同卡尺度放置消融

F1 在 Turing 空闲 A40 GPU0、PyTorch 2.8.0+cu129；F2 在 Element 空闲 L40 GPU1、PyTorch 2.5.1+cu124。**同一路线内部**使用同一主机/GPU、数据和初始 CNN；不同路线的毫秒数不作严格 GPU 排名。反馈在 1025 表示先完整解码后在最细层更新；反馈在 257 表示上式中间层更新后继续细化。两者均为两次、16 正弦模式、安全面积下界 0.05。

| 路线、反馈层 | 续训前保留 image MSE / map RMSE | 200 步后保留 image MSE / map RMSE | 200 步后最小 \(J_T\) | 中位训练步 | CUDA allocated / reserved |
|---|---:|---:|---:|---:|---:|
| F1，1025 | \(7.8517\times10^{-5}\) / 0.0010978 | \(1.0626\times10^{-4}\) / 0.0012391 | 0.15888 | 291.9 ms | 4120 / 4570 MB |
| F1，257 | \(2.9767\times10^{-5}\) / 0.00072459 | **\(2.9165\times10^{-5}\) / 0.00072780** | 0.20457 | 194.2 ms | 1912 / 2168 MB |
| F2，1025 | \(2.3509\times10^{-4}\) / 0.0018012 | \(6.8381\times10^{-5}\) / 0.0010121 | 0.15033 | 160.4 ms | 5019 / 5757 MB |
| F2，257 | \(3.6867\times10^{-5}\) / 0.00076390 | **\(2.7641\times10^{-5}\) / 0.00069623** | 0.16356 | 134.1 ms | 2844 / 3370 MB |

F1 的 fine-only 反馈续训恶化是该 200 步配置的观察，不是最优 fine-only 训练的不可行性定理。更可靠的结论是：**在相同两次反馈预算下，把安全修正放回 257² 层明显减少了运行成本并恢复此前误差量级**。F1 的 allocated 约减少 54%，F2 约减少 43%；然而两路线在不同 GPU 上，不能用此表断言 F2 比 F1 更快。原 F1 257² 最终检查点的保留 image MSE \(2.9767\times10^{-5}\) 与分层 1025² 续训前几乎相同，也符合零初始化细头加精确 P1 细化的预期。

为检验“百万点新头是否真的贡献”，用已训练模型在保留 8 例上将 513²、1025² latent 强制置零，其他权重和 257² 反馈完全不变：

| 路线 | 完整 1025² image MSE / map RMSE | 细头置零 image MSE / map RMSE |
|---|---:|---:|
| F1 | \(2.9165\times10^{-5}\) / 0.00072780 | \(2.9290\times10^{-5}\) / 0.00072912 |
| F2 | \(2.7641\times10^{-5}\) / 0.00069623 | \(2.7896\times10^{-5}\) / 0.00069893 |

细头目前贡献**非零但很小**。high32 目标的最高 32 周期在 257² 网格已有较多采样点，因此本分布本身不能证明网络学到了只有百万控制点才能表示的结构。为此另设 [high128 分辨率判别试验](09_high128_control_detail.md)：该高频位移在 257² 顶点上近乎零，在 1025² 有明确非零采样。必须报告这个更有区分力的结果，不能把本表单独包装成高分辨率网络突破。
