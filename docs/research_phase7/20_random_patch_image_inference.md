# 图像到局部 P1 latent：随机位置/方向任务与明确的阴性结果

## 任务及几何真值

单个样本的局部位移窗口原点 \((x_0,y_0)\) 在 \([0.08,0.86]^2\) 独立均匀采样，宽 \(w=1/16\)；方向角均匀，幅值 \(r\in[0.003,0.006]\)，令 \((a_x,a_y)=r(\cos\theta,\sin\theta)\)。窗口内部定义

\[
W(x,y)=\sin^2\!\big(\pi(x-x_0)/w\big)
\sin^2\!\big(\pi(y-y_0)/w\big),
\qquad T(x,y)=(x,y)+W(x,y)(a_x,a_y),
\]

窗口外取 \(W=0\)。边界为恒等，\(\|D(T-\mathrm{id})\|_\infty\le2r\pi/w<0.604<1\)，所以每个样本解析连续图同胚；规则 SW–NE 网格上的 P1 采样映射继承同一差商界，是独立核实的固定网格 P1 同胚。测试目标不是由待测 decoder 生成。移动灰度图由每样本独立的 8 个随机方向/相位 Fourier 波叠加并标准化；固定图在 512² 像素上由移动图按 \(T\) 的逆采样协议生成：\(I_f(q)=I_m(T(q))\)。随机纹理、窗口位置、幅值和方向均在训练/保留 seed 间独立。训练 128 例 seed 82617，保留 32 例 seed 194381；使用数据生成[源码](../../tools/phase7_train_random_patch_images.py)。

几何层是 [residual F2](19_residual_patch_multilevel_decoder.md) 的 257² 控制顶点、16-cell patch、2 个四错位循环、0.05 精确算术面积 floor，输入 130,050 scalar latent，输出一张 66,049 顶点/131,072 面的 P1 图。网络看且只看固定/移动图；已知 \(T\) 只用于 map-supervised 对照或评估。全局顶点向量 RMSE 为 \([V^{-1}\sum_i\|Y_i-T_i\|_2^2]^{1/2}\)；“窗口内 RMSE”只在真值 \(W>0\) 的控制顶点计同一量，以免大片恒等区域稀释局部失败。image MSE 是 512² 全像素 \(I_m(f_Y(q))-I_f(q)\) 的平方均值。最小 \(J\) 检查全部控制面。

保留集从恒等图开始：全局 map RMSE \(1.00046\times10^{-4}\)、窗口内 RMSE 0.00160699、image MSE \(5.97711\times10^{-5}\)。若直接从真目标控制顶点反算 latent，32 例 decoder 平均 float32 顶点 RMSE 为 0、最小面 \(J=0.720005>0\)；这区分了表示可行与图像推断成功。

## 从零训练的两个编码器

原始图像 CNN 先把固定图、移动图及其差下采样到 257²，经过宽 24 的四层局部/空洞卷积与零初始化输出头，每内部顶点给两个 latent；共有 17,498 个训练参数。第二个候选在输入额外加入 7×7 搜索窗口的 49 通道局部平方差 cost volume，共 46,898 参数。两者都从零初始化网络输出开始，Adam 学习率 0.003、eps \(10^{-8}\)、余弦退火 1200 步、batch4、float32；分别用真实控制顶点 map MSE 或**仅图像 MSE**作损失。即使 map 监督，网络输入仍为两张图，真 map 不提供给网络。`map` 在 Turing A40 GPU0/PyTorch 2.8，`image` 在 Element L40 GPU1/PyTorch 2.5.1；准确率可按同一数据协议比较，速度不能作严格同设备排名。[检查点](checkpoints/)。

| 编码器 / 监督 | 保留 image MSE | 全局 map RMSE | 窗口内 map RMSE | 最小 \(J\) |
|---|---:|---:|---:|---:|
| 原始 CNN / map | \(2.04113\times10^{-5}\) | \(7.25781\times10^{-5}\) | 0.00113998 | 0.60347 |
| 原始 CNN / image-only | \(1.74339\times10^{-5}\) | \(8.60590\times10^{-5}\) | 0.00137081 | 0.42229 |
| cost volume CNN / map | \(5.97736\times10^{-5}\) | \(1.00052\times10^{-4}\) | 0.00160700 | 0.99095 |
| cost volume CNN / image-only | \(4.79179\times10^{-5}\) | \(9.59690\times10^{-5}\) | 0.00153003 | 0.67924 |

原始 CNN 仅部分恢复局部位移；map 监督训练集窗口内 RMSE 仍为 0.001148，说明它不是只在保留集失败。cost volume 的额外参数/匹配通道**没有**带来收益，map 监督几乎停在恒等图附近；不能把“有 cost volume”当作实际成功的局部匹配。原始网络批量4的训练步中位约 A40 60.7 ms / L40 24.8 ms、峰值 CUDA allocated 都约 1.13 GB，数值受主机影响。cost volume A40 64.2 ms / L40 31.0 ms，allocated 约 1.18 GB。四个结果的 decoder teacher 都是精确的，所以眼下主要瓶颈是图像特征/优化/可辨识性，而非这 32 例目标的 P1 几何表示能力；还不能判定三者唯一归因。

## 不学习参数的光度位移提示：更强但并非几何真值

为拆解“网络没有学会”与“图像本身没有位移证据”，在当前图 \(Y\) 的 257² 控制点处计算移动图像梯度 \(g=(I_{m,x},I_{m,y})\) 和残差 \(r=I_f-I_m(Y)\)，在奇数宽 \(k\times k\) 窗口求局部平均 \(G=\langle gg^\top\rangle+\lambda I_2\)、\(b=\langle gr\rangle\)，取 \(d=G^{-1}b\)（每控制点仅 2×2 系统，\(\lambda=1\)），把它缩放为 F2 终点 latent。F2 几何层再按面面积接受位移；可重复“图像残差→局部 2×2 求解→安全 P1 更新”。这不是全网格大矩阵求逆，也不是从图像训练的网络；它是可微的图像条件 latent 提示。[实现](../../src/qcopt/neural_bijection/dense/photometric_hint.py)、[评估脚本](../../tools/phase7_photometric_patch_feedback.py)。

探索性在原 32 例上选窗口7、增益0.75、2次提示迭代：全局 map RMSE \(5.48552\times10^{-5}\)、窗口内 0.00087701、image MSE \(4.36764\times10^{-6}\)、最小 \(J=0.21354\)，每次提示加 F2 更新中位约 9.0 ms（Turing A40、batch4）、allocated 峰值约 0.179 GB。窗口5更差；窗口11在另一 A6000 上两次的窗口内 RMSE 为 0.000931；增益1或1.25在此保留集也不如0.75的 map 误差。**这些参数是在这32例上看的，不能拿32例作盲测胜出。**

锁定窗口7/增益0.75/2次后，新独立 128 例 seed 939031 的初始窗口内 RMSE 为 0.00174499、image MSE \(7.64579\times10^{-5}\)；安全提示后分别为 **0.00108984** 和 \(7.17842\times10^{-6}\)，全局 map RMSE \(6.81660\times10^{-5}\)，最小 \(J=0.049987>0\)。新集明显比32例困难；不可只报前者。该方法还提示任务指标冲突：原32例增益1时第二次提示窗口内 RMSE 为 0.000921，第三/四次 **升到** 0.000950/0.000997，尽管 image MSE 继续下降。图像配准像素改进不等于真实形变更准。

这个结果指出可尝试的下一步：让一个小网络读取原始图像及局部光度提示，预测**残差 latent**，并分别用 map 和 image-only 监督检验是否超越上述固定提示。任何效果都要在新位置/纹理种子上复核，且若只降低像素误差但几何误差升高，不宣称解决了 image-to-latent。

## 读入提示的网络：原 32 例与新 128 例必须一起看

把窗口7/增益0.75 的解析提示作为 latent 初值，CNN 同时读固定图、移动图、差图与提示两个通道，仅输出零初始化的**修正**；参数 18,698，仍经过相同 F2 安全 decoder。另一个变体先执行两次不学习的提示更新，再让同一 CNN 预测第三次的残差 latent；其零初始化输出精确等于两次固定提示。两种变体各以 map 或 image-only 损失从网络参数零输出开始训练 1200 步，训练集和最初 32 例保留集不变。训练模型/参数的快照保存在 [checkpoints](checkpoints/)；没有把解析真 map 传入网络输入。

| 方法 / 监督 | 原 32 例窗口内 RMSE | 原 32 例 image MSE | 新 128 例窗口内 RMSE | 新 128 例 image MSE |
|---|---:|---:|---:|---:|
| 固定提示 1 次（训练前基线） | 0.00093958 | \(1.0490\times10^{-5}\) | 0.00116060 | \(1.49155\times10^{-5}\) |
| 提示 1 次 + CNN / map | 0.00083625 | \(7.5579\times10^{-6}\) | 0.00122343 | \(1.23093\times10^{-5}\) |
| 提示 1 次 + CNN / image-only | 0.00088447 | \(4.5326\times10^{-6}\) | 0.00121947 | \(7.77222\times10^{-6}\) |
| 固定提示 2 次（训练前基线） | 0.00087701 | \(4.36764\times10^{-6}\) | 0.00108984 | \(7.17842\times10^{-6}\) |
| 提示 2 次 + CNN / map | 0.00089086 | \(4.12901\times10^{-6}\) | 0.00110198 | \(1.02699\times10^{-5}\) |
| 提示 2 次 + CNN / image-only | 0.00084201 | \(2.50911\times10^{-6}\) | **0.00105193** | **\(5.27564\times10^{-6}\)** |

“新 128 例”是 seed 939031；上面几个选择曾依据最初 32 例探索，因此这个新集是更可信的复核。提示 1 次的网络虽然让原 32 例更好，在新 128 例**几何上差于未训练提示**；不能只报前半张表。提示 2 次后 image-only 网络在新 128 例仍比固定提示 2 次小约 3.5% 的窗口内 RMSE，并显著降低像素损失；这个增量真实但小，map-supervised 第三步则略有恶化，不能把更强监督自动当成更好结果。训练后的新集最小面积多在 0.05 floor 附近；在实测 float32 检查中仍全脸正向，但[浮点边界](18_unaligned_patch_and_fp32_margin.md)不由单次结果证明。

上述训练的 image-only 完整步在 Element L40 GPU1 上，中位约 25.0 ms（初始 1 提示）或 33.3 ms（先 2 提示），峰值 allocated 约 1.13 GB；包括两张图的编码、局部提示、F2 更新、512² 查询/warp、损失及网络 VJP。map 监督在 Turing A40 GPU0 上同结构的 2 提示步约 81.1 ms，不跨机器排名。这里**只有 257² 实际控制顶点**；新网络尚未输出或训练 1025² 控制图，也尚未对随机大/小窗口尺度、遮挡、自然图像和不同纹理族验证。几何真值误差仍远离 teacher 0，因此“可训练”并不等于已达到精确注册。
