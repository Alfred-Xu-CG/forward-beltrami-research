# 首轮 257² image-to-latent 训练：安全与恢复精度分开

## 实验问题

F1 的逐层正向 decoder 已能在已知目标顶点的反编码诊断中表示多频 P1 同胚。本实验检查一个**实际图像对输入**的 CNN 能否在相同 257² 控制网格上，经过多步反向训练，输出足够准确的 latent；以及安全层的梯度能否在训练全过程使用。不能把已知目标反编码与这个结果合并宣称“已学会”。

实现与可复算入口：[forward_p1_encoder.py](../../src/qcopt/neural_bijection/dense/forward_p1_encoder.py)、[phase7_train_forward_pyramid_image.py](../../tools/phase7_train_forward_pyramid_image.py)，数据生成复用 [Phase VI 合成脚本](../../tools/phase6_train_multisample_image.py) 的同名 high32 设置。网络输入是两张 512² 灰度图：固定图 \(I_{\rm fixed}\) 与待采样图 \(I_{\rm moving}\)。输出不是映射本身，而是 5² seed 上两次四着色更新及 9²、17²、33²、65²、129²、257² 六层安全更新的 latent 场；固定 P1 decoder 再给 257² 顶点像 \(Y\)。CNN 有 14,784 个可训练参数（width 16），输出头零初始化，所以初始映射为恒等。它有四个下采样上下文块，但当前没有显式跨图像相关体或位移迭代。

数据生成先随机创建平滑纹理移动图 \(I_{\rm moving}\)，再以三个随机系数形成已知边界固定的解析目标映射：
\[
F(x,y)=(x,y)+(a_x,a_y)\sin(2\pi x)\sin(2\pi y)
 +a_f(1,1)\sin(64\pi x)\sin(64\pi y).
\]
high32 分布中 \(a_x\in[.005,.015]\)、\(a_y\in[.010,.025]\)、\(a_f\in[-.002,.0025]\)。固定图通过 \(I_{\rm fixed}(x)=I_{\rm moving}(F(x))\) 的双线性采样生成。训练集 32 个样本，seed 55101；独立保留集 8 个样本，seed 99317；每步随机 batch 2，数据纹理和三个系数均不同。目标 \(F\) 不进入 image-only 损失或网络输入；只有 map-supervised 消融直接用目标坐标。边界坐标、真实控制点数和图像查询数各自记录，不能把 512² 图像称作 512² 控制网格。

网络预测的 257² P1 图在固定 512² 查询点上的插值记 \(Q(Y)\)。像素损失为
\[
L_{\rm image}=\frac1{B\,512^2}\sum_{b,q}
\bigl[I^{(b)}_{\rm moving}(Q(Y_b)(q))-I^{(b)}_{\rm fixed}(q)\bigr]^2.
\]
map-supervised 诊断另用 \(L_{\rm map}= (B\,512^2)^{-1}\sum_{b,q}\|Q(Y_b)(q)-F_b(q)\|_2^2\)。报告的 query-map RMSE 是 \(\sqrt{L_{\rm map}}\)，不是每坐标单独 RMSE。每一步在全部 131,072 个原三角面上检查最小归一化有向双面积 \(J_T>0\)；这属于运行时数值检查，数学安全性另由每级径向更新和边界不变量推导。Adam 学习率 0.003，float32。

## 实测

Turing 主机当时空闲 A40 GPU0，PyTorch 2.8.0+cu129；Element 主机当时空闲 L40 GPU1 用于 map-supervised 消融。300 与 1000 步 image-only 都从同一零初始化重新开始，**不是** 300→1000 的续训。保留集初始（恒等）image MSE 为 0.0090506、query-map RMSE 为 0.0111056。

| 监督 / 步数 | 保留 image MSE | 保留 query-map RMSE | 保留最小 \(J_T\) | 训练步中位时间 | 峰值 CUDA allocated | 总训练时间 |
|---|---:|---:|---:|---:|---:|---:|
| 仅图像 / 300 | 0.00122938 | 0.00399655 | 0.67325 | 88.76 ms | 383.57 MB | 27.19 s |
| 仅图像 / 1000 | 0.000786528 | 0.00336893 | 0.78267 | 111.1 ms | 383.57 MB | 113.14 s |
| 真 query-map 监督 / 1000 | 0.0008609 | 0.00346589 | 0.77133 | 41.94 ms | 未在摘要中保存 | 42.73 s |

两台机器的训练步时间不作横向速度排名；它们使用不同 GPU/软件和运行时。三个实验训练过程未出现非正向控制面、非有限损失或反传故障。image-only 1000 步的训练集 image MSE 为 0.000866834；保留集仍更低，不能仅根据保留/训练差异断言“泛化很好”，两组目标与纹理有限且生成器相同。检查点存于本目录的 [checkpoints](checkpoints/)。

这个已训练网络**没有达到**旧 Phase VI A8 在其相应 high32 8 例上的 image MSE \(1.84785\times10^{-5}\) 和 map RMSE 0.00040936。旧模型使用额外图像反馈机制、训练历史和不同架构，虽然同属 high32 生成器，不能仅把这两个数字当成严格匹配预算的排名。更重要的是，当前 F1 decoder 的已知目标 oracle 能在 257²/1025² 达到近机器精度，而 1000 步 image/map 训练的误差依然高两个以上数量级；该差距明确表明“这些目标的几何不可表示”不是当前主要解释。可能瓶颈是图像配准信号、CNN 归纳偏置、逐层 latent 条件数、安全层的梯度，或优化策略；尚不能确定其中唯一主因。

下一轮需做三个解耦实验：① 用已知目标生成 teacher latent，检查 encoder 能否学习其多尺度模式；② 同一模型作真实图像-only 与地图监督的多种初始化/逐级训练，测量每级更新贡献；③ 在同一数据划分和控制尺度上与 A8 进行严格匹配的速度、显存与精度 Pareto 比较。以上未完成前，不宣称 F1 是有效的 image registration layer。

## 安全图像反馈：几何 decoder 后的明确附加模块

首轮 CNN 的主要差距在图像推断，而非已测目标的几何表达。为定位该差距，另接一个可微的局部光度更新：当前 P1 图在固定图像位置取样移动图，依照局部图像残差和约 \(3\times3\) 的图像梯度窗口求原始二维更新提示；可选地只保留前 16 个正弦模式，再将提示送入带统一面积下界的四着色顶点安全更新。后者直接更新当前**固定 257² 网格顶点**，所有反传仍穿过 P1 decoder、图像采样与反馈步骤。它不是原 F1 latent 网络独自推断的成绩；局部光度提示借用了先前 Phase VI 已存在的机制。

在冻结原 1000 步 CNN、完全不续训时，同一 8 例 high32 保留集有：

| 冻结 CNN 后的反馈 | 保留 image MSE | query-map RMSE | 最小 \(J_T\) |
|---|---:|---:|---:|
| 0 pass | 0.000786528 | 0.00336893 | 0.78267 |
| 无频率过滤，2 pass | 0.00002164 | 0.001914 | 0.04998 |
| 16 正弦模式，2 pass | 0.00007370 | 0.001002 | 0.2257 |
| 16 正弦模式，4 pass | 0.00003824 | 0.0007381 | 0.04999 |

上述参数是在这个保留集上**探索性检查**的，故不应称为盲测胜出。无频率过滤能迅速降低像素误差，但 map RMSE 仍高，提示发生了纹理追踪与几何精度分离。随后从原 CNN 的 1000 步检查点续训，把两个 16 模式反馈 pass 纳入完整计算图；先以学习率 0.001 训练 300 步，再以 0.0005 训练 1000 步。最终在原 8 例上的 image MSE \(2.97666\times10^{-5}\)、query-map RMSE \(7.2459\times10^{-4}\)、最小 \(J_T=0.27961\)；最后阶段中位训练步 145.9 ms，峰值 PyTorch CUDA allocated 约 545.1 MB。相同最终检查点在新生成 seed 939031 的 128 例上取得 image MSE \(3.41238\times10^{-5}\)、map RMSE \(7.6633\times10^{-4}\)、最小 \(J_T=0.11106\)。这个新集检查减少了单一 8 例偶然性，却不能撤销前面对反馈参数使用原保留集调试的事实。完整训练后 decoder 加反馈仍未达到已知目标 oracle 的精度，也未作相同训练预算的 A8 公平比较。

## F2 patch 图像编码器：同分布的第二个正向机制

新 [PatchPyramidImageEncoder](../../src/qcopt/neural_bijection/dense/forward_p1_encoder.py) 使用同样的两张灰度图和 width 16 CNN 主体，但每个尺度输出四个交错 patch pass 的位移 latent，送进 [F2 固定网格 decoder](../../src/qcopt/neural_bijection/dense/patch_field.py)。它有 15,192 个可训练参数；seed 为 17²，随后 33²、65²、129²、257²，每级四次 patch 更新，共 20 个 patch pass。其输入、损失、32/8 样本划分、512² 图像查询、257² **实际控制网格**和拓扑检查与上文相同。与 F1 不同的还有 seed 大小、pass 数及输出 latent 数，所以以下只是机制诊断，不是严格的同参量消融。

Turing 空闲 A40 GPU0、float32、batch 2、image-only 损失下，零初始化训练 300 步（Adam 学习率 0.003），再从其检查点续训 700 步（0.001）。两个阶段合计 1000 步后，8 例保留集 image MSE **0.000564905**、query-map RMSE **0.00283170**、最小 \(J_T=0.23503\)，最近 700 步中位训练步 111.3 ms，峰值 CUDA allocated 435.39 MB。300 步中途的对应数据为 0.000909676、0.00349115、0.42525。训练中全脸检查未发现非正向面。这个 CNN 明确可端到端反传，却远离已知目标的 F2 几乎精确表示，不能说高分辨率图像推断问题已解决。

冻结这 1000 步 F2 CNN，再使用上面同一个 16 模式光度反馈模块，可作如下探索性对照：

| F2 冻结后反馈 pass | 保留 image MSE | query-map RMSE | 最小 \(J_T\) |
|---:|---:|---:|---:|
| 0 | 0.000564905 | 0.00283170 | 0.23503 |
| 1 | 0.000195924 | 0.00161246 | 0.16847 |
| 2 | 0.000138224 | 0.00133079 | 0.12679 |
| 4 | 0.000095386 | 0.00110360 | 0.13688 |

F2 一样能从反馈获益，但它在四 pass 后的 map 误差仍高于 F1 的四 pass 探索结果；不能由此推断 patch 原语欠表达，因为两个预训练 CNN、seed 与潜变量不同。

已进一步从 F2 无反馈的 1000 步检查点开始，将两个 16 模式反馈 pass 放入可微图像损失中联合续训 500 步，Adam 学习率 0.001。原 8 例保留集的 image MSE 降为 **\(3.68690\times10^{-5}\)**、map RMSE **0.000763906**、最小 \(J_T=0.18367\)，中位训练步 176.3 ms，峰值 CUDA allocated/reserved 592.95/652.21 MB。新生成 seed 939031 的 128 例经过同一冻结检查点与两 pass 后为 image MSE **\(3.65491\times10^{-5}\)**、map RMSE **0.000765934**、最小 \(J_T=0.10782\)。这说明 F2 的完整图像到 latent 到 P1 输出链可以持续端到端训练，且不只是 8 例的偶然值；但反馈参数先前曾在 8 例上调试，128 例只是新样本复核，不是完全预注册外部数据。检查点位于 [checkpoints](checkpoints/)。

当前 F1+反馈与 F2+反馈在同生成器上的误差已接近；它们的训练步数、初始模型和计算量还不严格匹配，不能宣称谁的原语更优。图像反馈主要沿用 Phase VI 机制，其贡献必须与本轮 coarse-to-fine decoder 分开。下一步在 1025² **实际控制网格**和新的目标/图像分布上核对梯度、内存、速度与几何精度，并作相近精度下的 A8/S 对照。
