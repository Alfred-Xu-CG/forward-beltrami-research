# 首轮 257² image-to-latent 训练：安全与恢复精度分开

## 实验问题

F1 的逐层正向 decoder 已能在已知目标顶点的反编码诊断中表示多频 P1 同胚。本实验检查一个**实际图像对输入**的 CNN 能否在相同 257² 控制网格上，经过多步反向训练，输出足够准确的 latent；以及安全层的梯度能否在训练全过程使用。不能把已知目标反编码与这个结果合并宣称“已学会”。

实现与可复算入口：[forward_p1_encoder.py](../../src/qcopt/neural_bijection/dense/forward_p1_encoder.py)、[phase7_train_forward_pyramid_image.py](../../tools/phase7_train_forward_pyramid_image.py)，数据生成复用 [Phase VI 合成脚本](../../tools/phase6_train_multisample_image.py) 的同名 high32 设置。网络输入是两张 512² 灰度图：固定图 \(I_{\rm fixed}\) 与待采样图 \(I_{\rm moving}\)。输出不是映射本身，而是 5² seed 上两次四着色更新及 9²、17²、33²、65²、129²、257² 六层安全更新的 latent 场；固定 P1 decoder 再给 257² 顶点像 \(Y\)。CNN 有 14,784 个可训练参数（width 16），输出头零初始化，所以初始映射为恒等。它有四个下采样上下文块，但当前没有显式跨图像相关体或位移迭代。

数据生成先随机创建平滑纹理移动图 \(I_{\rm moving}\)，再以三个随机系数形成已知边界固定的解析目标映射：
\[
F(x,y)=(x,y)+(a_x,a_y)\sin(2\pi x)\sin(2\pi y)
 +a_f(1,1)\sin(64\pi x)\sin(64\pi y).
\]
high32 分布中 \(a_x\in[.005,.015]\)、\(a_y\in[.010,.025]\)、\(a_f\in[-.002,.0025]\)。固定图通过 \(I_{\rm fixed}(x)=I_{\rm moving}(F(x))\) 的双线性采样生成。训练集 32 个样本，seed 55101；独立保留集 8 个样本，seed 99317；每步随机 batch 2，数据纹理和三个系数均不同。目标 \(F\) 不进入 image-only 损失或网络输入；只有 map-supervised 消融直接用目标坐标。边界坐标、真实控制点数和图像查询数各自记录，不能把 512² 图像称作 512² 控制网格。

网络预测的 257² P1 图在固定 512² 查询点上的插值记 \(Q(Y)\)。像素损失为
\[
L_{\rm image}=\frac1{B\,512^2}\sum_{b,q}
\bigl[I^{(b)}_{\rm moving}(Q(Y_b)(q))-I^{(b)}_{\rm fixed}(q)\bigr]^2.
\]
map-supervised 诊断另用 \(L_{\rm map}= (B\,512^2)^{-1}\sum_{b,q}\|Q(Y_b)(q)-F_b(q)\|_2^2\)。报告的 query-map RMSE 是 \(\sqrt{L_{\rm map}}\)，不是每坐标单独 RMSE。每一步在全部 131,072 个原三角面上检查最小归一化有向双面积 \(J_T>0\)；这属于运行时数值检查，数学安全性另由每级径向更新和边界不变量推导。Adam 学习率 0.003，float32。

## 实测

Turing 主机当时空闲 A40 GPU0，PyTorch 2.8.0+cu129；Element 主机当时空闲 L40 GPU1 用于 map-supervised 消融。300 与 1000 步 image-only 都从同一零初始化重新开始，**不是** 300→1000 的续训。保留集初始（恒等）image MSE 为 0.0090506、query-map RMSE 为 0.0111056。

| 监督 / 步数 | 保留 image MSE | 保留 query-map RMSE | 保留最小 \(J_T\) | 训练步中位时间 | 峰值 CUDA allocated | 总训练时间 |
|---|---:|---:|---:|---:|---:|---:|
| 仅图像 / 300 | 0.00122938 | 0.00399655 | 0.67325 | 88.76 ms | 383.57 MB | 27.19 s |
| 仅图像 / 1000 | 0.000786528 | 0.00336893 | 0.78267 | 111.1 ms | 383.57 MB | 113.14 s |
| 真 query-map 监督 / 1000 | 0.0008609 | 0.00346589 | 0.77133 | 41.94 ms | 未在摘要中保存 | 42.73 s |

两台机器的训练步时间不作横向速度排名；它们使用不同 GPU/软件和运行时。三个实验训练过程未出现非正向控制面、非有限损失或反传故障。image-only 1000 步的训练集 image MSE 为 0.000866834；保留集仍更低，不能仅根据保留/训练差异断言“泛化很好”，两组目标与纹理有限且生成器相同。检查点存于本目录的 [checkpoints](checkpoints/)。

这个已训练网络**没有达到**旧 Phase VI A8 在其相应 high32 8 例上的 image MSE \(1.84785\times10^{-5}\) 和 map RMSE 0.00040936。旧模型使用额外图像反馈机制、训练历史和不同架构，虽然同属 high32 生成器，不能仅把这两个数字当成严格匹配预算的排名。更重要的是，当前 F1 decoder 的已知目标 oracle 能在 257²/1025² 达到近机器精度，而 1000 步 image/map 训练的误差依然高两个以上数量级；该差距明确表明“这些目标的几何不可表示”不是当前主要解释。可能瓶颈是图像配准信号、CNN 归纳偏置、逐层 latent 条件数、安全层的梯度，或优化策略；尚不能确定其中唯一主因。

下一轮需做三个解耦实验：① 用已知目标生成 teacher latent，检查 encoder 能否学习其多尺度模式；② 同一模型作真实图像-only 与地图监督的多种初始化/逐级训练，测量每级更新贡献；③ 在同一数据划分和控制尺度上与 A8 进行严格匹配的速度、显存与精度 Pareto 比较。以上未完成前，不宣称 F1 是有效的 image registration layer。
