# 跨 patch seam 的二维光滑同伦目标：257²/1025² 一轮每级的实际检验

## 独立目标与 teacher

为了检验[统一光滑同伦逼近命题](23_uniform_isotopy_multilevel_approximation.md)确实作用于**不固定内部 patch 边界**的两坐标映射，定义独立解析目标

\[
F_a(x,y)=
\begin{pmatrix}
x+a\sin(2\pi x)\sin(\pi y)\\
y-0.8a\sin(\pi x)\sin(2\pi y)
\end{pmatrix}.
\]

位移在整个外边界为零，但在 16-cell 或其他内部 patch seam 一般**不为零**；两个坐标均变化，故不是单轴 fiber 例子。用 $F_{a,t}=(1-t)\mathrm{id}+tF_a$ 作明确的光滑时间路径。对 $a\le0.08$ 可直接逐项给出统一连续界：$\det DF_{a,t}\ge(1-2\pi a)(1-1.6\pi a)-0.8\pi^2a^2$，在 $a=0.08$ 时仍为 0.246818；$\|DF_{a,t}\|_2\le1+\pi a\sqrt{8.2}<1.72$、$\operatorname{Lip}(DF_{a,t})\le\pi^2a\sqrt{41}<5.06$、$\|\partial_tF_{a,t}\|_2\le a\sqrt{1+0.8^2}<0.103$。因此 $a\le0.08$ **确实满足**[定理](23_uniform_isotopy_multilevel_approximation.md)的统一光滑同伦假设且 $\beta=0.05<m/4$；但定理的保守充分常数未必保证我们实际选的 17² 粗 seed。$a=0.14$ 的上述简单行列式下界为负，所以本文仅把它作为目标细面正向、但未由该保守解析界涵盖的压力样本；不能把采样正向反推成全域连续定理假设。

选 17² 固定粗控制点。先把 $t$ 等分为 4 或 8 份，逐份给四颜色 seed 一组从解析相邻顶点差得到的 $\operatorname{atanh}$ latent；每次 dyadic 细化时在**新顶点**设从解析 $F_a$ 与父 P1 精确延拓之差得到的 latent，旧顶点设零。每级恰好一轮四颜色更新，最终是一张 257² 或 1025² 固定原网格 P1 图，**没有连续映射复合**。该 teacher 构造知道目标函数，并不表示已学会 image-to-latent。

实现和复现入口为 [脚本](../../tools/phase7_verify_isotopy_pyramid.py) 与 [前向层](../../src/qcopt/neural_bijection/dense/forward_p1_pyramid.py)。257²/1025² 行使用 AI 主机 A6000 GPU2，2049²/4097² 行使用同主机空闲 A6000 GPU7；PyTorch 均为 2.5.1+cu124、batch1、float64。每行输出对全部 latent 的随机 cotangent VJP。时间为同步后的 forward+VJP 中位，不含解析 teacher 生成或目标评价；peak 为 CUDA allocated，不是 reserved。向量 RMSE 是 $\sqrt{V^{-1}\sum_i\|Y_i-F_a(x_i)\|_2^2}$，max error 为所有坐标绝对差的最大值，最小 $J$ 是全部目标/输出面中 $(\text{映后有向双面积})/h^2$ 的最小值。

所有列出的 VJP 张量有限，每层以及每个粗 seed latent 组至少有一个非零梯度；在 $a=0.14$、8 seed 轮时最后一级 latent 的绝对最大梯度约 $4.71\times10^{-9}$，这**不是**图像训练已成功的证据。257² 与 1025² 顶点数约 16 倍、allocated 峰值也约 16 倍；时间只增长约 1.6 倍，因为小问题被启动/调度开销主导，不能把它当作精确的时间复杂度拟合。理论的 $O(V)$ work 与这个内存趋势相容，但单机两点无法独立证实渐近复杂度。

2049² 与 4097² 行仍是实际控制顶点和全 VJP，并未增加图像训练；在同一 AI 主机的另一个空闲 A6000 GPU7 上运行，软件环境相同。4097² 有 16,785,409 顶点、约 3,355 万原三角面，不能将其理解为 query 数。1025²、2049²、4097² 的峰值约按顶点数四倍放大，分别 1.391、5.549、22.183 GB；后两行说明此实现在 48 GB 卡上仍可运行，**不是**一般网络训练在该尺度的显存保证。

新增的 [CertifiedForwardP1Pyramid](../../src/qcopt/neural_bijection/dense/multilevel_forward_p1.py) 用和[联合层](22_numeric_certified_joint_layer.md)相同的实际输出符号筛选；不通过时整样本回退单位图，因而在指定 IEEE 模型下把最终 binary-float 顶点也纳入拓扑契约。在 $a=0.08$ 的 1025² 教师测试中，启用筛选后误差与 VJP 不变、118.37 ms、峰值 1.408 GB；4097² 同样未回退、880.97 ms、峰值 22.452 GB。两个时间与无筛选运行处于同一噪声量级，不从这些少量重复推断筛选绝对零开销。小网格测试逐项核对筛选对合法映射的输出和梯度恒等。

$a=0.14$ 的 4 轮 seed 给出真实的失败样本：目标本身仍面正向，最终输出也面正向，**但**粗层有局部安全缩放，残差经后续每级只改新顶点而无法再纠正旧粗顶点，所以最终 RMSE $3.715\times10^{-4}$。增加粗 seed 到 8 轮，其他流程不变，即恢复至机器精度。它说明“每级一轮”命题的粗 seed 轮数必须依赖目标类的强度/余量，不能预先用一个未经证明的小常数替代。更强变形、低 Jacobian 余量可能需要更细的初始粗网格或更多 seed 轮；实验没有覆盖一般 homeomorphism。

本实验的 teacher 解码和梯度已经达到 1025² 实际控制网格，且目标位移跨内部 seam。下一步瓶颈是**用图像预测这些多尺度 latent**，而不是再证明解析 teacher 存在；还需对全域连续 $F_{a,t}$ 的 $m,L,K,M$ 做显式界，检验所证充分条件的保守程度，以及在浮点输出上加入[数值符号筛选](22_numeric_certified_joint_layer.md)。
