# 同一个4097²前向层：图像损失与坐标损失的判别性对照

## 问题与受控变化

[4097²空间修正头](66_trained_4097_spatial_correction_negative_result.md)用纯图像均方差训练，确能经全部原控制顶点反传，却未比两标量增益显著降低 map RMSE。需要区分两种解释：A，最后一级空间修正根本无法表示需要的几何差；B，层有表示能力，但纯图像损失在本任务上给出的更新方向不等于真值坐标方向。这里保持架构、32张训练图像、训练种子55101、batch1、500步、Adam学习率.001、初始[已训练细级两增益](checkpoints/phase7_extra_gains_4097_float32_train500.pt)、float32安全几何、4097²原控制网格与高通17窗口不变，**只把训练损失换成坐标损失**

$$
\mathcal L_{\mathrm{map}}=\frac{1}{512^2}\sum_{q\in Q}
\left\|f_{F_{4097}}(q)-F_*(q)\right\|_2^2.
$$

$F_*$ 是合成数据生成时已知的真值映射，**只用于这次诊断训练和评估**；图像损失实验从未用它更新参数。数值实现把 $\mathcal L_{\mathrm{map}}$ 乘 $10^6$ 后交给 Adam，以免梯度接近优化器 epsilon；正的常数缩放不改变该损失的极小点。一个5步小试确认梯度非零、训练样本损失下降，再执行完整500步。训练时仍做全部原面的拓扑筛选，500/500步被接受；中位训练步 .626秒，CUDA allocated峰值12.265GB，AI远程空闲RTX A6000、PyTorch2.5.1+cu124。保存[坐标监督权重](checkpoints/phase7_extra_spatial_4097_map_train500.pt)。其效果不是“无需真值的图像注册性能”，而是对可学性/损失函数的诊断。

## 新样本及载波族结果

两模型都在相同128例、相同4097²网格上输出并对**33,554,432个原三角面**检查；下表采用真正未用于本次诊断设计的 seed20270113。`high128` 是共同对角高频正弦位移，`high128_tri` 用三个不同方向组合的高频载波，`high128_tiles` 用16个局部窗口调制同类高频载波；后二者训练时没出现。纹理生成族相同。map RMSE 是512²查询点的二维坐标向量均方根；image MSE 是固定图像与移动图像按预测图重采样后的像素均方差。指定 high128 mode RMSE 的定义是两坐标位移在 $\phi(x,y)=\sin(256\pi x)\sin(256\pi y)$ 上的投影系数误差的向量均方根；在 `tri`/`tiles` 中它**只测这一个指定载波**，不是全部高频位移误差。

| 128例测试族 | image-only map / mode RMSE | map-supervised map / mode RMSE | image-only / map-supervised image MSE | 两者通过数 |
|---|---:|---:|---:|---:|
| high128 | .00048714 / .00014399 | **.00046744 / .00010802** | 2.590e-8 / 4.071e-7 | 各128/128 |
| high128_tri | .00044946 / .00003990 | **.00044281 / .00002402** | 5.760e-9 / 1.365e-7 | 各128/128 |
| high128_tiles | .00043150 / .00000532 | **.00042945 / .00000362** | 4.999e-9 / 1.044e-7 | 各128/128 |

同一正向层在可用坐标真值训练后，high128新测试组 map RMSE下降约4.0%，指定模态误差下降约25%；对未训练过的三模态、局部16包目标也有较小但同向的几何收益。然而图像损失提高约16—24倍。这不是拓扑退化：所有样本输出仍通过逐面筛选，三个目标族的最小归一化有向面面积 $J$ 分别约.04918、.04923、.04910（坐标监督模型；以存储float32坐标升到float64重算）。这些数低于名义.05一点，详见[float32证书语义](63_float32_certified_geometry_tradeoff.md)。

## 解释与下一步

观察支持一个**有限的可学性结论**：在相同网络/安全更新结构中，确有一些先前纯光度训练没有学到的几何改进方向；因此不能把全部误差归因于“前向细网格拓扑层完全无表达能力”。但几何改进只有数个百分点，不能推断该最后一级卷积头足以覆盖任意细部同胚或已经充分逼近真值。更高的 image MSE 说明在当前单通道纹理、双线性成像和512²采样下，纯光度最优方向与坐标真值方向不一致；也可能涉及局部极小值与两种优化轨迹，尚未隔离成严格的信息论不可能性命题。

从应用角度，真值坐标往往不可得。下一步应在**不把真值当作真实训练输入**的前提下研究可观测的附加约束：例如多独立图像通道/纹理、跨图像对一致性，或带明确假设的局部不确定性建模；并用同一个4097²输出和独立坐标指标验证。若仍只用同一张图像的 MSE 更激进地训练，本文的对照提示可能继续降低像素损失而不明显提高几何准确度。安全拓扑、表达性和从图像辨识形变是三个不同问题。
