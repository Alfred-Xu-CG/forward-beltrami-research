# 百万控制顶点的双分量细节：F1 直接 latent 拟合而非仅手工模式

## 为什么需要一个纤维层做不到的目标

[正边增量与顶点势层](15_potential_fiber_conditioning.md)在弱细节上又快又可训练，但固定 \(f_y=y\)，所以其精度不能证明一般二维形变能力。本实验在相同强剪切粗基图上加入**同时影响 x、y** 的独立解析高频位移，然后直接优化 F1 的每个细网格内部顶点两分量 latent；没有给 decoder 指定正弦模式方向、窗口或真实系数。该目标超出任何单独水平纤维层，但仍有可核查的固定 P1 拓扑。

令 \(s=0.28\)、\(H(x,y)=\sin(256\pi x)\sin(256\pi y)\sin^2(\pi x)\)，\(G_s=(x+s\sin^2(\pi x)\sin(2\pi y),y)\)，独立目标取
\[
T(x,y)=G_s(x,y)+aH(x,y)(1,1),\qquad a=2\times10^{-5}.
\]
边界逐点不变；在 257² 控制顶点上 \(H=0\)，在 1025² 顶点上不全为零。\(G_s\) 的导数矩阵写成 \(\left(\begin{smallmatrix}A&B\\0&1\end{smallmatrix}\right)\)，满足 \(1-s\pi\le A\le1+s\pi\)、\(|B|\le2\pi s\)。同分量细节使 determinant 的二次项恰好抵消：
\[
\det DT=A+aA\,\partial_yH+a(1-B)\partial_xH.
\]
由于 \(|\partial_xH|\le257\pi\)、\(|\partial_yH|\le256\pi\)，全系数盒 \(|a|\le2\times10^{-5}\) 都有
\[
\det DT\ge1-s\pi-|a|\big[(1+s\pi)256\pi+(1+2\pi s)257\pi\big]
>0.045.
\]
规则 SW–NE 网格每面 P1 导数的 x/y 分量都是沿同方向网格边的差商，服从相同导数上界，故**目标自身的固定 1025² P1 采样图**也全脸正向；固定一一对应的边界给出全局同胚。实际 float32 所有 2,097,152 面最小归一化 \(J_T=0.113038\)，比保守解析下界大。上述保证来自目标公式，独立于待测 F1 decoder。

## 输入、输出和训练设置

从强剪切 \(G_s\) 的解析 1025² P1 采样图反求边密度 logit，再只保留 257 侧长的 **65,280 个**粗 logit，经双线性 log-density 插值与正边增量层生成安全基图 \(B\)。这一步是只用于隔离细层的 oracle，尚未从图像训练得到。相对最终目标 \(T\)，基图的 1025² 全顶点向量 RMSE 为 \(1.02681\times10^{-5}\)。

F1 细层输入是 \(z\in\mathbb R^{1023\times1023\times2}\)，共 2,093,058 个**真实细控制自由度**。每个内部顶点提出最多 \(2h\tanh z_i\) 的二维位移，按四个互不共面的顶点颜色依次更新；每个子步用六个相邻面的面积裕量限制不利运动，继承固定边界并保证所有面继续正向。这里取 \(h=1/1024\)、安全比例 0.85、不施加固定 0.05 的绝对 \(J\) 下界。输出是**同一张 1025² SW–NE 三角网格**上的顶点表及其 P1 延拓；没有解整图线性系统，也没有对地图复合后重插值。由于当前小目标余量充分，理论 teacher latent \(z_i=\operatorname{atanh}((T_i-B_i)/(2h))\) 在这一个四着色 pass 未被安全比例截断，数值上逐顶点重现目标。这证明此样本的 decoder 表示性，不代表网络自动学得 teacher。

实际优化从 \(z=0\) 开始，不提供 teacher：最小化 \(10^6\) 倍的全部 1025² 顶点欧氏平方均值，Adam 初始学习率 0.01、余弦退火 400 步、eps \(10^{-12}\)，batch1、float32；不使用图像像素损失、目标模式系数监督、折叠修复或大系统近似解。[复现实验](../../tools/phase7_fit_dense_f1_detail.py)。

## 结果与解释边界

Turing A40 GPU0、PyTorch 2.8，400 步内全顶点向量 RMSE 从 \(1.02681\times10^{-5}\) 降至 **0（同一 float32 顶点表示逐元素相等）**，最优步 381；最终全脸最小 \(J_T=0.113038>0\)。teacher 一 pass 也给 RMSE 0。用与训练损失无关的随机 cotangent 再做一次 VJP，结果逐元素有限且最大绝对值 \(4.83\times10^{-9}\)（损失取全输出平均，数值自然很小）；因此“训练末态误差 0”不等于反传路径消失。热启动后每个仅顶点监督的完整 forward+VJP+Adam 步中位 0.0219 秒，峰值 CUDA allocated 0.576 GB；**不含**图像编码器与 512² 图像取样。

另一个 x-only 高细节目标 \(G_{0.28}+10^{-4}H(1,0)\) 在同一粗基图、2,093,058 fine latent、400 步与学习率下，也得到 float32 RMSE 0、最小 \(J_T=0.083374\)、单步中位约 0.0220 秒、峰值 allocated 约 0.547 GB。它便于与同基图的[纤维细势实验](15_potential_fiber_conditioning.md)比较。纤维势在 x-only 目标更快、用约一半 fine latent，但根本不能直接表达这里的 y 高频分量；因此不能从速度表简单选一个“所有目标上更好”的胜者。

此结果对下一步很重要：至少在有余量、位移幅度约 \(h\) 以下的**独立双分量高频目标**上，一次稠密 F1 局部正向 pass 既能保原网格 P1 拓扑，也能从零直接优化到数值精确。它**没有**解决较大二维非纤维粗变形从图像推断、固定有限层数覆盖大范围 homeomorphism，或在最薄三角形附近保持同样梯度与速度。对于图像配准，更严格的下一关是用固定/移动图像而非真 map 顶点作损失，并在新纹理与新目标上评价 map 误差和拓扑；这不能由本顶点监督试验代替。
