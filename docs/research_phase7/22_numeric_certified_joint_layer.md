# 粗 patch + 细顶点统一层：混合精度、数值拓扑筛选与成本

## 输入、输出与两个不同层次的保证

实现 [`CoarsePatchFineVertexP1Layer`](../../src/qcopt/neural_bijection/dense/multilevel_forward_p1.py) 的输入是两个网络可预测张量。首个是形状 `B×255×255×2` 的粗层 latent，第二个是 `B×1023×1023×2` 的细层 latent；本文实验中它们都是 float32。输出是 `B×1025×1025×2` 的 float64 顶点坐标。固定网格有 1,050,625 个控制顶点和 2,097,152 个 SW–NE 三角形；这不是 1025² 次图像查询。两个 latent 合计 2,223,108 个标量/样本，其中细层 2,093,058 个。层内没有随网格规模增长的线性系统求逆。

粗层在 257² 顶点上用 16-cell、两个四错位循环的 residual patch 更新，精确算术约束每个三角形的归一化有向面积 $J\ge0.05$。把其连续 P1 函数在两次二分后的顶点上**精确求值**，得到 1025² 初值。最后用四颜色、单顶点径向局部更新处理细 latent；每个面在同一颜色子步至多有一个动点。细层限制采用**绝对**有向双面积下界 $0.05/1024^2$，而不是每次继承当前最薄面的 5%：后者经过粗层会把可能的下界再乘 0.05，得到 0.0025。整个层的精确算术归纳仍是固定细网格单张 P1 同胚，前提是有限 latent 与算法公式定义域。

计算时把两个 float32 latent 转成 float64；自动微分的梯度经类型转换传回 float32 latent。输出保持 float64，不再向 float32 舍入。**精确算术证明不保证 IEEE 坐标正向。** 因此默认对实际输出的每个三角形执行独立的保守符号筛选；某一 batch 样本不通过时，整张样本输出改为精确单位映射。回退样本对 latent 的梯度为零；在接受/拒绝分界处该离散选择不可微，所以不能把它叫作全域光滑层。已通过的样本对原解码器正常反传。这是运行时的输出契约筛选，不能拿它替代 decoder 的表达与训练证据。

## 面符号筛选的数值模型

对三角形坐标 $a,b,c$ 计算 $p=(b_x-a_x)(c_y-a_y)$、$q=(b_y-a_y)(c_x-a_x)$、$d=p-q$。检查所有输出分量有限且绝对值不超过 2、四条外边界严格等于预存单位边界，并要求每个面满足

\[
\widehat d>16u\bigl(|\widehat p|+|\widehat q|\bigr)+64\,\mathrm{tiny},
\]

其中 $u$ 是输出 dtype 的机器 epsilon（并非 unit roundoff，因此常数更保守），`tiny` 是最小正 normal 数。两个边差、两个乘积与最后的减法在普通 IEEE 正常舍入模型下产生至多约 $4u(|\widehat p|+|\widehat q|)$ 的误差，所用 16u 留余量；坐标限制 $[-2,2]$ 使 subnormal/flush-to-zero 的绝对扰动也被 64 tiny 的余量包住。若中间乘积溢出，非有限判定不会满足严格不等式。于是**在上述运算模型中**，通过筛选的 binary-float 坐标作为精确实数时有正面积，连同精确外边界给出全局 P1 同胚；没通过则输出 dyadic 单位映射。对启用不符合此模型的编译器重排、非 IEEE 后端或未来硬件，仍须独立核对；这里没有声称跨任意后端的形式验证。

小网格自动化测试还故意造出一个折叠样本，验证批内仅该样本回退、梯度清零，另一合法样本保留非零梯度。小网格粗/细联合测试验证 float32 latent→float64 输出、边界、所有面面积及两个 latent 的有限非零 VJP。当前 Phase VII 相关测试合计 38 项（见提交后的实际测试输出）。

## 真实 257→1025 控制网格：同机混合精度对照

运行 [`phase7_profile_joint_precision.py`](../../tools/phase7_profile_joint_precision.py)，AI 主机 A6000 GPU2、PyTorch 2.5.1+cu124，batch1，CUDA 同步计时 20 次中位；计时包含 decoder 前向和对两个 latent 的一次随机 cotangent VJP，不包含编码 CNN、纹理采样或输入传输；peak 为 `torch.cuda.max_memory_allocated`，不是 reserved。目标是独立解析两维局部窗口位移 + 128 周期微幅高频扰动，详见[细网格拟合协议](19_residual_patch_multilevel_decoder.md)。粗 teacher 和细 teacher 分别从解析目标及精确延拓残差构造，再缩放为 float32 latent。向量 RMSE 定义为 $\sqrt{V^{-1}\sum_i\|Y_i-T_i\|_2^2}$，最小 $J$ 对全部细网格面计算。

| 层计算 / latent / 筛选 | 目标 RMSE | 目标最小 J | forward+VJP 中位 | peak allocated | 20 个极端随机样本最小 J 范围 | 回退数 |
|---|---:|---:|---:|---:|---:|---:|
| float64 / float32 / 关 | 3.71e-12 | 0.598808 | 74.69 ms | 1.427 GB | 0.04999999999970–0.04999999999979 | 不适用 |
| float64 / float32 / 开 | 3.71e-12 | 0.598808 | 70.69 ms | 1.427 GB | 0.04999999999970–0.04999999999979 | 0/20 |
| float32 / float32 / 开 | 0 | 0.598785 | 56.75 ms* | 0.841 GB | 0.049844–0.049885 | 0/20 |

星号：float32 行只计时 10 次，不能把 56.75 与 70.69 ms 当作严格配对的硬件收益；不同 run 的 float64 关/开值反向波动，说明当前测量噪声大于可见筛选开销。float32 的 teacher RMSE 为 0 是**相对于同 dtype 解析采样**，不是连续目标的零误差。随机 latent 各坐标为 (5N(0,1))，20 个样本由固定 seed 1949 生成；其全部面仍正向，但这只是抽样观察。以前无绝对细 floor 的深层 float32 链曾出现负面积，不能用本表的 20/20 推广为纯 float32 无条件安全。

两种 float64/float32 混合运行均使粗/细 VJP 有限非零。启用筛选的结果没有回退，因此能保持该目标的精度和梯度；有回退时训练信号会断，仍须报告实际训练分布中的回退比例。相较于先前仅有精确算术证明，这个封装把**实际输出浮点坐标的拓扑检查**接入了网络层，同时暴露其局限：高分辨率网络编码器尚未在该封装上端到端训练，1.427 GB 是 decoder+VJP 而不是整个 image-to-latent 系统。
