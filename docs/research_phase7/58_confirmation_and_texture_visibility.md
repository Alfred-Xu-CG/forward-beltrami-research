# 冻结结构后的确认集与弱纹理边界

## 为什么另设确认集

[可训练反馈层](57_high128_trainable_feedback_layer.md)最初在128例 seed939031 上评价；我们随后看着那批结果选择了“先训粗层及增益，再冻结它们、只训最后1025²修正网络”的两阶段结构。因此 seed939031 虽然没有进入任何梯度训练，却已参与架构选择，不能当最终未触碰测试。这里在结构、训练权重、窗口 $w=3$、每级2轮、评价代码全部固定后，另用此前未使用的 **128例 seed20261017** 作一次同分布确认。两批解析地图均是[high128 目标族](09_high128_control_detail.md)独立系数抽样；512²图像查询与1025²控制网格严格区分。

评价指标与[前文](57_high128_trainable_feedback_layer.md)一致：image MSE 是移动图经预测 P1 地图采样后的像素均方差；map RMSE 是512²查询位置预测与解析真坐标的二维向量均方根；模式误差是在 $H(q)=\sin(256\pi q_x)\sin(256\pi q_y)$ 上的二维位移系数向量 RMSE；最小 $J$ 是128例全部2,097,152个原三角面的有向像面积/原面积最小值。真地图只在评价环节可见，训练损失始终仅为 image MSE。结果在 AI 主机空闲 RTX A6000、PyTorch2.5.1、batch2取得。

| 固定检查点/机制，确认集 seed20261017 | image MSE | map RMSE | high128模式误差 | 最小 $J$ / 回退 |
|---|---:|---:|---:|---:|
| 原1500步完整 CNN 细 head | .00005644 | .00103380 | .00028630 | .05000 / 0 |
| 原 CNN 粗层＋未经再训练的局部反馈 | .000000565 | .00080921 | .00020786 | .05000 / 0 |
| 图像训500步的粗层＋增益反馈 | .000000411 | **.00050273** | .00019960 | .05000 / 0 |
| 同一粗层冻结＋最后细层再训500步 | **.000000077** | .00050390 | **.00010761** | .05000 / 0 |

确认集的真实模式系数向量 RMS 为 .00028671。最后两行的整体地图误差差约 $1.18\times10^{-6}$，可说“在这次确认中没有可见恶化”，不能据一次实验/种子证明总体非劣效；模式误差减少约46.1%。两阶段方案并未靠读取解析真地图训练，而是让图像残差生成安全 latent。拓扑对全部实际输出原面核对；基于逐步正向局部几何的不变量与最终浮点符号筛选给出算法适用域内的保证，而128例只是额外实现核验。该确认仅限同一 high128 合成分布，不是自然图像泛化验证。

## 相同地图更换纹理：哪些损失真的有信息

取探索性评价集 seed939031 的**同一128张真地图**，将移动纹理替换为稀疏 Gaussian spots 或不同方向/频率的 crosswaves，再由真地图生成相应固定图。这样仅改变外观，不改变真实形变。all 增强把原32个训练地图分别配标准、spots、crosswaves，共96图像对；spots 增强为64对。三种反馈权重都从同一个原 CNN 检查点出发，采用同样500步、batch2、$w=3$、仅 image MSE 的粗编码器＋增益联合训练。注意96/64对只有32个独立变形，不等于96/64个新地图。

| 训练时外观（相同32地图） | 标准外观 map RMSE | spots map RMSE | crosswaves map RMSE | spots image MSE |
|---|---:|---:|---:|---:|
| 仅标准 / 32对 | **.00048922** | .00820831 | .00094101 | $9.51\times10^{-7}$ |
| 标准＋crosswaves＋spots / 96对 | .00086567 | .00832020 | **.00066125** | $9.93\times10^{-7}$ |
| 标准＋spots / 64对 | .00088875 | **.00817192** | 未测 | **$4.85\times10^{-7}$** |

所有这些实际输出仍有正向原三角面、零恒等回退。增强能改善它直接覆盖的 crosswaves 或微弱改善 spots，却明显牺牲标准外观上的几何精度；没有产生“一次性解决分布外纹理”的结果。[分阶段细修正检查点](57_high128_trainable_feedback_layer.md)在 spots/crosswaves 分别为 .00820450/.00095070 的地图 RMSE，其优势亦不跨到弱纹理。

为检验 spots 为何出现**很小 image MSE、很大 map RMSE**，再用解析真地图仅做评价诊断。在图像位置 $q$，高频系数 $a_f$ 的一阶亮度响应近似

$$
s(q)=H(q)\bigl[\partial_x I_M(F(q))+\partial_y I_M(F(q))\bigr].
$$

物理坐标梯度由512²像素中央差分近似，随后在真位置双线性取样。对每个图像求 $\sqrt{|Q|^{-1}\sum_{q\in Q}s(q)^2}$，再取128例平均；它是**指定单一高频方向的局部线性响应**，不是完整 Fisher 信息、可识别性证明或对任意变形的性质。[独立诊断脚本](../../tools/phase7_high128_texture_sensitivity.py)同时计算恒等地图的 image MSE。结果为：

| 外观 | 高频系数一阶图像响应 RMS 均值 | 恒等地图 image MSE | 恒等地图 map RMSE |
|---|---:|---:|---:|
| 标准 | 6.09885 | .00757496 | .01021642 |
| crosswaves | 11.63973 | .02606729 | .01021642 |
| spots | **.49050** | **.00006858** | .01021642 |

spots 的指定模式响应约为标准的 1/12.4，恒等地图在它上面的像素误差也已经很低；低 image MSE 在这种纹理下是弱几何证据。这与无监督像素目标的歧义相符，但不能由一个响应标量推出信息论不可能，也不能断言更多独立图像、不同损失或更强先验无效。下一步不宜只增加同一类 spots 训练步数；要明确建模图像可观测性/不确定性，或在可使用时加入来自真实应用的几何监督、时序/多模态约束，同时继续严格区分“同胚安全”与“真地图恢复”。
