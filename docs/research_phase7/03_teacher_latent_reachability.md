# 教师 latent 的目标采样可达性：与图像学习分开的诊断

本诊断回答“解码器能否表示某些独立目标”，**不**回答“能否从图像预测 latent”。输入目标顶点坐标仅用于构造教师 logit，训练或部署时不能调用此过程。可复算脚本为 `tools/phase7_teacher_reachability.py`，其目标公式、逐层残差和全脸面积计算都在文件内。

## 目标和编码方式

从 5² 恒等网格开始，取已知目标 $F$ 在 5² 上的顶点差，反解一轮安全径向更新的 raw logit。随后每层先对当前 P1 图作**精确** dyadic 细化，算新增顶点的目标残差 $\delta_v=F(x_v)-Y_v$，取 $z_v=\operatorname{artanh}(\delta_v/(2h))$；旧顶点 latent 置零。若径向更新的安全缩放仍为 1，就会恰好得到目标在该层的所有顶点采样。每级共同面积 floor 为 $J_T\ge0.05$（精确算术），逐层记录实测全脸最小 $J_T$、最大顶点差和 $\max|\delta_{v,k}|/(2h)$。目标和返回图均由原固定三角剖分上的 P1 延拓定义。

四个目标都固定单位方形边界：`base`、`high32`、`high64` 是 Phase VI 中低频双坐标形变叠加不同细频；`local_swirl` 则由本轮独立设计，为以 $(0.57,0.43)$ 为中心、尺度 0.12 的 Gaussian 局部旋转乘以 $\sin(\pi x)\sin(\pi y)$ 边界包络。目标**不**从候选 decoder 采样。对每张目标的 P1 全面数值面积独立检查；脚本代码给出精确公式。

|---|---|---:|---:|---:|---:|---:|

更新目标生成器后，边界顶点显式覆盖为恒等值；上表均为该版本重跑结果，不能与此前 float32 近边界残差混用。

1025² 指 1,050,625 个**真实控制顶点**和 2,097,152 个原面，不是 512² 图像查询。表中 RMSE 定义为 $\sqrt{N^{-2}\sum_v\|Y_v-F(x_v)\|_2^2}$，而最大误差是所有顶点、两坐标的最大绝对值。每层面积与残差可由脚本输出的 `steps` 重算。所有列出的层级、包括首次显现高频的 129²/257² 层，教师要求的安全缩放均实际为 1（从最终达到目标采样以及 raw-span 未饱和推得）；这只是这些目标的证据，不是任意 target 的保证。

这些结果说明父边共线障碍确已被“细分后安全移动新点”的正向金字塔突破，且目标频率需要在实际细控制网格中出现才能表达。它们不说明：有限图片能唯一识别每个目标、网络容易输出上述教师 latent、显存/时间与相同拟合精度的别的网络相比占优，或所给定的 5² 两轮种子足以覆盖所有有界正则同伦目标。接下来的多步 image-to-latent 训练须单独报告。
