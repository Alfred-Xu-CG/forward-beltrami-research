# 257² 局部终点场 → 精确 P1 加密 → 1025² 细顶点层

## 1. 一个共享 latent 的正向映射，而非全图线性系统

网格 \(\mathcal T_n\) 是单位正方形的 \(n\times n\) 规则顶点网格，每个小方格用西南—东北对角线剖成两个三角形；\(n=257\) 或 1025。输出顶点像 \(Y_{ij}\in\mathbb R^2\)，在每个三角形内作唯一仿射延拓，记为 \(f_Y\)。本实验固定所有边界顶点；检验每个三角形的目标有向双面积除以源双面积所得 \(J_T(Y)>0\)。在固定且一一对应的方形边界条件下，这给出连续 P1 同胚，而不是仅有像素 warp 或连续复合的拓扑性质。

令 \(p\) 为 patch 边长（源网格单元数），\(h=1/(n-1)\)，\(s_0=0.5ph\)。`ResidualStaggeredPatchP1Layer` 接收一张**单一**内部 latent 场 \(z_{ij}\in\mathbb R^2\)，并构造不要求自身同胚的候选终点

\[
E_{ij}=B_{ij}+s_0\tanh z_{ij}\quad (i,j\text{ 内部}),
\qquad E_{ij}=B_{ij}\quad (i,j\text{ 边界}),
\]

其中 \(B\) 是上一层给出的安全 P1 基图。对 \(c\) 个循环，循环 \(k\) 的暂时目标是 \(E^{(k)}=B+(k/c)(E-B)\)。每个循环按 patch 起点偏移 \((0,0),(p/2,0),(0,p/2),(p/2,p/2)\) 顺次处理四组互不重叠的 patch。一个 pass 只更新各 patch 的**内部**顶点，边界与 patch seam 保持原值；它先以 \(E^{(k)}_i-Y_i\) 作为该顶点想走的残差，再用 bounded `atanh` 转成 patch 原语的输入。若当前 pass 因面积限制未走到终点，后续重叠 pass 会重新计算剩余残差，因此不需要为每个 pass 额外学习一张可互相抵消的 latent 场。

每 patch 的同步原始位移 \(d_i\) 使每个受影响面的有向双面积成为 \(A_T(t)=A_T(0)+tL_T+t^2Q_T\)。对 \(0\le t\le1\) 有

\[
A_T(t)\ge A_T(0)-t C_T,
\qquad C_T=(-L_T)_+ +(-Q_T)_+.
\]

模块选择不超过 \(0.85 A_T(0)/C_T\) 的共同 patch 比例；还可限制精确算术的归一化面积下限为 0.05。每 patch 的所有三角形均受这个最小比例约束，patch 外的顶点/面不变。对**任意有限 latent**，从一个正向基图归纳得到每步正向；固定原网格上直接改顶点，不求任何全局线性系统，也不把连续图复合后插值误称为 P1。`atanh` 的输入在实现中夹到 \((-1+4\epsilon,1-4\epsilon)\)，防止极端 finite latent 在浮点 `tanh` 饱和为 1 后出现无限值；这是数值域处理，不改变精确算术证明。

`TiedStaggeredPatchP1Layer` 是另一候选：同一顶点的目标总位移平均分给它在所有 pass 的访问次数。它同样用 2,093,058 个 1025² scalar latent，但早期 pass 遇到安全裁剪后，均分方案不能主动补偿；下面实验将其作为阴性对照。两者均有 [实现与小网格 VJP 测试](../../src/qcopt/neural_bijection/dense/patch_field.py)。

## 2. 真正的 coarse-to-fine 输出契约

取安全的 257² 粗输出 \(C(z_c)\)，先用两次 dyadic 规则加密算子 \(R\) 形成 1025² 的 \(R^2 C(z_c)\)。新顶点的坐标由**原粗三角形内的仿射值**计算，不重新解算；子三角形仍位于某个旧三角形内部，因此 \(f_{R^2 C}=f_C\) 作为连续函数完全相同。随后在这张**已经固定的 1025² 三角网格**上，用 F1 四着色安全顶点更新 \(U_{1025}\) 接受细 latent \(z_f\)：

\[
D(z_c,z_f)=U_{1025}\bigl(R^2C(z_c),z_f\bigr).
\]

F1 每种颜色的顶点两两不共享三角形，六个相邻面的有向面积对单顶点位移线性；以当前面积的 0.85 作为不利变化预算，并在本次试验中另设与细基图最小面积对应的 `floor_fraction=0.05`。固定边界不动。所以精确算术下 \(D(z_c,z_f)\) 对所有有限 latent 都是**一张原 1025² 网格上的 P1 同胚**。该结论不要求候选终点场 \(E\) 自身同胚，也不包含全局大线性系统。浮点实现仍需逐面核查：上一份[数值故障报告](18_unaligned_patch_and_fp32_margin.md)已显示 `float32` 无 floor 时可让极薄面翻号；0.05 floor 是此实验的实测安全余量，尚不是任意 latent 的 IEEE 舍入定理。

## 3. 独立目标族、完整训练设置与指标

令 \(w=1/16\)，窗口原点 \(x_0=y_0=0.28125\)，定义零延拓的

\[
W(x,y)=\sin^2\!\left(\pi(x-x_0)/w\right)
\sin^2\!\left(\pi(y-y_0)/w\right)
\quad\text{在 }[x_0,x_0+w]^2\text{ 内},
\]

并设 \(H(x,y)=\sin(256\pi x)\sin(256\pi y)\sin^2(\pi x)\)，

\[
T(x,y)=(x,y)+\bigl(0.006W(x,y)+aH(x,y)\bigr)(1,1),
\qquad a\in\{0,2\times10^{-5}\}.
\]

两分量都运动，窗口横跨 64-cell fine patch seam；高频 \(H\) 在 257² 顶点上为零，在 1025² 顶点上不全为零。整个目标不是从待测解码器采样生成。对 \(|a|\le2\times10^{-5}\)，标量位移 \(v=0.006W+aH\) 的导数满足

\[
|v_x|+|v_y|\le 2(0.006)\pi/w+|a|(257+256)\pi<0.636<1.
\]

故连续图 \(\mathrm{id}+v(1,1)\) 是固定边界的全局同胚。规则 SW–NE 三角网格的 P1 插值之 x/y 导数分别是沿相应网格边的差商，服从同一上界；其每面 \(J=1+v_x^{\rm P1}+v_y^{\rm P1}>0\)，所以**目标自身的离散 P1 采样图**也独立地有拓扑保证。实测最小 \(J\) 为 0.60864258（\(a=0\)）和 0.59878540（\(a=2\times10^{-5}\)）。这里的面积指标是所有 2,097,152 个 fine 面的最小归一化有向双面积；顶点 RMSE 定义为 \([V^{-1}\sum_i\|Y_i-T_i\|_2^2]^{1/2}\)，最大坐标误差为 \(\max_{i,c}|Y_{i,c}-T_{i,c}|\)。

实验在 Turing A40 GPU0、PyTorch 2.8、float32、batch1 进行。粗层是 257²、16-cell patch、2 个四错位循环、130,050 个 scalar latent，从全零开始以全粗顶点 map MSE×\(10^6\)、Adam 学习率 0.003、eps \(10^{-12}\)、余弦退火 600 步直接训练。**冻结**粗输出、精确加密后，细层是 1025² F1 一次四着色 pass、2,093,058 个 scalar latent，再从全零以全细顶点相同损失、Adam 学习率 0.01、余弦退火 400 步训练。没有向优化器给 teacher latent；解析目标顶点仅作为监督和评估。另计算 teacher 的可表达性，并用与训练损失无关的随机全输出 cotangent 对**两组 latent 同时**求一次完整链 VJP。[复现脚本](../../tools/phase7_fit_coarse_patch_fine_vertex.py)。

## 4. 1025² 实测与对照

| 设置 | 粗图 RMSE | 精确加密后 fine RMSE | 细训练后 fine RMSE | 最终最小 \(J\) |
|---|---:|---:|---:|---:|
| \(a=0\) | 0 | \(2.76919\times10^{-6}\) | 0 | 0.60864258 |
| \(a=2\times10^{-5}\) | 0 | \(9.08453\times10^{-6}\) | 0 | 0.59878540 |

“0”表示同一 float32 顶点表逐元素相等，不是解析连续图在所有非顶点位置误差为零；输出与目标的 P1 延拓相同，而目标连续函数有正常的 P1 插值误差。\(a=2\times10^{-5}\) 时细层 teacher logit 最大绝对值 0.06316，按此 teacher 一 pass 也达到相同顶点表；从零训练的 400 步结果不是仅有可表达性 oracle。粗层一训练步中位 0.0563 秒、峰值 CUDA allocated 0.119 GB；细层一训练步 0.0237 秒、峰值 0.597 GB。两段独立训练，不能把两项时间当作一次联合训练步。

在已训练 latent 上，从最终 1025² 输出对**粗 130,050 和细 2,093,058 scalar latent 同时**做独立随机 cotangent VJP，两个梯度均有限且非零；包含粗 F2、两次精确 P1 加密、细 F1 的完整 decoder forward+VJP 中位 **0.0802 秒**、CUDA allocated 峰值 **0.784 GB**。未计入 CNN 图像编码、512² 图像 warp 或 optimizer；这是几何 neural layer 的成本，而非端到端图像训练成本。

匹配目标 \(a=2\times10^{-5}\) 的负对照：在**直接** 1025² 上用同一个 residual F2 原语、64-cell patch、2 循环、2,093,058 scalar latent，从零作 600 步 Adam（学习率 0.001），teacher 能精确到 0，但训练后仅有 RMSE \(3.48901\times10^{-5}\)、最大坐标误差 0.004342、最小 \(J=0.06096\)；每步 0.104 秒、峰值 1.760 GB。此前学习率 0.01、300 步在无高频的同位移目标上更差；这不是全面的超参数最优性证明。它说明本样本的 coarse-to-fine 分工是**训练条件数上的实质收益**，不是单靠新增 fine 参数提高 teacher 容量。

另一个阴性候选 `tied` 将同一顶点总位移平均分摊到各 pass：同一错位目标 \(a=0\)，1025²、2 循环、600 步、学习率 0.001，teacher RMSE \(4.72\times10^{-5}\)、训练 RMSE \(1.95\times10^{-5}\)、峰值约 1.72 GB；增加到 4 循环的 teacher RMSE 才降至 \(4.81\times10^{-6}\)，成本约翻倍。与之相反，按**剩余位移**反复追逐的参数化在相同 2 循环有零 teacher 误差，因此保留 residual 版本、暂不以 tied 版本作为主层。

## 5. 还没有解决的核心问题

本实验是直接 map-supervised latent 优化，不是图像对输入到 latent 的网络训练。它只覆盖一个有清晰尺度分离、解析可核验的目标族；不能据此宣称固定深度下逼近大多数同胚。理论上的全 P1 可达性是**目标依赖的可能很深的序列**，并未给出此架构的统一低深度/低复杂度逼近率。下一步需随机化局部窗口位置、尺度、方向并做训练/保留分离；比较图像到粗、细 latent 的端到端训练与 map-supervised oracle，检测图像不可辨识性；同时建立有限精度的保拓扑证书或采用可接受成本的高精度输出。不能因为此单个大网格目标达到 float32 顶点 0 误差，就宣布预期 neural layer 已全面完成。
