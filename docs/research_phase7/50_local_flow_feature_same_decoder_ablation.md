# 局部位移提示改善图像推断，但不改变正向 P1 保证

## 问题、输入与数学构造

此前的[同任务比较](49_same_task_three_forward_pyramids_and_ood.md)显示，17² 粗 patch ＋细级新顶点的混合解码器能在 1025² 控制网格反传，却不能从 32 个训练图像对准确推断全部形变；直接读取解析目标顶点的[teacher 测试](47_hybrid_patch_seed_vertex_refinement.md)则能近乎精确抵达该目标。这一消融只问：在**同一个安全解码器**、同一数据与相同训练步数下，把一个不含真值地图的局部图像位移估计作为编码器特征，是否改善 image-to-latent 训练？它不是提出新的同胚生成原语。

固定灰度图记 $I_F:\Omega\to\mathbb R$，移动图记 $I_M$。本实验按 $I_F(x)=I_M(F(x))$ 生成，其中解析地图 $F$ 只用于合成固定图及训练后的误差评价，**不输入编码器、不进入训练损失**。先把两图双线性缩放到 257² 特征网格。在位置 $x$，令 $g=\nabla I_M$、$r=I_F-I_M$，使用窗口 $W_x$ 内的平均值形成

\[
G_x=\langle gg^\top\rangle_{W_x}+\lambda I_2,\qquad
b_x=\langle gr\rangle_{W_x},\qquad
d_x=G_x^{-1}b_x,\qquad
h_x=\tanh(d_x/s).
\]

实现为逐像素解析 2×2 解，窗口边长 5 像素、$\lambda=1$、$s=.02$；输入图像坐标域是 $[0,1]^2$，所以 $g$ 是对物理坐标求导。$G_x$ 由 ridge 正则严格正定，$h_x\in(-1,1)^2$ 有界；这里不存在随网格增大的线性系统。线性化式 $I_M(x+d)\approx I_M(x)+g(x)^\top d$ 只在小位移/足够纹理时可靠。局部最小二乘位移属于经典 [Lucas--Kanade 图像配准思想](https://publications.ri.cmu.edu/storage/publications/pub_files/pub3/lucas_bruce_d_1981_1/lucas_bruce_d_1981_1.pdf)；本工作只把它接到既有的有安全约束的多尺度 latent 解码器。

原编码器把 \((I_F,I_M,x_1,x_2)\) 四通道送入宽度 16 的卷积网络；提示版额外拼接 \((h_1,h_2)\)，其他主干、粗细 latent head 和解码器完全相同。后者先用 17² 粗 patch 输出一张 P1 地图，然后对 33、65、129、257、513、1025² 嵌套网格做**精确 P1 延拓**及仅新顶点的四着色安全更新，最后作保守的二进制浮点逐面符号筛选。每次局部更新的可行性与最终边界固定的面正向，才是固定规则网格 P1 同胚保证的来源；局部光流本身可能错误，也不会单独保证拓扑。筛选切换处不可按一般光滑层理解，但训练实际路径没有输出恒等回退。

## 实验设置与指标

与无提示模型对比：512² 输入图像和查询、257² 或 1025² **控制顶点**，分别有 66,049/1,050,625 顶点和 131,072/2,097,152 原三角面。合成纹理是随机正弦与 Gaussian 斑块；`high32` 地图位移含一个低频 \(\sin(2\pi x)\sin(2\pi y)\) 项及 32 周期细项，`base` 的低频幅度更大、细项为 8 周期。具体系数范围和完整生成器在[脚本](../../tools/phase6_train_multisample_image.py)；两族不是相同幅度的纯频率消融。训练 32 例 seed55101，开发 8 例 seed99317，最终全新 128 例 seed939031。每种 257² 模型从零训练 1000 步；1025²模型从对应 257²检查点继承，精确增添零初始化的 513²/1025² latent head 后续训 600 步。batch2，Adam，257² 学习率 .003/\(\epsilon=10^{-8}\)，1025² 学习率 .001/\(\epsilon=10^{-12}\)。唯一训练目标是

\[
L_{\rm image}=\frac{1}{BHW}\sum_{b,p}\bigl[I_M^b(f_{Y^b}(p))-I_F^b(p)\bigr]^2.
\]

`image MSE` 即上述逐像素均方差。`query-map RMSE` 是对查询像素的二维坐标向量取 \(\sqrt{(BHW)^{-1}\sum_{b,p}\|f_{Y^b}(p)-F^b(p)\|_2^2}\)；它仅用于评价。`最小 J` 是两百万或十三万原三角面上的有向像面积除以原面积的最小值，再跨样本取最小值，故正值证实这批数值输出均无翻面。`回退` 统计最终二进制坐标筛选后被替换为恒等图的样本数。速度是 A6000/PyTorch 2.5.1 cu124 同机中位完整训练步（前向、图像损失、反传、Adam），显存是训练中的 CUDA `max_memory_allocated`，不含其他进程占用。

### 迁移训练反例与只训练新增 head

`base` 的 1025²联合训练比各自的 257²模型还差，虽然新细层初始为零、第一步梯度非零；这不能直接判作解码器表达不足或细层必然有害。为区分旧层漂移与新增 head 的作用，我们在同样的 257²起点、32训练例、600步、学习率与控制网格下，冻结原有卷积主干、seed head 和至257²的所有 head，只训练新加的513²/1025²两个 1×1 head；它们一共只有 **68 个可训练标量**，其空间特征仍由冻结的257²主干给出。冻结不改变解码器或已训练安全地图。

|---|---:|---:|---:|
| 无提示，所有旧/新参数共同更新 | .00187926 / .00559224 | .05000 / 0 | 221.55 ms / 2.920 GB |
| 无提示，只训练新增68参数 | .00217525 / .00576918 | .05000 / 0 | 130.20 ms / 2.689 GB |

在这一次 `base` 训练里，“冻结旧层＋提示”同时优于自身257²起点（.00072607 / .00332549）和全参数1025²迁移；无提示模型没有这种收益。差异支持“无约束的旧层漂移会伤害这里的迁移”的判断，但不能证明冻结普遍最优；因为只训练68个参数也改变了优化问题和有效学习率，不是控制全部因素的因果分解。两份冻结版权重：[无提示](checkpoints/phase7_hybrid_plain1025_base_frozen600.pt)、[有提示](checkpoints/phase7_hybrid_flow1025_base_frozen600.pt)。

各 257²/1025² `high32` 提示版权重：[257²](checkpoints/phase7_hybrid_flow257_high32_image1000.pt)、[1025²](checkpoints/phase7_hybrid_flow1025_high32_transfer600.pt)；`base` 权重：[原版257²](checkpoints/phase7_hybrid_plain257_base_image1000.pt)、[提示版257²](checkpoints/phase7_hybrid_flow257_base_image1000.pt)、[原版1025²](checkpoints/phase7_hybrid_plain1025_base_transfer600.pt)、[提示版1025²](checkpoints/phase7_hybrid_flow1025_base_transfer600.pt)。精确训练命令参数由检查点的 `config` 保存；入口是[训练/评价脚本](../../tools/phase7_train_forward_pyramid_image.py)，独立提示质量测量在[诊断脚本](../../tools/phase7_measure_flow_hint.py)。两个输入梯度与编码器形状的[单元测试](../../tests/test_phase7_flow_hint_features.py)在本地通过。

## 为什么不能把这个结果过度解释

单独把未训练的 $d_x$ 当成地图估计时，`high32` 新 32 例的向量 RMSE 从零位移 .01135 降到 .00701；`base` 则从 .02576 **略升**至 .02580。尽管如此，`base` 的提示版经过端到端训练也有改善。这表明网络可能从不完美的局部相关特征中提取线索，而非直接采纳 $d_x$；不能把提示视为准确光流或给它拓扑保证。**还有一个反向结果：**`base` 的两个版本从257²扩展到1025²并再联合训练600步后，尽管最终仍是大网格同胚，128例的image MSE相对于各自257²模型都变差。网格分辨率增大不保证推断精度；目前需要区分新增细层的影响与旧层参数共同更新造成的漂移。上述两个族共享同一个合成纹理程序、一次权重初始化/训练种子，尚无自然图像测试、跨纹理来源测试或多随机种子置信区间。并且 1025² 的主干仍只在 257² 特征网格计算、再把 head 插值到细网格，不能因此声称已学会百万个独立自由度。此处证明的是这个合成分布中，一个经典、便宜、可微的局部图像特征能明显改善**图像推断瓶颈**，不是已解决广义图像配准，也不是发明了新的同胚定理。
