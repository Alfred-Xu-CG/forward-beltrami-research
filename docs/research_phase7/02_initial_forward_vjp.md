# 第一轮正向金字塔：真实控制网格前向/VJP 与面积余量

## 问题、构造与口径

问题是一个**无大线性求解**、输出一张固定规则网格 P1 图的多尺度 latent decoder，能否实际生成 257² 和 1025² 控制顶点、把损失反传到全部尺度 latent，并保持可核查的原面拓扑。实现见 `src/qcopt/neural_bijection/dense/forward_p1_pyramid.py`；复算入口为 `tools/phase7_benchmark_forward_pyramid.py`。

以 5×5 恒等种子网格出发，执行两次全内点四着色 latent 更新；之后每层精确 P1 细分到 $N\mapsto2N-1$，仅对新顶点输入 latent，执行一次四着色径向安全更新。输出始终是**最后固定网格上的一张 P1 图**，不是动态网格复合。各层使用同一个归一化有向双面积下界 $\rho=0.05$：面积下界传给已有 A4 径向安全更新，单位为实际双面积 $\rho/(N-1)^2$。精确算术下，由恒等初态、P1 保真细分和逐面剩余面积限制归纳得 $J_T\ge\rho$，边界点恒等，故全局同胚。由于浮点舍入，返回图的实测最小 $J_T$ 可略低于 $0.05$；逐面全量证书仍需独立检查，不能把常数当 IEEE 算术定理。

本次只测**随机 latent 的表示、数值拓扑、完整前向与 VJP**，不是 image-to-latent 训练或映射准确性比较。每个种子 logit 独立取 $0.08N(0,1)$，每层 logit 取 $0.03N(0,1)$，另有一次大 logit 压力测试。最终查询固定为 512×512=262,144 个图像坐标，独立于控制网格规模；通过预计算的固定 P1 插值表取最终坐标，对一张固定正弦纹理做 `grid_sample`，以其未扭曲版本计算像素 MSE。VJP 是从该损失回到**全部**种子和各层 latent 的一次反传，不含 encoder，因为这次没有 encoder。回传后检查每个尺度 latent 的梯度存在、有限且非零。计时是预热两次后五次 GPU 同步 wall time 的中位数，含 decoder、最终查询、图像取样与损失；setup 和全脸证书另计、不包含在 forward/VJP 时间内。峰值 `allocated/reserved` 在预热后重置，且在事后拓扑检查之前读取。

设备：Turing 主机当时空闲的 NVIDIA A40 物理 GPU 0，`CUDA_VISIBLE_DEVICES=0`，PyTorch 2.8.0+cu129，float32，batch 1；没有动另一张忙碌 A40 或现有 SSH 的 18082 转发。网络波动和共享机器调度使几十毫秒短测有噪声，下面只是本次五次中位数。

| 控制顶点 / 原面 | 层级 latent 标量数 | 最小 $J_T$；非正面 | 完整 forward / VJP 中位数 | 峰值 allocated / reserved | 一次 setup |
|---|---:|---:|---:|---:|---:|
| 257²=66,049 / 131,072 | 172,752 | 0.049993；0 | 22.34 / 79.87 ms | 96.31 / 127.93 MB | 0.97 s |
| 1025²=1,050,625 / 2,097,152 | 2,788,052 | 0.049941；0 | 28.88 / 100.09 ms | 743.88 / 872.42 MB | 12.85 s |

这里 $J_T$ 是面像的有向双面积除以对应源面的有向双面积；“非正面”在**所有**原三角形上计数。证书也核查有限坐标、单位方形范围和逐边界点恒等。两个主尺度全部尺度 latent 均有非零有限梯度。setup 主要包含构造每色邻接索引与固定查询插值表，不能对一次性推理忽略。上述延时**不含图像 encoder**，因此不能直接称比 Phase VI A8 或 C 的完整 image-to-map 网络更快；映射拟合质量尚未比较。

## 捕获的失败和修正

同一实现最初未施加跨层共享面积下界，仅每步保留正面积的比例。257² 同一种子最小 $J_T\approx0.000122$；1025² 同一种子返回的 float32 网格有 **5 个非正向面**，最小 $J_T=-4.95\times10^{-5}$，全量证书失败。float64 在该样本也未通过证书（该轮没有保存全脸最小值，因此不声称 float64 也折叠）。这与精确算术的逐步正面积证明不矛盾：长期衰减后的面裕量可能小到不足以抵抗浮点和实现误差，且旧层本身可逐渐接近退化。

加入固定 $\rho=0.05$ 的归一化面积下界后，1025² 同一种子证书通过，实测最小 $J_T=0.049941$、无非正面。更大随机 latent 的压力样本（seed 701、种子标准差 0.5、各层标准差 1）在 1025² 得最小 $J_T=0.049513$、0 非正面，完整 forward/VJP 约 32.96/101.57 ms。另一个 batch 4 样本（seed 702、默认标准差）在真实 1025² 控制上得到最小 $J_T=0.049876$、0 非正面，forward/VJP 约 42.94/144.84 ms、峰值 allocated/reserved 2.466/2.613 GB。有限样本通过是实现证据，不是所有 float32 输入的无条件证书。

1025² 用逐 pass activation checkpoint 的消融：同种子、同 GPU、同 512² 查询，forward/VJP 约 41.46/164.40 ms，峰值 allocated/reserved 637.04/729.81 MB。相对不 checkpoint 只节约约 107 MB allocated，却明显增加时间；当前实现默认不 checkpoint。这个结论仅适用于此网络结构、batch 1 和该 CUDA 版本。

## 表示性与接下来的关键空白

`tests/test_phase7_forward_p1_pyramid.py` 已在小网格检验精确 P1 细分作为连续函数与粗图相同，及小幅独立光滑目标 $F(x,y)=(x+0.02s,y-0.015s)$、$s=\sin(\pi x)\sin(\pi y)$ 的教师 latent 从 5² 经 33² 各层**精确到达目标顶点采样**。这只验证一个良性目标。对大位移、高曲率、细频或窄 Jacobian 目标，常数 $\rho$ 可能限制可表示性；需要直接 latent oracle 与独立目标族的误差—速度 Pareto 曲线，再进入 image-to-latent 训练。理论上的有条件可达性见 [01 文档](01_refinement_reachability.md)，不等于已训练网络覆盖该目标族。

当前最大的工程优化点还包括 1025² 一次性约 12.85 s 的 setup，以及 257² 时不少小层 CUDA kernel 的发射开销；不能只用热启动毫秒数评价部署。
