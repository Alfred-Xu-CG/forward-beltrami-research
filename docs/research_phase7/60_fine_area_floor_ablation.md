# 不牺牲拓扑裕量换高频：1025²反馈面积下界消融

## 问题和同条件设置

[两阶段 image-only 反馈层](57_high128_trainable_feedback_layer.md)在标准外观新128例上输出的最小归一化面 Jacobian 接近训练时设定的0.05。细高频模式误差仍非零。一个可能的解释是“安全层面积下界过高，阻碍继续拟合”；因此只在**推理时**修改最后两级四着色更新的名义面积下界 $\rho h^2$，不重新训练、不改编码器、增益、修正网络、图像、窗口或轮数。每个样本仍在1025²实际控制顶点及全部2,097,152原三角面上计算拓扑与地图指标。面积下界只约束单顶点更新的允许面积损失；若输入某面已低于 $\rho h^2$，该更新不能凭空恢复它，故不能把参数 $\rho$ 本身误称为任意输入的全局输出下界。

固定检查点为[分阶段最终 w=3 权重](checkpoints/phase7_hybrid_feedback_w3_final_correction500.pt)，标准外观探索性评价 seed939031、128例、512²图像及 query、batch2、AI 主机 A6000。image MSE、query-map 向量 RMSE 与 high128 模式向量误差的公式见[训练报告](57_high128_trainable_feedback_layer.md)。最终仍有保守浮点面符号筛选。$\rho=0$ 在实数运算中仍有由安全比例0.75给出的严格正向面，但不再要求指定的非零面积裕量。

| 推理时名义 $\rho$ | image MSE | map RMSE | high128模式误差 | 全128例最小 $J$ / 回退 |
|---:|---:|---:|---:|---:|
| 0 | $6.3411\times10^{-8}$ | .000495132 | .000096245 | $1.896\times10^{-6}$ / 0 |
| .005 | $6.3469\times10^{-8}$ | .000495132 | .000096247 | .00500 / 0 |
| .05（训练设置） | $6.5272\times10^{-8}$ | .000495157 | .000096361 | .05000 / 0 |
| .10 | $7.0028\times10^{-8}$ | .000495193 | .000096668 | .10000 / 0 |
| .20 | $9.5400\times10^{-8}$ | .000495413 | .000097900 | .20000 / 0 |

放松下界从.05到0对 map RMSE 和模式误差只带来所示微小变化，却使最薄面的归一化面积下降约四个数量级；即使这一批输出的浮点证书全部通过，也会使数值稳健性明显脆弱。因此当前欠拟合**不能主要归咎于 .05 面积下界**，没有证据支持为了高频准确度将它去掉。相反，在这批输入上提高到.10或.20，地图误差也只略变；这提示可探索更大裕量，但这些行只是未再训练的同分布推理消融，不能据此断言训练后相同或跨所有 latent 统一保证 $J\ge.20$。模型选择已接触 seed939031，任何采用新 $\rho$ 的最终优劣都需要另设确认集。

复现参数：[反馈脚本 --area-floor-jacobian](../../tools/phase7_high128_local_feedback.py)。该实验不改变正向固定P1输出契约，不涉及从任意 Beltrami 场恢复映射。
