# 单幅图像不能唯一决定固定网格 P1 同胚：一个完全离散的反例

## 设定与命题

令 \(\Omega=[0,1]^2\)，在均匀 \(N\times N\) 顶点网格上将每个方格沿西南—东北对角线分成两个三角形；\(h=1/(N-1)\)。映射由所有顶点像和逐面仿射延拓定义，边界固定为恒等。考虑移动图像 \(I_m(x,y)=x\)，固定图像由某个真实映射 \(F\) 按 \(I_f=I_m\circ F\) 生成。图像是非恒定的，但只含水平坐标信息。

**命题。** 在每个奇数 \(N\ge3\) 上，存在两张不同、全局无折叠、边界恒等的**同一固定三角网 P1 同胚** \(F_0,F_1\)，使两者生成完全相同的固定图像，且中心顶点像相差 \(1/16\) 个单位长度。因而从这一幅图像对无法唯一推断 P1 顶点表；即使解码器对每个 latent 都严格保证同胚、图像重建误差为零，这个结论仍然成立。

## 显式构造与证明

令 \(x_i=ih,y_j=jh\)，定义 \(b_{ij}=x_i(1-x_i)y_j(1-y_j)\)，并令 \(b_h\) 为其在上述网格上的连续 P1 插值。取
\[
F_0(x,y)=(x,y),\qquad F_1(x,y)=(x,y+b_h(x,y)).
\]
由于 \(b_{ij}=0\) 于整个边界，两个映射都逐点固定边界；它们的第一坐标恒为 \(x\)。所以**连续域中逐点精确地**
\[
I_m(F_0(x,y))=x=I_m(F_1(x,y)).
\]
这不是光度误差接近零、采样插值误差或事后拓扑修补，而是两个不同的固定网格 P1 映射给出完全相同的非恒定图像。

在任何三角面内，\(F_1\) 的 Jacobian 行列式等于 \(1+\partial_y b_h\)。该固定对角线的每个面的竖向导数，等于某一竖边两端的 \(b\) 值之差除以 \(h\)：
\[
\partial_y b_h=x_*(1-x_*)\frac{y_{j+1}(1-y_{j+1})-y_j(1-y_j)}{h}
=x_*(1-x_*)(1-y_j-y_{j+1}),
\]
其中 \(x_*\) 是该面一条竖边的 \(x_i\) 或 \(x_{i+1}\)。于是 \(|\partial_y b_h|\le1/4\)，从而每一原网格面严格有 \(J_T(F_1)\ge3/4>0\)。更直接地，对每个固定 \(x\)，\(y\mapsto y+b_h(x,y)\) 连续、严格递增，端点为 \(0,1\)；故 \(F_1\) 是 \(\Omega\) 到自身的全局同胚。奇数 \(N\) 的中心 \((1/2,1/2)\) 是顶点，\(b_h(1/2,1/2)=1/16\)。

对 \(N=257,1025,4097\)，由上式逐行枚举竖边得到的最小原面 \(J_T\) 分别为 \(0.7509765625,0.750244140625,0.75006103515625\)；最大顶点位移都是 \(0.0625\)。此数值核验只是精确证明的实现 sanity check。连续函数 \(b(x,y)=x(1-x)y(1-y)\) 的二维位移均方根恰为 \(1/30\)，所以这种歧义在整域上也不是一个只发生于单点的微扰；\(b_h\) 的均方根随加密趋于该值。

## 对多通道实验与目标契约的含义

反例不否定“latent \(\to\) 安全 P1 同胚”的**生成层**，而是否定“单幅灰度图像对 \(\to\) 任意真值形变唯一可辨”的无条件主张。单幅真实图像仍可依赖先验、监督、形状模型、landmark 或多时相信息选出一个有用解；但要明确那是额外信息，不能只靠图像残差为零和面面积为正推断真值几何恢复。

对一般足够光滑的单通道图像，只要在某一内部开集 \(\nabla I\ne0\)，任取支撑在该开集的非零光滑标量 \(\eta\)，向量场 \(v=\eta(-\partial_y I,\partial_x I)\) 满足 \(\nabla I\cdot v=0\)。其短时间流在内部产生非平凡边界固定微分同胚 \(\Phi_t\)，且沿轨线 \(dI(\Phi_t(x))/dt=0\)。这个连续版本解释了等亮度方向的歧义；**上面的 \(I=x\) 构造更强，因为歧义直接发生在要求的固定网格 P1 输出类内部**。两个或更多独立纹理通道可能让局部梯度矩阵满秩，因此[多视图实验](68_multiview_observability_4097_p1.md)大幅改善；这只是该合成任务中的可观测性证据，不自动证明一般多视图的全局唯一性或噪声稳健性。

本轮评价应把两个问题分开：①给定任意或任务相关 latent，decoder 能否快速、可微并且必然输出固定 P1 同胚；②给定的观测模态是否提供足够信息让网络推断目标 latent。第二个问题的失败不能直接归罪于第一个，反之严格拓扑保证也不能解决第二个。
