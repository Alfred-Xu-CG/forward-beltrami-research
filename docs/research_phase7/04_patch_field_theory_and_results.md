# F2：同一张固定网格上的并行 patch 向量场

## 对象与输出契约

取单位正方形的规则三角剖分，每个小正方形沿左下—右上对角线分成两面。顶点像为 \(Y_i\)，三角面 \(T=(i,j,k)\) 的有向双面积为
\[
A_T(Y)=\det(Y_j-Y_i,Y_k-Y_i).
\]
原网格对应双面积为 \(h^2>0\)，故归一化 Jacobian 是 \(J_T=A_T/h^2\)。本算法始终存储并直接输出**同一张规则网格**所有顶点的像，再逐面作仿射延拓；它不是把几个连续 P1 因子复合后重采样的替身。

一个 patch 是网格上 \(p\times p\) 个小方格组成的正方形。一次 pass 选取互不重叠的完整 patch，固定每个 patch 的边界顶点及整个定义域的外边界，只移动 patch 的严格内部顶点。第 \(k\) 个 patch 的原始位移场来自有限 latent \(z_i\in\mathbb R^2\)：
\[
D_i=rp h\,\tanh z_i\quad (i\text{ 是 patch 内点}),\qquad D_i=0\quad(i\text{ 是 patch 边界}),
\]
其中 \(r>0\) 为无量纲位移跨度。这里每个 patch 内**相邻的多个顶点可以在同一个 pass 同时运动**，与 F1 的四着色单点更新不同。

## 每个 patch 共同安全步幅的推导

设更新是 \(Y_i(s)=Y_i+sD_i\)，其中同一 patch 使用一个共同标量 \(s\in[0,1]\)。任一 patch 三角面满足精确二次式
\[
A_T(s)=A_T(0)+sL_T+s^2Q_T,
\]
\[
L_T=\det(D_j-D_i,Y_k-Y_i)+\det(Y_j-Y_i,D_k-D_i),\quad
Q_T=\det(D_j-D_i,D_k-D_i).
\]
因为 \(0\le s^2\le s\)，令
\[
C_T=(-L_T)_++(-Q_T)_+,\qquad (a)_+=\max(a,0),
\]
便有对所有 \(s\in[0,1]\) 的保守但严格下界 \(A_T(s)\ge A_T(0)-sC_T\)。正的线性项或二次项无需列入不利预算；这比 \(|L_T|+|Q_T|\) 紧。给定 \(0<\gamma<1\) 和统一源尺度面积下界 \(\rho h^2\)，定义
\[
B_T=\min\{\gamma A_T(0),\, (A_T(0)-\rho h^2)_+\},\qquad
s_P=\min_{T\subset P}\frac{B_T}{\max\{C_T,B_T,\varepsilon_h\}},
\]
其中 \(\varepsilon_h>0\) 只用来避免分母为零；实现对 \(C_T=0\) 的面直接规定面尺度为 1，因为它在整个 \(s\in[0,1]\) 上不会降低面积。其余比值在 \([0,1]\) 内。如果输入每面 \(A_T(0)\ge\rho h^2\)，则
\[
A_T(s_P)\ge A_T(0)-B_T\ge \rho h^2,
\qquad
A_T(s_P)\ge(1-\gamma)A_T(0)>0.
\]
patch 的每个被移动顶点均属于该 patch 的内部；涉及这些顶点的三角面也完全落在同 patch 中。不同 patch 的内部顶点和受影响面互不相交，所以各 \(s_P\) 可以并行计算。未涉及的面面积不变，定义域外边界逐点保持恒等。由此，在**精确算术**中，归纳得到任意有限合法 latent 的每个 pass 都保持全部面正向；结合该矩形盘域的恒等边界与三角面非退化条件，得到全局 P1 homeomorphism。最后一项仍须使用具有正确边界/度数假设的 PL 全局单射定理，不能把“局部面积正”单独当作全局证明。

浮点代码采用 \(\varepsilon_h=\sqrt{\epsilon_{\rm machine}}\,h^2\)，并不属于上述精确算术证明的一部分。曾使用 float32 的最小正数 \(10^{-38}\) 作保护值；在面积正好到 \(\rho h^2\)、\(C_T=0\) 的 patch 角点，反向导数可达 \(2.6\times10^{36}\)，四轮优化在第 19 步出现 NaN。面积尺度保护值修复了这个具体数值问题。还发现 \(C_T=0\) 的面根本不应限制 patch，但数值保护分母曾使零余量的无位移面冻结整个 patch；现单独令该面的安全尺度为 1。两个问题均有先失败、后通过的小网格回归测试；1025² 大网格逐面数值核验仍须保留。

## 交错覆盖与多尺度

固定 \(p=8\)，按四种偏移 \((0,0),(p/2,0),(0,p/2),(p/2,p/2)\) 依次做四次 patch pass。每次内部 patch 不重叠，跨 pass 可交错重叠。对 \(N=17,33,65,\ldots\) 的网格，四种偏移的严格内部顶点并集覆盖所有定义域严格内部顶点；此性质已有枚举测试，边界从不运动。也可以重复多个四-pass 周期。

从粗网格到细网格时，先用粗 P1 函数在细顶点的**精确取值** \(P Y\)，因此连续函数不变、面仍正向；再执行四个交错 patch pass。这个层级过程不需要随 \(N\) 增长的全局线性求解，也不改变最终固定网格的 P1 输出契约。

### 受限目标类的条件可达性

设目标 \(F\) 是边界恒等的 \(C^{1,1}\) 正向微分同胚，满足统一奇异值下界 \(m>0\)、导数上界 \(M\) 和导数 Lipschitz 界 \(L\)。若粗层正好是 \(I_{2h}F\)，精确细化后每个新增顶点的目标残差 \(F(v)-I_{2h}F(v)\) 是 \(O(Lh^2)\)。每个交错 pass 只为尚未到位的新顶点指定该残差，旧顶点及已到位顶点取零。四-pass 覆盖保证最终顶点表是 \(I_hF\)。在任一受影响面，现有边是 \(O(Mh)\)、位移差是 \(O(Lh^2)\)，故不利项 \(C_T=O(MLh^3+L^2h^4)\)；而初始面积与目标允许余量是 \(\Omega(m^2h^2)\)。如果预设下界 \(\rho<m^2/8\)，并选足够细的 \(h\)，则所有目标 pass 的 \(s_P=1\)，且原始跨度 \(rph\) 大于 \(O(Lh^2)\)，所以有限 artanh latent 可以精确编码残差。这里的 \(O\)/\(\Omega\) 常数依赖规则三角网格与固定 \(p\)，尚未整理成锋利的显式尺度阈值；这是一个**条件构造论证**，不是当前 17 点 seed 加四-pass 实现对任意此类 \(F\) 的无条件普适性定理。起始粗层如何从恒等生成仍需要统一正则 isotopy 和可能较多的周期，参见 [F1 构造](01_refinement_reachability.md)。

上述存在性不保证 latent 从图像容易推断，不给低层数的统一表达误差率，也不证明所有边界固定 homeomorphism 可达。更不能把下面随机 latent 的速度与直接 latent oracle 的拟合误差拼成一条“同准确度速度”曲线。

独立目标的 direct-latent oracle 用解析形变生成目标网格，优化 patch latent 以最小化**顶点向量平方误差**；这使用目标坐标作监督，不是图像推断。\(E_{\rm v}=\sqrt{V^{-1}\sum_i\|Y_i-F(x_i)\|_2^2}\)。257² 高 32 周期目标的恒等初始误差 0.014627；单个四-pass 周期、500 步 Adam 后 \(E_{\rm v}=0.006676\)（采用不利项安全界）；四周期、1000 步及面积尺度保护后为 0.007428；进一步修复零不利项冻结后的相同 1000 步设置为 **0.006281**，最小 \(J_T=0.049991\)。因此多轮数值优化仍未达到可表示的目标。较早的绝对值界/未修复保护版本四周期曾到 0.003816，但它的反传数值故障使该数字不能作为稳定配置的成果。33² 局部旋转目标单周期 200 步可得 \(1.39\times10^{-7}\) 顶点 RMSE；257² 同族单周期 500 步为 \(5.44\times10^{-4}\)，显示规模与优化难度仍有问题。

为把表示性与优化困难严格分开，另以目标顶点表直接反编码每层 latent：[phase7_patch_teacher.py](../../tools/phase7_patch_teacher.py) 从 17² 恒等 seed 开始，先更新 seed 内点；每次精确细化后，只在四次交错 pass 的首次覆盖中给尚未到位的新顶点分配 \(\operatorname{artanh}((F(v)-Y_v)/(rph))\)，其余 latent 为零。这是已知目标的构造性 oracle，**不能**用于衡量图像网络推断。Element 主机空闲 L40 GPU1、float32、1025² 控制网格的结果：

### 紧凑 latent 与阶段式优化

原型最初为每个 patch pass 都预测整张 \((N-2)^2\) 内点 latent，再用索引取出本 pass 实际涉及的 patch 内点；这些未被选中的数在此 pass 的 VJP 恒为零。代码现在还接受仅对活跃 patch 内点存储的紧凑张量，测试验证两种布局在相同活跃数值下输出逐元素相同且紧凑 latent 可反传。Element 空闲 L40 GPU1、PyTorch 2.5.1+cu124、batch1、512² query、五次热运行中位数的**同卡**比较如下；不同随机形变，但同一分布与相同计算路径：

| 1025² 多尺度 patch 布局 | latent 标量 | full forward / VJP | 峰值 allocated / reserved | min \(J_T\) |
|---|---:|---:|---:|---:|
| 全内点张量 | 11,151,672 | 18.58 / 53.73 ms | 1203.22 / 1396.70 MB | .049826 |
| 仅活跃内点 | 8,463,966 | 17.99 / 50.86 ms | 1186.40 / 1367.34 MB | .049849 |

latent 数减少约 24.1%，但 allocated 只减少约 1.4%；主要显存成本是逐层 P1 更新的中间激活和 512² 图像取样，不是那些未用 latent。257² 同卡全/紧凑的 full forward/VJP 分别为 13.23/37.62 与 13.14/36.72 ms；紧凑布局并非数量级加速。前表 Turing A40 时间与此 Element L40 时间不可直接合并排名。

[阶段式 direct-latent 脚本](../../tools/phase7_fit_patch_pyramid_stagewise.py)采用**同一个已知独立目标**，从 17² 起每一级只优化本级四-pass 紧凑 latent 300 步，再精确 P1 细化到下一网格；每一级用目标顶点坐标监督，Adam。257² high32 的最终顶点 RMSE 为 \(2.5144\times10^{-6}\)、最大单坐标差 \(1.2958\times10^{-4}\)、最小 \(J_T=0.39055\)，用时 18.4 s；比先前直接在 257² 同时优化四个 patch 周期的 RMSE 0.006281 小很多，但层级结构、训练步总量和参数表均不相同，不能将差异单独归因于优化调度。

初次把同一阶段式方法扩到 1025² 时，所有层仍取 Adam 默认 \(\epsilon_{\rm Adam}=10^{-8}\)：512² 层的 RMSE 为 \(1.2305\times10^{-4}\)，1025² 层为 \(1.3936\times10^{-4}\)，最后一层几乎不能改善；按物理网格步长降低 fine 层学习率后，1025² 仍为 \(1.7194\times10^{-4}\)。定位发现该层**第一步对 latent 的最大梯度仅 \(7.1625\times10^{-13}\)**，默认 Adam 分母中的 \(10^{-8}\) 完全主导更新幅度。这是损失对全百万顶点取平均时的尺度效应，不能解释为目标表示缺失。保持尺度化学习率、300 步/层与全部其余设置不变，仅令 \(\epsilon_{\rm Adam}=10^{-12}\) 后，1025² high32 顶点 RMSE 为 **\(7.9550\times10^{-8}\)**、最大单坐标差 \(1.7881\times10^{-7}\)、最小 \(J_T=0.343628\)，7 个层级合计 27.9 s。各层输出均核对全脸正向。小 \(\epsilon\) 可能对噪声/其他目标不稳，需要更多独立目标与 batch 训练确认；此处是特定解析目标的 direct-latent oracle，不是 image-to-latent 结果。

同一设置将独立目标换成 high64，1025² 最终顶点 RMSE 为 **\(7.8184\times10^{-8}\)**、最大单坐标差 \(1.7881\times10^{-7}\)、最小 \(J_T=0.353088\)，七层合计 28.0 s。另一个不调用拟合循环的 [检查点重建脚本](../../tools/phase7_verify_patch_checkpoint.py) 从保存的七层 latent 与恒等 seed 重新正向执行 high64，逐层误差和最小面积均重现；末层仍为 \(7.8184\times10^{-8}\) 与 \(0.353088\)，非有限和非正向面数为零。high32 与 high64 检查点已复制到本仓库 [checkpoints](checkpoints/)；均为**使用真实目标坐标的单例阶段式 oracle**，既不是从图像推断，也不是百万控制点的网络训练。小 \(\epsilon_{\rm Adam}\) 对大规模平均损失的重要性由两目标重复支持，但“必然收敛”不由此成立。
