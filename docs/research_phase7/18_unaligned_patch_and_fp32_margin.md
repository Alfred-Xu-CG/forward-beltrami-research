# 半 patch 错位下的 F2 表示、训练与 float32 面积余量

## 问题、目标和拓扑先验

[对齐局部块实验](17_coherent_patch_vs_vertex_depth.md)里 F2 一个 pass 远快于所试 F1 调度，但目标窗口刚好落在单个 64-cell patch 内。这里保持 1025×1025 **控制顶点**、2,097,152 个 SW–NE 三角形、窗口宽度 64 个细单元及振幅 \(A=0.006\)，只把窗口在 x、y 方向都平移半个 patch：

\[
Q=[0.28125,0.34375]^2,\quad
W(x,y)=\sin^2\!\big(\pi(x-0.28125)/0.0625\big)
\sin^2\!\big(\pi(y-0.28125)/0.0625\big)
\]

在 \(Q\) 内，外部设 \(W=0\)，\(T=(x,y)+A W(1,1)\)。窗口一阶导数在边界为零；\(\|D(T-\mathrm{id})\|_\infty\le2A\pi/0.0625\approx0.6032<1\)，故连续图同胚。同样的边差分估计保证固定网格 P1 采样图全脸正向，实测最小归一化面积 \(J_T=0.60864258\)。目标与 [对齐版本](17_coherent_patch_vs_vertex_depth.md)仅有平移差异，难度变化来自 patch 划分，而非新的形变尺度。

## 一个 pass 的不可避免误差与重复调度

F2 的一个非重叠 patch pass 固定所有 patch seam 顶点。平移后的窗口穿过 seam，且某些 seam 顶点的目标位移范数达到 \(\sqrt2 A=0.0084853\)；因此该 pass 无论怎样选择 latent，都**不可能**逐顶点重现目标。按目标在可动内点的位移构造 oracle logits，输出顶点向量 RMSE \(1.52893\times10^{-4}\)，最大单坐标误差 0.006。此结论是固定 seam 的结构性限制，不依赖优化器。

为覆盖 seam，使用四种半 patch 错位 pass 并可重复循环。比较两种 latent 归属：`unique` 仅让一个顶点在首次覆盖它的 pass 运动；`all` 允许重叠 pass 反复修正同一顶点。对每个指定循环 \(c\)，oracle 在第 \(k\) 轮尝试中间图 \(\mathrm{id}+(k/c)(T-\mathrm{id})\)，对当前 pass 中每个允许移动的顶点以 `atanh(目标位移 / raw_span)` 提议，几何安全比例再依据 patch 全部面的精确算术面积下界裁剪。这是目标相关的**表示证据**，不是从数据学习到的参数。

| F2 调度 | pass 总数 | oracle RMSE | 最大坐标误差 | forward+VJP 中位秒 | 峰值 allocated GB |
|---|---:|---:|---:|---:|---:|
| 单个未错位 pass | 1 | \(1.52893\times10^{-4}\) | 0.006000 | 0.0096 | 0.442 |
| unique，1 循环 | 4 | \(1.45516\times10^{-4}\) | 0.005155 | 0.056 | 0.527 |
| unique，2 循环 | 8 | \(8.99720\times10^{-5}\) | 0.004300 | 0.105 | 0.590 |
| unique，4 循环 | 16 | \(3.06757\times10^{-5}\) | 0.001511 | 0.216 | 0.718 |
| unique，8 循环 | 32 | 0 | 0 | 0.426 | 0.975 |
| all，1 循环 | 4 | \(1.40493\times10^{-6}\) | \(9.45\times10^{-5}\) | 0.056 | 0.528 |
| all，2 循环 | 8 | 0 | 0 | 0.104 | 0.591 |

同一目标的 F1 线性中间图 oracle：4、8、16 pass 的 RMSE 分别 \(1.32237\times10^{-5}\)、\(2.00933\times10^{-7}\)、0，forward+VJP 分别约 0.122、0.240、0.484 秒。因而重叠 F2 的 8 pass 在此样本达到与所试 F1 16 pass 相同 float32 顶点精度，VJP 时间约为其 22%；但**不是** F1 最优深度下界。重叠 F2 每轮有效参数更多：四 pass 活动向量数分别为 1,016,064、952,560、952,560、893,025，总计每轮 3,814,209 个二维向量；两轮共有 15,256,836 个 scalar latent。上表 VJP 仅包含 decoder，不含训练、图像、query。全部实测输出和随机 cotangent VJP 有限且非零，oracle 输出的全脸最小 \(J\) 为 0.60864258。[脚本](../../tools/phase7_unaligned_patch_motion.py)。

## 从零直接拟合：表示不等于可训练

Turing A40 GPU0、PyTorch 2.8、float32、batch1，使用上面的两循环重叠 F2，15,256,836 个独立 fine latent 全零初始化；只以所有目标顶点的向量均方误差训练，Adam 学习率 0.01、余弦退火 300 步、eps \(10^{-12}\)，loss 乘 \(10^6\)。**仅最终图损失**得到 RMSE \(4.04744\times10^{-5}\)，最大坐标误差 0.002295，最小 \(J=0.1810\)，训练步中位 0.1076 秒、峰值 allocated 0.706 GB。它没有学到精确 oracle。

再加一项权重 1 的中间图损失，使第一循环输出靠近 \(\mathrm{id}+0.5(T-\mathrm{id})\)。同样 300 步所得 RMSE 反而为 \(4.50734\times10^{-5}\)。更严重的是，`minimum_jacobian=None` 的 float32 输出最小 \(J=-3.4511\times10^{-5}\)：因此不能称这次训练结果为 P1 homeomorphism，尽管连续/精确算术的面积限制推导是正确的。此负结果不是“QC 恢复”误差，而是 decoder 在有限精度下的核心拓扑条件被破坏。

## 数值故障定位及当前结论

对上述同一批训练 latent 逐 pass 测量最小 float32 \(J\)，数列为 0.321、0.0519、0.00811、0.00127、0.000178、0.0000371、\(-0.0000211\)、\(-0.0000345\)。把**最终 float32 顶点**转成 float64 后重算面积仍为负，因此不是检查器 float32 交叉积的假阴性。反之把相同 float32 latent 转为 float64、从 identity 重新执行 8 个 pass，最小 \(J=7.61838\times10^{-6}>0\)。两次解码输出最大坐标差 \(9.64\times10^{-8}\)，足以使已经极薄的三角形翻号。根因是多 pass 的安全比例允许面积趋近零，而返回顶点的 float32 舍入没有被精确算术证明覆盖；它不是面积多项式符号实现错误。

启用现有 `minimum_jacobian=0.05` 再做中间损失实验，float32 输出最小 \(J=0.04999194>0\)，同顶点转 float64 验证为 0.04999195；同 latent 用 float64 解码为 0.05。**这一样本**的数值拓扑恢复，但 RMSE 变为 \(5.98787\times10^{-5}\)，并且若干 pass 被面积 floor 卡住。不能由单次测试宣称固定 0.05 floor 对任意有限 latent、任意网格尺度均提供严格 IEEE 浮点证书。其精确算术保证和实测浮点余量必须分开。后续应比较 float64 顶点解码、明确的浮点误差预算、以及与 stage-wise/tied-latent 优化配合的表现；也应避免把无 floor 的 `float32` 结果标为“无条件保证拓扑”。
