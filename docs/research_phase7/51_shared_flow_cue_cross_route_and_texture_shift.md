# 同一局部图像提示的三条正向路线复核与纹理转移反例

## 对照假设

[前文](50_local_flow_feature_same_decoder_ablation.md)在混合解码器中加入局部 2×2 ridge-flow 特征后观察到显著的同分布改善。这里检验两个互不等价的问题：第一，这种收益是否独属于混合粗 patch／细顶点路线？第二，图像编码器是否学到了对**未见过纹理类型**仍稳健的位移推断？后一个问题不涉及解码器本身的拓扑定理。

F1 是四着色单顶点安全更新，F2 是四个错位局部 patch pass，H 是 17²粗 F2 patch＋细级 F1 只更新新顶点。三者都从网络 latent 正向生成固定规则网格上的一张 P1 地图，没有全局大线性系统。F1、F2 使用 float32 坐标且训练时仅逐步检查面符号；H 使用 float64 并在最终输出执行二进制坐标符号筛选。因此下面是完整实现比较而不是只改变局部模块的纯消融。新128例评价对 F1/F2 也加上同一个最终保守筛选；所有这些例子都没有恒等回退。

共同任务为 `high32`：32 训练图像对、8 开发对、新128测试对，源随机种子分别 55101、99317、939031；每对的固定图由移动图按独立解析真地图采样合成。512² 图像也是512²查询，而不是控制顶点规模。257²控制网格有66,049顶点/131,072三角面，1025²控制网格有1,050,625顶点/2,097,152三角面。batch2，257²从零训练1000步，1025²由对应257²检查点扩展两个零初始化新层 head、续训600步，后者训练所有参数；只用图像 MSE 监督。GPU为同一主机RTX A6000，PyTorch2.5.1+cu124。指标定义与本实验的图像/地图公式在[文档50](50_local_flow_feature_same_decoder_ablation.md)。

| 控制网格 | 解码器 | 无提示新128 image MSE / map RMSE | 有提示新128 image MSE / map RMSE | 有提示最小 J | 有提示训练中位步时 / allocated峰值 |
|---|---|---:|---:|---:|---:|
| 257² | F1 | .00111417 / .00393484 | .00027143 / .00231800 | .04999 | **87.14 ms / .392 GB** |
| 257² | F2 | .00099410 / .00368805 | .00030291 / .00209351 | .05001 | 115.35 ms / .438 GB |
| 257² | H | .00109182 / .00382517 | **.00014130 / .00166472** | .10285 | 131.91 ms / .473 GB |
| 1025² | F1 | .00076326 / .00325775 | .00017514 / .00173456 | .04990 | **142.64 ms / 1.748 GB** |
| 1025² | F2 | .00047756 / .00281803 | **.00009265** / .00132628 | .04991 | 252.14 ms / 2.674 GB |
| 1025² | H | .00060433 / .00291193 | .00010419 / **.00129863** | **.13537** | 221.10 ms / 2.921 GB |

结果支持“局部提示主要缓解图像到 latent 的推断瓶颈，而且不是 H 独有”的判断。257²上 H 的两个误差最低；1025²上 F2 的 image MSE 最低、H 的地图坐标 RMSE 略低、F1 最省时省显存。1025² F2/H 两者地图误差差距只有约2%，这里只有一个训练种子，不能声明统计优越性。F2 与 H 的内在参数化、起始网格与数值精度不同；若要判断原语本身的贡献，还需同精度同 seed 布置及多个初始化。F1/F2 的最小 J 低于名义 .05 安全底线约 1e-4，属于 float32 面积比的舍入范围，仍为正；H 使用 double 的最小 J 明显更高，但这可能是被学出的地图本身不同，并不能归因于 double 精度。

检查点：[F1 257²](checkpoints/phase7_matched_colored_flow257_high32_image1000.pt)、[F1 1025²](checkpoints/phase7_matched_colored_flow1025_high32_transfer600.pt)、[F2 257²](checkpoints/phase7_matched_patch_flow257_high32_image1000.pt)、[F2 1025²](checkpoints/phase7_matched_patch_flow1025_high32_transfer600.pt)；H 的检查点见文档50。

## 保持地图与样本不变，只换移动图纹理

为避免把相同合成纹理的随机相位误称为外部分布验证，在 128 个新样本上固定同一解析真地图及其形变系数，替换移动图 $I_M$，再从该移动图重新生成固定图 $I_F(x)=I_M(F(x))$。`standard` 是训练时的正弦加 Gaussian 斑纹；`spots` 是六个随机有符号 Gaussian 光斑加很弱线性背景；`crosswaves` 是四个新的、与训练载波频率和方向不同的交叉波。`spots` 存在大片低纹理区域，位移本身可能局部不可辨识。纹理构造在[评价脚本](../../tools/phase7_train_forward_pyramid_image.py)的 `replace_test_appearance`，测试证实同一张真地图未改变并重新按该图 warp 移动图。没有在这些新纹理上更新权重；下面所有结果都是旧检查点零重训评价，控制网格仍为1025²、查询512²。

| 新128纹理 | 模型 | image MSE | query-map RMSE | 最小 J / 回退 |
|---|---|---:|---:|---:|
| `standard` | 恒等图 | .00762082 | .01025128 | 1 / 128恒等 |
| `standard` | H 无提示 | .00060433 | .00291193 | .75082 / 0 |
| `standard` | H＋提示 | .00010419 | .00129863 | .13537 / 0 |
| `standard` | F2＋提示 | .00009265 | .00132628 | .04991 / 0 |
| `spots` | 恒等图 | .00006892 | .01025128 | 1 / 128恒等 |
| `spots` | H 无提示 | **.00000601** | **.00307474** | .82838 / 0 |
| `spots` | H＋提示 | .00001274 | .00891357 | .43801 / 0 |
| `spots` | F2＋提示 | .00001300 | .00872790 | .42090 / 0 |
| `crosswaves` | 恒等图 | .02622710 | .01025128 | 1 / 128恒等 |
| `crosswaves` | H 无提示 | .00340076 | .00353881 | .19934 / 0 |
| `crosswaves` | H＋提示 | **.00101603** | **.00195896** | .05000 / 0 |
| `crosswaves` | F2＋提示 | .00106069 | .00203311 | .04986 / 0 |

`spots` 行是一个重要反例：局部提示版本虽然在标准纹理上领先，却在稀疏新纹理的地图 RMSE 从 .00130 升至约 .0089，接近恒等图 .01025，而且比无提示 H 的 .00307 明显差。其 image MSE 依然极小，只说明多数像素缺乏足够纹理约束，**像素误差不能替代位移精度**。`crosswaves` 上有提示的两个架构仍优于无提示 H，但误差也高于各自标准纹理。这既不否定局部提示在训练族上的价值，也不支持“已解决跨纹理泛化”；安全解码器始终保持正向面与零回退，但拓扑正确与图像推断正确仍是两件事。后续应该比较增加纹理多样性的训练、匹配置信度或遮罩条件，并使用自然图像数据验证，不能在同一个稀疏纹理测试集上反复调参后再把它称为盲测。
