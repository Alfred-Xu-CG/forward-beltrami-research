# 同一图像任务的 F1、F2、混合层对照，以及分布外失配

## 对照到底固定了什么

在[混合层的首次训练](48_hybrid_image_training_and_fine_transfer.md)之后，重新用同一个[脚本](../../tools/phase7_train_forward_pyramid_image.py)在同一AI A6000主机的空闲GPU2/7训练两种既有正向金字塔：F1从5² seed、2次四着色顶点更新开始；F2从17² seed、每级4个交错patch pass开始；混合层从17² seed、单endpoint field经4轮F2粗patch、后续每级一次F1四着色开始。三者都输出预定规则三角网格的一张P1地图，不是复合映射的采样。各网络使用同一width16图像主干、512²图像、`high32`随机生成器、32训练seed55101/8开发保留seed99317、batch2、Adam同一学习率和步数；新128例seed939031完全不用于训练。

257²阶段从零训练1000步，学习率$.003$、Adam $\epsilon=10^{-8}$；1025²阶段精确加密并添加零初始化513²/1025²输出head，从各自257²检查点续训600步，学习率$.001$、$\epsilon=10^{-12}$。两阶段均只以图像像素MSE反传。目标地图用于事后评价；具体生成、指标公式、目标连续同胚的导数界参见[前文](48_hybrid_image_training_and_fine_transfer.md)。GPU2/7均为RTX A6000，PyTorch2.5.1+cu124；但F1/F2整个decoder坐标是float32，混合层是float64，且F1/F2训练期间只逐步检查面符号、**未**启用末端保守二进制坐标筛选。最终1025²新128例另外加相同[保守筛选](22_numeric_certified_joint_layer.md)复算，F1/F2均0/128回退、输出地图和指标完全不变；混合层筛选内置。因此下表是统一数据和训练预算下的**实现级别**比较，不是只改变原语的纯消融，也不是严格相同数值安全开销的速度排行榜。三种CNN参数量在1025²分别14,852、15,464、14,750。

| decoder | 257²新128 image MSE / query-map RMSE | 257²训练中位步时 / CUDA峰值 | 1025²新128 image MSE / query-map RMSE | 1025²新128最小$J$ | 1025²训练中位步时 / CUDA峰值 |
|---|---:|---:|---:|---:|---:|
| F1全级顶点 | .00111417 / .00393484 | 85.85 ms / .389 GB | .00076326 / .00325775 | .77012 | **143.90 ms / 1.745 GB** |
| F2全级patch | **.00099410 / .00368805** | 112.23 ms / .435 GB | **.00047756 / .00281803** | **.04994** | 252.56 ms / 2.670 GB |
| F2 seed＋F1新点 | .00109182 / .00382517 | 128.41 ms / .471 GB | .00060433 / .00291193 | .75082 | 222.56 ms / 2.920 GB |

每个1025²输出有1,050,625控制顶点、2,097,152个原三角面，图像只有512²查询点。新128例的恒等地图基线为image MSE $.00762082$、map RMSE $.01025128$。三者均改善基线，但没有一个接近相应独立解析目标的[teacher精度](47_hybrid_patch_seed_vertex_refinement.md)。F1在当前设置速度/显存最佳而误差最大；F2测试误差最低，但许多面接近预设$.05$的归一化安全底线，所列全局最小$J=.04994$来自float32舍入而不是数学上的严格底线被负向突破。混合层处于两者之间，**没有**在这组统计任务中同时压倒F1/F2；其优势更具体：大尺度粗patch允许相邻顶点共同运动，而细级不用F2四patch pass，且[强目标teacher](47_hybrid_patch_seed_vertex_refinement.md)在17²/4粗阶段精确达到F1/4阶段曾被截断的目标。几组速度无法推断普适Pareto前沿。

各1025²新128检查点：[F1](checkpoints/phase7_matched_colored1025_high32_transfer600.pt)、[F2](checkpoints/phase7_matched_patch1025_high32_transfer600.pt)、[混合](checkpoints/phase7_hybrid_1025_high32_transfer600.pt)；相应257²初始化：[F1](checkpoints/phase7_matched_colored257_high32_image1000.pt)、[F2](checkpoints/phase7_matched_patch257_high32_image1000.pt)、[混合](checkpoints/phase7_hybrid_257_high32_image1000.pt)。训练记录包含粗细head首步非零梯度、每步正向检查与独立128例；没有多随机初始化均值/方差，不能对几百分点误差差距给统计显著性结论。

## 混合层的零重训分布外测试

固定已训练1025²混合检查点，在同一个新seed939031再生成128例、只换目标族。`high64`把细频率从32周期改为64周期，同时也减小了高频系数，低频幅度范围不变；`base`把主形变幅度显著加大，并换为8周期的细项。所以两行不是“只改变频率”的因果消融，而是不同变形分布。都与训练网络共享图像纹理生成器，不是自然图像外部验证。

| 新128目标族 | 单位图image MSE / map RMSE | 已训练混合层image MSE / map RMSE | 最小$J$ / 回退 |
|---|---:|---:|---:|
| high32，训练同族新样本 | .00762082 / .01025128 | .00060433 / .00291193 | .75082 / 0 |
| high64，更高频但更小系数 | .00758563 / .01022455 | .00056408 / .00281756 | .75082 / 0 |
| base，更强主形变 | .03214869 / .02348542 | .01118231 / .01314593 | .35937 / 0 |

保持拓扑并不意味着几何准确。base行地图RMSE较训练同族高4.5倍，虽然相对自身单位图仍改善；image误差变化还受纹理及真形变幅度影响，不能简单拿不同族的绝对image MSE当泛化评分。高频64行未崩溃，也不能证明频率泛化：其细项幅度按生成器规则减半，低频误差仍可能主导总RMSE。需要固定低频/幅度仅改频率、加入局部位移或旋转、与自然图像/外部数据对照，才可更严谨测试图像编码器的表达边界。下一步若优化编码器，目标应是同族与这些压力族**同时**改善，而不是牺牲地图精度换一个更低的像素残差。
