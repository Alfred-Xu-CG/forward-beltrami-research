# 独立纹理多视图使4097²前向 P1 层从光度反馈中恢复细节

## 问题与数学机制

[单通道 image-only 训练诊断](67_map_supervision_identifiability_diagnostic_4097.md)显示，小像素残差并不保证细位移正确。这里不改解码器拓扑架构、控制网格或任何训练权重，只问：**若同一个未知形变同时作用于若干独立纹理通道，多出的观测是否使现有局部前向反馈恢复准确几何？** 这不是普通单幅灰度图配准实验；它是研究观测可辨识性和细网格算法容量的受控诊断。

在固定4097² P1 映射 $F$ 的当前顶点，设第 $c$ 个移动纹理 $I_{M,c}$、固定纹理 $I_{F,c}$ 满足理想关系 $I_{F,c}(x)=I_{M,c}(F_*(x))$。对小校正 $d=F_*-F$ 作一阶展开，

$$
r_c(x):=I_{F,c}(x)-I_{M,c}(F(x))
\approx \nabla I_{M,c}(F(x))^\top d(x).
$$

在原控制网格的 $3\times3$ 邻域 $W(x)$ 上，代码用每通道平均的局部正规方程

$$
G(x)=I+\frac1C\sum_{c=1}^C\langle g_cg_c^\top\rangle_{W(x)},\qquad
b(x)=\frac1C\sum_{c=1}^C\langle g_cr_c\rangle_{W(x)},\qquad
d_{\rm lin}(x)=G(x)^{-1}b(x),
$$

其中 $g_c$ 是在当前映射上取样的移动纹理空间梯度，$I$ 是ridge=1的2×2单位矩阵，$C$ 是纹理通道数。每个顶点只需一个显式2×2求解，**没有随顶点数增长的全局线性系统**。然后按当前网格间距 $h$ 把 $d_{\rm lin}$ 转成有限 logit，乘已训练增益，经[四着色局部安全更新](../../src/qcopt/neural_bijection/dense/colored_vertex_relaxation.py)执行；其原面定向条件与通道数无关，最终存储的全部原三角面还由[保守证书](../../src/qcopt/neural_bijection/dense/multilevel_forward_p1.py)检查。细化1025→2049→4097仍是原 P1 映射的精确 dyadic 细化，再修改**真正的细控制顶点**，不是把低分辨率结果插值冒充4097²同胚。多通道局部公式见[实现](../../src/qcopt/neural_bijection/dense/photometric_hint.py)与[重复通道不变性/VJP单元测试](../../tests/test_phase7_local_feedback.py)。

一阶模型说明为何独立通道可能有用：单通道在单点只能提供一个梯度方向；四个独立纹理可使局部 $\sum_cg_cg_c^\top$ 的两个特征值都较大，减少横向位移的不确定性。这里没有测量所有原顶点的谱下界，**不**据此宣称全域强凸或全局收敛定理；真实映射误差、非线性重采样和安全截断也超出该线性解释。复制同一通道不会增加梯度张成的方向，提供一个明确的阴性对照。

可把这个动机写成一个**仅对理想局部模型**成立的误差界。假定窗口内真实校正是同一个向量 $\delta$，各移动纹理二阶导的算子范数至多 $M$、梯度范数至多 $G_0$，固定纹理满足无噪声精确亮度守恒，局部均值和取样也精确。令 $S=C^{-1}\sum_c\langle g_cg_c^\top\rangle_W$，其最小特征值为 $\lambda\ge0$，ridge 为 $\rho>0$。Taylor 余项给 $r_c=g_c^\top\delta+e_c$、$|e_c|\le M\|\delta\|^2/2$。由于 $b=S\delta+C^{-1}\sum_c\langle g_ce_c\rangle_W$，2×2解满足

$$
\|d_{\rm lin}-\delta\|
\le\frac{\rho\|\delta\|+G_0M\|\delta\|^2/2}{\rho+\lambda}.
$$

证明只是把 $d_{\rm lin}-\delta=(S+\rho I)^{-1}(-\rho\delta+\frac1C\sum_c\langle g_ce_c\rangle_W)$ 取范数。这解释了独立梯度使 $\lambda$ 增大时的局部潜在收益，但**不**覆盖空间变化的 $\delta$、图像离散插值误差、噪声、窗外大位移或拓扑安全更新的非线性，也不构成当前实测误差的定量预测。

## 数据、参数与输出契约

沿用[单通道已训练阶段一编码器](checkpoints/phase7_hybrid_feedback_w3_float32_train500.pt)和[4097²两标量增益](checkpoints/phase7_extra_gains_4097_float32_train500.pt)，**多通道条件下没有重新训练任何权重**。粗编码器只读取第一通道；各细级局部光度公式读取全部 $C\in\{1,2,4\}$ 通道。第一通道始终相同；其余通道从相同随机纹理生成机制的独立种子构造移动图像，随后用**第一通道样本的同一个真值映射**重采样得到对应固定图像；额外纹理生成器自己的形变完全丢弃，绝不把它偷偷当作真值提示。512²图像/query、batch1推理，控制网格为4097²，即16,785,409个原顶点、33,554,432个原三角面。两套各128例种子20270129和20270215均未参与这两个权重的训练。图像使用float32，几何与证书使用float32并以float64重算最小 $J$。所有例子先经1025²、再2049²、4097²，新增两级各一轮局部更新。

map RMSE 是在512²查询位置的预测二维坐标与生成真值之差的欧氏均方根；mode RMSE 是两坐标位移在 $\phi(x,y)=\sin(256\pi x)\sin(256\pi y)$ 上投影系数的误差均方根，不代表全频谱误差。image MSE 是所有通道、所有像素的平均平方残差。最小 $J$ 是各实际原面有向面积除恒等面面积后的最小值。K通道不是K个不同形变或K次串联层，而是**同一形变的K组独立观测**。

| 控制网格 / 图像通道 | seed20270129：map / mode RMSE | seed20270215：map / mode RMSE | seed20270215 image MSE | seed20270215 最小 $J$ / 通过 |
|---|---:|---:|---:|---:|
| 4097² / 1 | .00050394 / .00013643 | .00048257 / .00013647 | 2.003e-8 | .049294 / 128/128 |
| 4097² / 2独立 | .00011402 / .00002267 | .00011039 / .00002217 | 7.178e-9 | .049468 / 128/128 |
| 4097² / 4独立 | **.00001576 / .00000481** | **.00001523 / .00000459** | **3.316e-9** | .049737 / 128/128 |
| 4097² / 4份**重复第一通道** | 未测 | **.00048257 / .00013647** | 2.003e-8 | .049294 / 128/128 |
| 1025² / 4独立 | 未测 | .00007847 / .00012115 | 3.368e-7 | .049969 / 128/128 |

重复第一通道的所有几何指标与1通道**逐项相同**；这排除“通道数变大本身、张量运算或有效ridge缩放”解释了收益。四个独立通道在第二组把 map RMSE 相对一通道降低约31.7倍，而同样四通道仅输出1025²时仍高约5.2倍；因此**额外纹理信息和真实细控制网格都起作用**。所有通过计数指对整张4097²原网格逐面筛选，不是只检查512²采样点。正向安全性仍独立于图像来源；这些统计不能证明任意合法 latent 不回退或所有真实图像准确。

## 对未训练过的目标载波与计算成本

另以seed20270215、128例、同样标准纹理测两个**训练时未出现的形变族**，且仍未调整权重：

| 4097²目标族 | 1通道 map RMSE | 4独立通道 map RMSE | 4通道指定 mode RMSE | 4通道最小 $J$ / 通过 |
|---|---:|---:|---:|---:|
| 三个高频载波 `high128_tri` | .00045115 | **.00001420** | .00000135 | .049674 / 128/128 |
| 16个空间包 `high128_tiles` | .00043197 | **.00001397** | .00000030 | .049770 / 128/128 |

`mode RMSE` 在这些复杂目标只测一个指定对角载波，不能代替总 map RMSE；后者才是各模式共同的几何指标。三族 4 通道 map RMSE 都在约1.4—1.5e-5，但纹理分布仍与训练生成器一致，未测试自然图像、多模态真实扫描或噪声/遮挡。

AI远程主机当时空闲的RTX A6000 48GB、PyTorch2.5.1+cu124；同一4097²模型batch1、seed20270215、count16、5次同步热态计时，包含完整细级前向、最终面证书、查询/图像取样；VJP含编码器及全部增益的完整反传。两列为CUDA allocated峰值，不是进程实际总显存；一次性setup约16—20秒另计。

| 通道 | 热态 forward 中位 | forward峰值 | forward＋VJP中位 | VJP峰值 |
|---|---:|---:|---:|---:|
| 1 | .1322秒 | 5.158GB | .7854秒 | 12.826GB |
| 4独立 | .1430秒 | 5.523GB | .8409秒 | 13.659GB |

四通道相对单通道，完整 VJP约慢7.1%、allocated峰值多6.5%，在该GPU上都有限且可反传。不能从A6000结果直接推出16GB GPU能运行，尤其需考虑reserved和驱动余量。更不能把四独立视图的近1e-5误差作为普通单图注册成绩。它告诉我们：本正向固定P1层在足够可观测的合成输入上，确能以4097²原控制网格逼近较细形变；现阶段单图性能的主要矛盾之一是从图像恢复正确位移的信息/优化，而非必须回到大矩阵逆解。
