# 未知频率加未知空间包络：1025² P1 image-to-latent 多步训练

## 目的与非目标

[频谱实验](33_unknown_carrier_fft_encoder.md)表明，只给三个固定频率模板会在邻近频率失败，而一次图像频谱估计加少量候选光度复核在合成无噪声整数频率族上可较好恢复频率。这里进一步问：当每例频率 \(k\in\{80,\ldots,128\}\)、局部包络位置和位移向量均未知时，是否能在保持**固定原网格 P1 同胚**的条件下，让一个可训练网络从图像估计空间变化的高分辨率 latent，并完成真实反向训练？本实验仍有强先验：载波形式为 \(H_k=\sin(2\pi kx)\sin(2\pi ky)\)，同一整数 \(k\) 用于两轴，有限已知频率范围，随机 Fourier 合成纹理。它不是任意形变或自然图像注册结论。

目标位移、包络分布、随机纹理、固定图由真值 P1 图一致采样的成像协议见[前两节](33_unknown_carrier_fft_encoder.md)。训练256例 seed31719，独立保留128例 seed99113；两个集合的位置、向量、频率与纹理均重新采样。每例实际控制输出1025×1025顶点、2,097,152个SW–NE三角面，图像另为512×512。

## 架构、可微性边界与训练协议

图像前处理先对 \(r\,I_{m,x}\)、\(r\,I_{m,y}\) 作512² FFT，在49个整数候选中找频谱top12；对这12个频率分别估计窗口17、ridge1的局部幅度，并按解析光度改善分数选择一个频率 \(\hat k\)。此步在数据预处理时完成，**top-k/argmax不可导**，不通过损失训练。随后用 \(\hat k\) 解调的两通道512²幅度降采到128²；一个13,938参数的残差卷积网络预测128²幅度改正，双线性升到1025²，乘 \(H_{\hat k}\) 得细顶点候选位移。再通过 \(\operatorname{atanh}[\operatorname{clip}(u/(2h),-.95,.95)]\) 构造细 latent，粗257² patch latent固定为零，经[联合安全层](22_numeric_certified_joint_layer.md)给出**一张固定1025² P1图**。网络参数到输出的路径由普通自动微分完整覆盖；细 latent 两通道梯度经过四颜色安全更新及输出筛选回传。它并非“图像到频率到地图的每一步都可微”，所以不能把整条管线无条件叫作 end-to-end differentiable registration network。

网络最后卷积零初始化，训练前严格等于解析解调的降采样幅度。Adam学习率.001、batch4、600步。map监督损失为 \(10^8\) 乘所有控制点的向量平方误差均值；image-only损失为 \(10^6\) 乘经固定P1 query与图像双线性采样后的512²像素MSE。两种训练均更新同样的卷积参数，频率前处理固定。脚本为[完整训练](../../tools/phase7_train_unknown_frequency_spatial.py)。评价指标公式沿用[前文](28_unknown_fine_packet_demodulation.md)。

训练样本的频率识别成功率未在本脚本最终 JSON 中单独输出，不应把留出128/128偷换成训练集全部正确。已知真实细 latent 的同族 P1 目标地图误差可达约 \(10^{-13}\)（见[oracle频谱实验](33_unknown_carrier_fft_encoder.md)）；所以保留误差主要来自空间幅度的图像推断/学习及其有限网络容量，不是固定P1层无法表达。两种监督都改善几何，但 map 监督在600步时还同时得到更低像素误差；这表示该训练预算下 image-only 尚未达到相同解，不能声称 map 目标在一般情形优于优化充分的图像目标。

设备为 AI A6000 GPU2，PyTorch2.5.1+cu124，图像/网络/latent float32，几何内部及输出 float64，实际输出逐面筛选启用。训练数据已预先留在GPU；不计预处理，map/image平均训练步分别133.95/136.24ms，包含128²网络、1025²解码及所选损失的全反传。完整样本库常驻时的 CUDA peak allocated 分别15.851/15.874GB，**包含256+128例的百万点真值、支撑掩码、预计算细频载波与图像**，不是网络或单层本身的显存。另以仅4训练+4测试例、同batch4、40步 image-only 作隔离探针，峰值3.977GB、约141.9ms/步；仍包括8例数据，不等于裸 decoder 峰值。纯 decoder 批1口径另见[单层报告](22_numeric_certified_joint_layer.md)。

## 目前真正取得与未取得的东西

此实验把“图像编码器知道唯一载波”的窄先验扩到**每例频率未知、频率集合有49项、局部位置和方向未知**，并在百万控制顶点网格上进行了真实多步训练、留出几何检查、完整P1拓扑检查。它尚未摆脱给定载波函数族、整数同轴频率、合成纹理或硬频率选择；在噪声 \(\sigma=.01\) 的前处理已发生明显失败。当前最重要的下一步不是再声称拓扑安全性，而是设计不显著牺牲频率准确率和速度的**可微频率混合或连续频率估计**，并在有噪/多尺度目标上检验空间幅度网络的几何效果。
