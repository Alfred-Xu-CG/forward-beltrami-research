# 四视图前向反馈的剩余误差：P1节点参照、更新轮数、噪声和再训练

## 为什么还要核对近 (10^{-5}) 的误差

[四独立纹理4097²实验](68_multiview_observability_4097_p1.md)把无噪声合成 high128 的 map RMSE 从单通道约 (4.8\times10^{-4}) 降到约 (1.5\times10^{-5})，但这不等于“已达到固定规则P1网格分辨率所允许的误差”。本节固定同一网格、数据生成器与指标，分别核查一个**已知真值的节点插值参照**、局部更新轮数与增益、重新训练及独立像素噪声。所有对照都不放松原面同胚筛选。

## 已知解析真值的节点P1参照

对 high128 家族，数据生成器的真值映射是

$$
F_*(x,y)=\left(x+a_x B(x,y)+a_f H(x,y),\quad
y+a_y B(x,y)+a_f H(x,y)\right),
$$

其中 (B=\sin(2\pi x)\sin(2\pi y))、(H=\sin(256\pi x)\sin(256\pi y))，三个系数由数据生成器逐例抽样。**作为oracle参照**，在原规则网格每个控制顶点直接代入该公式，作原三角剖分P1延拓 (I_hF_*)，再在同一512²查询点比较于解析 (F_*)。这完全不使用图像推断，因此是“该具体节点采样映射”的误差，**不是**全部P1同胚的严格最佳近似下界；另一个P1顶点表可能在这些查询点更准确。[复算工具](../../tools/phase7_high128_nodal_teacher_floor.py)及所用系数来自[合成数据生成器](../../tools/phase6_train_multisample_image.py)。

| seed20270215、128例 | 1025²控制顶点 | 4097²控制顶点 |
|---|---:|---:|
| 解析真值节点P1，512²查询 map RMSE | **1.6376e-5** | **1.0708e-6** |
| 四视图前向图像反馈 map RMSE | 7.8469e-5 | 1.5232e-5 |
| oracle节点表最小原面 (J) | .59492 | .56910 |

四视图4097²图像模型约是其4097²解析节点参照误差的14.2倍，仍有算法/可观测/训练余量。由1025²到4097²的真值节点误差显著下降，也证明细网格存在真实的表示空间；仅输出1025²并多作512²查询无法替代4097²原控制网格。

## 轮数和增益：不是越多越好

在四视图、固定已训练单通道细级增益、4097²、seed20270129 的16例**开发子集**上，新增2049/4097级各多做一轮或两轮，反而把 map RMSE从约 (1.5\times10^{-5}) 提高到 (3.07\times10^{-5})（每级2轮）和 (2.23\times10^{-5})（每级3轮）；两轮指定高频模态误差约 (4.76\times10^{-5})，明显高于一轮。这与把当前局部光度线性步长简单重复会过冲或在安全约束下非单调的解释相容，但实验没有给出严格动力系统收敛/发散证明。另保持一轮、两新增级共同乘尺度0.5、0.75、1.25、1.5，在同16例上的 map RMSE 分别约 (3.53,2.15,1.60,1.96\times10^{-5})；原尺度1的128例为 (1.576\times10^{-5})。因为16例和128例数不同，这里**不**从微小差距选一个“最佳尺度”；没有证据说明统一缩放比原设置稳定优越。所有方案经最终面筛选通过。

直接以四独立纹理的 image MSE 继续训练两个新增级增益500步，是另一个更公平的调参测试：训练仍用32例seed55101、batch1、float32、Adam学习率.001，把目标乘 (10^6) 仅作梯度数值尺度；从单视图已训练增益(0.9054,2.0176)开始，得到(0.9762,2.0826)。500/500步拓扑通过，训练步中位.662秒、CUDA allocated峰值13.791GB。独立128例对照：

| 测试种子 | 原单视图权重直接用于四视图 map RMSE / image MSE | 四视图再训练增益 map RMSE / image MSE |
|---|---:|---:|
| 20270301 | 1.4851e-5 / 3.257e-9 | 1.4590e-5 / 3.119e-9 |
| 新种子20270317 | 1.4974e-5 / 3.484e-9 | 1.4681e-5 / 3.329e-9 |

这是两组约2%的小幅改善，远小于“由1通道变4独立通道”的提升。四视图训练后的[两增益检查点](checkpoints/phase7_extra_gains_4097_multiview4_train500.pt)保存在D盘；不把这些标量调优误写成训练了一个4097² dense latent 网络。

## 独立采集噪声揭示的实际边界

对同一128例seed20270215，在每个固定和移动图像通道的每个像素**独立**加入均值0、给定标准差 (\sigma) 的高斯噪声；真值几何和权重不变，随机种子固定。noise MSE的基线不是0，因为固定与移动采集噪声独立。全部输出依然通过原4097²面筛选，下表给出四视图模型的几何指标；预滤波只用于局部光度线索，粗编码器和评价图像仍读取原有含噪观测。`blur .5/1` 是512²像素坐标中的可分离高斯标准差；`window` 是**4097²控制顶点**邻域的边长，原值3。

| σ / 局部线索 | map RMSE | 指定 high128 mode RMSE | 最小 (J) |
|---|---:|---:|---:|
| 0 / window3 | 1.523e-5 | 4.592e-6 | .049737 |
| .0002 / window3 | 3.872e-5 | 4.620e-6 | .049741 |
| .001 / window3 | 1.7336e-4 | 5.905e-6 | .049691 |
| .001 / window9 | 1.4790e-4 | 4.909e-5 | .049884 |
| .001 / window17 | 1.3828e-4 | 1.616e-4 | .049930 |
| .001 / window3＋blur .5 | 1.3157e-4 | 1.072e-4 | .049737 |
| .001 / window3＋blur 1 | 1.4032e-4 | 2.502e-4 | .049742 |
| .005 / window3 | 6.9421e-4 | 3.693e-5 | .048994 |
| .005 / window3＋blur .5 | 5.4322e-4 | 1.140e-4 | .049019 |

单通道在 σ=.001、相同128例上的 map RMSE为 (5.985\times10^{-4})：四视图仍明显较好，但其无噪声近 (10^{-5}) 结果**非常脆弱**。扩大原控制格上的平均窗口或先高斯平滑，能降低总 map RMSE，却大幅破坏 high128 细模态；不能据一项改进就宣布“去噪成功”。局部窗口3对应的物理宽度 (3/4096)，小于512²图像一个像素宽，噪声在这层高分辨率反馈里会被图像梯度差分放大。这是可能的机制解释，仍需更直接的噪声谱与条件数诊断；不能当成严格因果证明。

**阶段判断。** 无噪声多独立视图证明了安全正向细网格层有很强的可用表达/局部恢复潜力，且不依赖大矩阵逆；但真实数据会有噪声、遮挡、通道失配和单图信息不足。下一步需要一个在图像像素尺度进行噪声建模、又保留细模态的多尺度局部估计器，例如跨通道稳健匹配或显式噪声协方差加权，而不是盲目增加控制点轮数或对所有频率做同一种模糊。本文只建立对照与失败边界，不声称已解决这一难题。
