# 4097² 空间局部修正训练：可反传，但未突破几何精度

## 为什么在两标量之后再试空间修正

[4097²细层增益实验](65_trained_4097_extra_feedback_gains.md)表明，把2049²和4097²新增两级的两个全局标量增益训练500步可使图像均方差约减半，却几乎不改变坐标误差。一个可能解释是两个标量无法按空间位置调节更新。因此另加一个**仅在最后4097²级使用**的卷积修正头 $C_\theta$，有3,378个可训练参数；两标量从已训练增益开始，旧1025²及以下的图像编码器和增益仍冻结。该实验检验“给最后一级空间自由度能否改善图像到几何的推断”，而非再证明固定网格输出能力。

设 $F$ 是到达4097²末轮前的当前 P1 映射，$Q(x)=I_M(F(x))$ 是在512²图像格上的移动图像回采，$G(x)$ 是回采的移动图像中心差分梯度。七通道输入为 $(I_F,Q,100(I_F-Q),G_1/32,G_2/32,x_1,x_2)$。卷积头依次为 $7\to16$ 的3×3卷积、GELU、$16\to16$ 的3×3卷积、GELU、$16\to2$ 的1×1卷积；最后一层从零初始化。对其两通道 logit $c$ 作

$$
c^{\rm HP}=c-A_{17}c,
$$

其中 $A_{17}$ 是截断边界的17×17局部算术平均，再把 $c^{\rm HP}$ 双线性插值到4097²**提议**位置。实际更新为

$$
F^+=U_{4097}\bigl(F,\;e^{\lambda_{4097}}H_{4097}(F;I_F,I_M)
 +\operatorname{Interp}_{4097}(c^{\rm HP})\bigr).
$$

$U$ 是四着色局部几何安全更新，不是单纯的 $F+\operatorname{Interp}(c)$；它输出的原控制顶点随后仍经逐面保守证书检查。因此修正头的双线性插值**不是**把稀疏控制网同胚插值成密网同胚，其值只是对4097²每个原顶点局部安全步骤的建议。$2049²$ 新增级只用其已训练增益，无这个卷积头。具体实现与运行配置见[规模/训练脚本](../../tools/phase7_feedback_scale_probe.py)。

## 图像训练和独立评估

训练数据是32张 high128 合成固定/移动图像对，seed55101，512²图像、batch1；全部损失仅是经最终4097² P1 映射采样后的像素 MSE。从[两标量500步检查点](checkpoints/phase7_extra_gains_4097_float32_train500.pt)出发，Adam学习率.001继续训练卷积头和两增益500步；此时早先两标量模型的图像误差已经很小，是保守的增量检验。设备为AI远程机空闲的RTX A6000 48GB，PyTorch2.5.1+cu124，float32几何，额外细级激活重计算。500/500训练步均通过最终原面筛选；训练步中位 .625秒，CUDA allocated峰值12.263GB。训练结束两增益为(.8993,2.0162)，最后1×1卷积权重的最大绝对值约.00269，故网络不只是未训练的全零输出。保存[空间修正权重](checkpoints/phase7_extra_spatial_4097_float32_train500.pt)。完整解冻编码器的VJP成本没有由这次训练报告测量；冻结编码器到细级参数的forward＋VJP中位.624秒、allocated峰值12.401GB。

误差计算与[增益实验](65_trained_4097_extra_feedback_gains.md)完全相同：map RMSE 是512²查询位置的二维真值坐标误差；image MSE 是整批像素平方残差平均；最小 $J$ 在全部33,554,432个原三角面上按实际float32输出坐标提升为float64重算。输出固定4097²三角剖分上的单张 P1 图，而不是对多个连续因子的复合取样。

| 未参与训练的128例 | 两标量已训练 map RMSE / image MSE | 再训空间修正 map RMSE / image MSE | 空间修正最小 $J$ / 接受 |
|---|---:|---:|---:|
| high128，seed20261217 | .00048307495 / 2.2261e-8 | .00048307410 / 2.2267e-8 | .049166 / 128/128 |
| high128，新 seed20261231 | .00048763470 / 2.1137e-8 | .00048763464 / 2.1140e-8 | .049278 / 128/128 |
| high128_tri，新 seed20261231，三种高频载波 | .00045748779 / 6.0598e-9 | .00045748339 / 6.0738e-9 | .049276 / 128/128 |
| high128_tiles，新 seed20261231，16个空间包 | .00043825925 / 5.1280e-9 | .00043825204 / 5.1414e-9 | .049278 / 128/128 |

`high128_tri` 的高频位移用三个不同组合的正弦载波，`high128_tiles` 用16个局部窗调制高频载波；二者没有出现在训练集中，但仍使用同一标准纹理生成机制。所有观察到的几何差异远小于原有误差；不能把最后若干位数的微小正差解释为显著改进。与标量模型相比，空间头的增量没有跨种子、跨载波族显出有用收益。

单独更换图像外观为训练中没见过的稀疏 spots、保持 high128 形变和新 seed20261231 时，空间模型 map RMSE **.00839044**、image MSE **7.49e-7**、最小 $J=.049822$、128/128通过。相对标准纹理 map误差约17倍；扩大控制网格和新增空间网络都没有解决图像可辨识性/分布偏移问题。这里不把 spots 的低 image MSE 错当成几何准确。

## 能推断什么、不能推断什么

结论是本**特定初始化、局部高通架构、图像损失和32张训练图像**下，4097²空间修正能稳定反传且同胚，但没有测到实质几何收益；不是“任何空间神经修正都无效”的不可能性定理。可能瓶颈包括目标光度误差已接近离散采样下限、图像特征不足以区分细微形变、只在最后一级修正、或者低学习率使学习修正过小。下一次若继续此方向，应使用对照良好的更复杂形变/纹理与局部几何监督的 teacher 可达性实验，先区分“解码器表达”与“纯图像无法辨识”；在相同纹理和相同训练预算下测试是否有真实的地图精度改善。不能仅凭参数变多或图像 MSE 降低宣布 dense neural layer 的准确性问题已解决。
