# 两种百万顶点正向原语的相同图像任务对照：交错 patch 与四颜色顶点

## 问题、共同契约与区别

[F1 四颜色局部顶点更新](23_uniform_isotopy_multilevel_approximation.md)和[F2 交错 patch 同时更新](26_f2_uniform_isotopy_approximation.md)均直接修改**同一固定规则三角网格**的顶点像，没有求大线性系统，也没有将多个连续 P1 因子的复合误称为原网格 P1。本实验控制编码器、图像、latent 提案及认证器，只替换细尺度正向更新原语，问 F2 是否在百万顶点实际前向/VJP和图像训练中仍能达到 F1 的映射精度。

每例目标 \(T\) 是位于随机矩形支撑、方向/模长随机的高频局部位移；频率 \(k\) 从80至128的49个整数均匀抽。移动图为八项随机 Fourier 波叠加，固定图由**真值 P1 插值**后采样移动图。定义、边界、独立正向证明和指标见[原协议](28_unknown_fine_packet_demodulation.md)及[频率扩展](33_unknown_carrier_fft_encoder.md)。控制网格为1025×1025顶点、2,097,152个面；图像512×512。两种 decoder 的粗257² latent 均固定为零，真正学习的是细层1023²内部顶点 latent。任务覆盖的是一个合成高频族，不是任意图像注册。

F2 从单位顶点表 \(Y^0\) 开始，在一个四偏移周期中将边长为4个源单元的 patch 内部顶点**同时**向给定 endpoint proposal 移动；patch 边界暂时固定。四个偏移为 \((0,0),(2,0),(0,2),(2,2)\)，保证内部顶点均被覆盖。给定当前 patch 面的双面积
\[
A_T(s)=A_T(0)+L_Ts+Q_Ts^2,
\]
其中 \(s\in[0,1]\) 是该 patch 所有内部顶点共享的步幅。记 \(B_T=(-L_T)_++(-Q_T)_+\)，则 \(A_T(s)\ge A_T(0)-sB_T\)。实现以该 patch 所有面的允许面积下降预算的最小比率选 \(s\)，再留85%安全因子及归一化 \(J\ge .05\) 的预设下界；无不利项时取 \(s=1\)。因此在精确算术下，每个 patch 及每个交错周期保持全部面正向，固定外边界；实际二进制浮点输出另由逐面保守证书检查，不合格样本返回单位 P1 图。该布尔回退在分界处不可导，但已接受分支的一阶 VJP 可计算。F2 代码的逐面公式和边界处理见[实现](../../src/qcopt/neural_bijection/dense/patch_field.py)，证书见[实现](../../src/qcopt/neural_bijection/dense/multilevel_forward_p1.py)。

两路输入同一二维幅度提案 \(u\)，细 latent 均为
\[
z_i=\operatorname{atanh}\{\operatorname{clip}(u_i/(2h),-.95,.95)\},
\qquad h=1/1024.
\]
F1 的安全单顶点层 raw span 是 \(2h\)；F2 选 patch_cells=4、raw_span=.5，raw span 也是 \(.5(4h)=2h\)。因此并未因两路 latent 量纲不同造成对照失真。F2 一次周期有四个显式局部 pass，每个 pass 的 patch 可并行；本实验并未运行多级 F2 金字塔的非零 coarse latent。

## Oracle 表达与真实反向

先**不使用图像编码器**，直接从独立目标顶点 \(T_i\) 构造上述 \(z_i\)，输入 F2。seed99023、8例、batch2时全控制点向量 RMSE 数值为0，8/8通过证书，\(J_{\min}=.91229\)；seed99113、独立128例、batch4时仍为0，128/128通过，\(J_{\min}=.89223\)。这里的“0”是该特定小幅平滑目标在同一 float64 点表上按 endpoint proposal 重建的结果，**不是**所有 P1 同胚均可一次 patch 周期精确重建。独立全网格 VJP 探针的梯度逐项有限且有非零分量。128例 batch4 的平均一次认证 forward 82.22ms、VJP 281.25ms；峰值已分配8.931GB，包含常驻的128例数据与 autograd，不可作为裸层显存。脚本见[oracle 对照](../../tools/phase7_compare_patch_packet.py)。

## 相同 encoder 的实际训练

图像侧采用[全软频率编码器](35_soft_frequency_spatial_training.md)：FFT 评分、49频率 softmax（初始温度.02，可训练锐度）、局部2×2幅度解调、13,938参数空间 CNN；总参数13,939。训练256例seed31719、留出128例seed99113，batch4、Adam .001、600步。Map loss 为 \(10^8\) 倍全部控制点向量平方误差均值。输出为同一固定网格 P1，不是图像像素位移表。两路分别用 float64 几何内部运算、相同逐面认证，图像/网络 float32。结果：

| 正向原语，map监督600步 | 留出全图向量 RMSE | 支撑区 RMSE | image MSE | 最小 \(J\) | 频率 argmax/128 | 回退/128 | 平均训练步 | CUDA峰值已分配 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| F1 四颜色顶点 | 5.173701e-7 | 2.032054e-6 | 7.445655e-10 | .895741 | 128 | 0 | 147.86ms | 14.575GB |
| F2 四偏移 patch | 5.173651e-7 | 2.032051e-6 | 7.445667e-10 | .895741 | 128 | 0 | 316.95ms | 17.673GB |

两个模型的零初始化 baseline 都是全图 RMSE \(1.046248\times10^{-6}\)、支撑区 \(4.188079\times10^{-6}\)、image MSE \(2.390554\times10^{-9}\)，因为此目标族内两层都完整接受相同小幅 endpoint proposal。两路600步中可训练频率锐度每步均收到有限、非零梯度。F2训练步约是F1的2.14倍，显存也更高；此硬件/实现/任务下没有显示 F2 的速度优势。CUDA峰值包含整套256+128例数据常驻，故两数之差比绝对值更有比较价值，但仍包含不同 autograd 暂存量。设备为AI A6000 GPU2，PyTorch2.5.1+cu124；不计合成数据生成。完整 F2/F1 同脚本用 `--decoder patch|vertex` 复现：[训练脚本](../../tools/phase7_train_soft_frequency_spatial.py)。

另在相同256/128数据、600步、温度.02下只以512²图像残差监督F2，留出全图向量 RMSE \(8.476944\times10^{-7}\)、support RMSE \(3.388937\times10^{-6}\)、image MSE \(9.719344\times10^{-10}\)、\(J_{\min}=.89904\)，0/128回退，平均319.23ms/步。它与F1 image-only 的 \(8.477024\times10^{-7}\) 几乎一致，仍未追平 map 监督的几何精度。把真频率改成**从未训练的半整数** \(\{80.5,96.5,112.5,127.5\}\) 且重新采样128例(seed59473)后，该 F2 image-only 模型全图 RMSE 变为 \(5.22813\times10^{-6}\)，support 为 \(2.09324\times10^{-5}\)，image MSE \(1.61584\times10^{-7}\)，虽然全部输出仍通过拓扑认证。有限整数载波先验的分布外失败不可被分布内结果遮蔽。

## 目前结论

这证明**两种机制**都已在实际百万顶点控制网格、完整 P1 输出、非零 VJP、image-to-latent 多步训练上运行；只测 image/query 512² 不能替代这些检查。F2 的潜在价值不是这组小幅目标的准确率或速度，而可能是对“每个三角面多个相邻顶点一起移动”的 coherent 局部目标有更高表达效率，或者更适合多级 patch 动态。需要在**相近误差**下比较更大局部旋转/剪切、接近可行域边界和真正非零 coarse-to-fine latent；此处不根据一个 oracle 恰好精确就宣称 F2 优于 F1。两者的图像侧都仍依赖有限整数同轴频率字典，对连续/方向频率、噪声和自然图像尚无同等证据。
