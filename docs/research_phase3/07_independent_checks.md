# Phase III independent checks

This file records only claim, independent checker finding, and fix. A claim is
not closed merely because the builder's derivation or implementation passes its
own tests.

|---|---|---|---|
| C1 | Unit-grid electrical rectangle has modulus/energy/right flux/area (n_y/(n_x-1)). | Independent parallel-row derivation and 2x2, 3x2, 3x3 calculations agree; old 0.75 omitted one strip. | PASS for the restricted rectangular row-path-independent construction; weighted API documented as restricted. |
| C2 | Four-direction anisotropic decomposition is unique. | Rank-three coefficient map has null vector ((-1,-1,1,1)); exact signed family is one-parameter, while nonnegative feasibility is (|b|\le t\le\min(a,c)). | PASS after API/documentation correction. |

| C7 | SPD anisotropic mixed solve has monotone free-side traces. | Explicit 3x3 vertex/8-face case with (|\mu|=0.8) gives left middle-row increment (-0.10057537), despite SPD face tensors. | COUNTEREXAMPLE for fixed facewise-(P_1) complementary solve; continuum canonical-map monotonicity remains separate. |
