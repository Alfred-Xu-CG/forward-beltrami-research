# Phase III independent checks

This file records only claim, independent checker finding, and fix. A claim is
not closed merely because the builder's derivation or implementation passes its
own tests.

| claim_id | claim | checker finding | fix/status |
|---|---|---|---|
| C1 | Unit-grid electrical rectangle has modulus/energy/right flux/area (n_y/(n_x-1)). | Independent parallel-row derivation and 2x2, 3x2, 3x3 calculations agree; old 0.75 omitted one strip. | PASS for the restricted rectangular row-path-independent construction; weighted API documented as restricted. |
| C2 | Four-direction anisotropic decomposition is unique. | Rank-three coefficient map has null vector ((-1,-1,1,1)); exact signed family is one-parameter, while nonnegative feasibility is (|b|\le t\le\min(a,c)). | PASS after API/documentation correction. |
| C3 | Local transformed nonobtuse condition is globally necessary. | Isotropic 120°/30° shared edge gives local (+0.288675), (-0.866025), assembled (-0.577350). | PASS as a sufficient-only condition; use assembled edge sums for (M)-matrix claims. |
| C4 | Directed Tutte layer unconditionally guarantees a homeomorphism for its current boundary input. | The theorem requires a simple weakly convex/strict-corner boundary, positive directed weights, and 3-connected-to-boundary. The implementation now validates weak convexity/orientation/repeated vertices, but still does not check graph 3-connectivity. | REVISE: retain graph certificate as an explicit caller precondition. |
| C5 | Rectangle modulus latent is differentiable. | Independent finite-difference check at (m=-0.3): analytic gradient (1.651961931851348), central difference (1.651961931692370), absolute error (1.6\times10^{-10}). | PASS for tensor-valued width/height or modulus helper; float defaults are constants. |
| C6 | Directed Tutte is universal for arbitrary Beltrami coefficients. | Local-star positivity proof applies only to an already valid straight-line PL embedding with positive areas and boundary-reachable support. | REVISE scope to valid-embedding surjectivity; arbitrary-(\mu) expressivity remains open. |
| C7 | SPD anisotropic mixed solve has monotone free-side traces. | Explicit 3x3 vertex/8-face case with (|\mu|=0.8) gives left middle-row increment (-0.10057537), despite SPD face tensors. | COUNTEREXAMPLE for fixed facewise-(P_1) complementary solve; continuum canonical-map monotonicity remains separate. |
| C8 | Positive scalar conductances on the tested planar stencil force ordered free-side traces. | Exhaustive \(3^8=6561\) scalar assignments \(\{1,2,10\}^8\) on the 2x2-cell right-triangle stencil had no negative increment; minimum was 0.0909090909. | RESTRICTED PASS only for this M-matrix stencil family; no arbitrary-planar-graph theorem claimed. |
| CQ1-CQ2 | Continuum mixed Beltrami/conductivity theorem has the stated sign, same-(A) stream problem, and reciprocal energy. | Independent checker found no sign/orientation/algebra error. Required precision fixes: image is open rectangle interior; closure maps to closed rectangle; boundary implications are weak trace identities; insert (operatorname{div}(A\nabla v)=0); fresh audit additionally requires explicit Jordan wording, Carathéodory closure extension, a.e. arc-trace constants, and weak flux pairing. | PASS after document revisions; checker reports `tmp/phase3_continuum_checker.md` and `tmp/phase3_continuum_checker_reaudit.md`. |
| CQ8-continuum | Canonical continuum stream map has ordered marked-side traces. | Conditional on CQ1's canonical QC closure theorem, marked boundary arcs map homeomorphically to rectangle sides, so their coordinate traces are strictly monotone. Ellipticity alone is insufficient; the fixed-P1 negative trace example remains separate. | CONDITIONAL PASS for the canonical continuum map; OPEN/NOT CLAIMED for arbitrary independent discrete solves. |
| CQ10 | Directed Tutte can fit arbitrary QC/PL targets with exact universal expressivity. | Sine-bump targets on a 16x16-cell mesh fit with map RMSE 1.27e-3 to 4.12e-3, but facewise mu RMSE grows 1.95e-2 to 8.91e-2 and the determinant margin approaches 3.75e-6. | REVISE: empirical conditional expressivity only; no universal exact claim. |
| CQ11-CQ12 | Learnable modulus plus directed Tutte is a practical hard-bijective neural layer at realistic resolution. | Independent Tutte runs at 129x129 and 257x257 are finite and positive (257x257: 4.0842 s forward, 1.8012 s backward, RSS +121.4 MB). The MBM implicit CPU VJP is also finite (257x257: 14.1279 s forward, 12.1254 s backward, RSS +247.25 MB), but has 0.02352 conjugacy residual; graph 3-connectivity remains an explicit precondition. | CONDITIONAL: Tutte has lower measured prototype cost, but neither is a certified universal production solver. |
| CODE-SPD | `discrete_conjugacy` accepts only valid face tensors for the stated theorem. | Independent code checker found that determinant-positive alone admits negative-definite `-I`; the validator was corrected to require positive diagonal entries and determinant-one for the conjugacy residual. | PASS after focused regression tests. |
| CQ4-stream | A structure-preserving flux can be integrated as a discrete stream coordinate rather than reconstructed by an independent complementary solve. | The new edge-integrated prototype was independently tested on direct affine sign cases and the layered compatible P1 map: face predictions agree, cycle residual is below 1e-12, and reconstructed values equal the manufactured stream up to gauge. A random incompatible P1 potential with identity tensors is rejected by edge/cycle diagnostics. Boundary singleton edges necessarily contribute zero to face-mismatch, and tree-edge cycle residuals vanish by construction. | PASS as a compatibility diagnostic/prototype; not a general dual Hodge star, boundary solver, or arbitrary-μ neural layer. |
| CODE-BOUNDARY | Directed Tutte boundary preflight rejects all invalid target cycles needed for the theorem. | Independent checker found a boundary-only empty reduction and a self-intersecting star polygon. The layer now handles zero interior rows, checks device equality, and rejects repeated/negative-turn/self-intersecting boundaries. | PASS for these preflights; graph 3-connectivity remains a caller precondition. |
| CODE-AREA | Electrical tiling-area check is independent of the reference target. | Independent checker identified `target_area=modulus` as circular; the result field was removed and tests compare independently reconstructed area to right flux. | PASS after API correction. |
| CODE-METRICS | Benchmark determinant and memory columns have one consistent meaning. | Independent checker found raw triangle area and normalized Jacobian values were mixed and provenance was absent. CSV now records determinant definition, hardware class, seed, and RSS-delta semantics in notes. | PASS as a reporting correction; RSS is a process-level proxy, not allocator peak. |
| C6-ADAPTIVE | Eigen directions, metric pullback, or a full SPD Hodge block automatically solve the anisotropic route. | Eigen/pullback algebra is valid locally, but face-dependent metrics require weighted edge sums; a generic 2x2 Hodge block lacks specified basis/DOFs/assembly and gives no M-matrix/topology guarantee. The current P1 module is only a compatibility prototype. | REVISE: keep adaptive/metric/block routes open research, not implemented or proved. |
| SUPPORT-Beurling | A bounded-domain Beurling solve can use a periodic FFT without boundary qualification. | On a 128x128 compactly supported field, periodic vs pad2 differed 5.19% centrally and 27.5% in the outer annulus; periodic vs pad8 differed 5.53% and 29.5%, while pad4/pad8 central values differed 2.03e-4. | PASS as a caution: FFT is a torus/periodized operator; zero-padding is an approximation, and nonuniform meshes need quadrature/NUFFT/treecode. |
| SUPPORT-BHF | Legacy BHF multilevel evidence establishes a production-ready universal solver. | Independent checker matched the receipts: a separate 512x512-cell GPU-native single-step assembly took 1,044.19 s (1,066.53 s end-to-end), had zero flips, and a separate 32x32 NumPy Duffy parity run had relative L2 error 1.66e-7. The receipts omit GPU driver/software/seed/commit metadata; older validation identifies the device class as an AI RTX A6000. No bounded-domain principal-value theorem, arbitrary-mesh homeomorphism certificate, or production multistep benchmark is closed in Phase III. | SUPPORTING ONLY: retain the promising multilevel direction, but do not promote it to a certified candidate or call the failed large run a theorem counterexample. |
| CQ12-Tutte-unstructured | Structured-grid positivity evidence transfers automatically to a general mesh. | Independent Delaunay stress with 4,056 vertices and 7,854 faces had zero flips/intersections and finite VJPs at logit spreads 1 and 3, but the minimum signed-area ratio fell from 3.465e-3 to 5.547e-11. | REVISE: unstructured finite stress passes conditionally, but high logit spread is nearly singular and no arbitrary-mesh theorem is established. |
| CQ12-MBM-VJP | The MBM candidate has no differentiable backward prototype, or a finite VJP benchmark is only self-consistent. | `mbm_lbs_torch_implicit` was independently timed in isolated processes at 65/129/257 vertices (0.758/3.227/14.128 s forward; 0.752/3.019/12.125 s backward; RSS deltas +18.52/+59.85/+247.25 MB). A separate 7x7 directional finite-difference row (seed 3, epsilon 1e-6) gave relative gradient error 9.37e-10; independently recomputed P1 conjugacy residuals were 0.02416/0.02366/0.02352. The independent induced-face calculation gives all-face Beltrami RMSE 2.1288e-3/1.0675e-3/5.3513e-4 at 65/129/257 and 2.6822e-4 at 513, while max error remains about 1e-2. | PASS for existence of a CPU VJP prototype and empirical P1 refinement trend; REVISE candidate status because exact discrete conjugacy, GPU implementation, and hard topology certificate remain unresolved. |
| CQ12-highres | The two surviving neural-layer prototypes remain practical at 513x513 vertices. | Independent run: MBM output/gradient finite, 70.961 s forward, 46.875 s backward, RSS delta +1,290.8 MB, normalized minimum face determinant 0.50538, residual 0.02355. Directed Tutte at 512x512 cells (263,169 vertices) had finite output/gradient and zero flips/intersections at logit spreads 1 and 3, but minimum signed-area ratios 1.328e-3 and 2.5495e-12; the combined passes took 117.990 and 118.219 s, and RSS delta was not measured by that script. | CONDITIONAL numerical pass only; MBM memory is a major scaling bottleneck and high-spread Tutte is near singular. No production or universal complexity claim. |
| CQ7-wide-stencil | Enlarging a positive edge-direction stencil preserves topology while improving anisotropic tensor coverage. | Independent checker reproduced the structural counts, residuals, determinants, and 1,641 flips from the checked-in artifact.
