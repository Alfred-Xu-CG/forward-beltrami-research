# Native multi-chart registration for closed high-genus surfaces

Date: 2026-08-28

## Research question

Can two closed, orientable, same-genus triangle surfaces be registered without
turning either entire surface into one Poincare/universal-cover domain, while
allowing mapped points to move across chart boundaries and retaining a
numerically auditable global homeomorphism?

This prototype addresses the refinement problem: it assumes a topology-valid
initial homeomorphism and improves it using landmarks and intrinsic curvature.
Constructing a homeomorphism between two unrelated raw meshes with no
topological marking is a separate initialization problem and is not hidden in
the registration objective.

## Considered architectures

### A. Independent disk charts with consensus variables

Each source chart owns a planar map and duplicated overlap vertices; equality
or transition penalties weld the copies. This resembles the repository's
existing two-chart cylinder experiment. It is useful for testing transition
formulae, but it presupposes source/target chart correspondence, becomes
fragile when an image crosses target charts, and a small seam residual does not
certify a global bijection. It is therefore not the primary architecture.

### B. Fundamental polygon or universal cover

This gives one global optimization domain and familiar QC operators, but for
genus at least two it imports hyperbolic geometry and deck transformations into
the main computation. It is retained only as a conceptual baseline because the
research question explicitly asks whether a native multi-chart route works.

### C. Global surface map evolved through a native PL atlas

This is the selected architecture. A point on the target is represented by a
triangle id and barycentric coordinates. Every triangle interior is a local
chart. Adjacent charts are connected by intrinsic edge-unfolding transitions.
A mapped point may cross any number of target edges; its face id is discrete
bookkeeping produced by deterministic face walking, not an optimized chart
label. Vertex-star charts are used for diagnostics and local Jacobians.

There is one global map. Chart-local coordinates are transient views of that
map, so overlaps do not contain duplicated map unknowns and C0 compatibility
is automatic. This directly resolves the branch-assignment problem that occurs
when independent source charts are assigned to target charts.

## Inputs and initialization

Inputs are two connected, closed, oriented, manifold triangle meshes of equal
genus, optional landmark pairs, and an initial homeomorphism `F0`. The initial
map is represented on a common refinement: corresponding vertices and faces
have the same combinatorics but their 3D embeddings lie on the two original
surfaces. This representation is a certificate of a continuous piecewise
linear homeomorphism before refinement.

The official data for *Inter-Surface Maps via Constant-Curvature Metrics*
contains precisely such paired `M_on_A` and `M_on_B` meshes. The downloaded
package contains genus-3 and genus-5 pairs, not genus-2. They will be used as
real high-genus tests without claiming that they are genus-2 data. A generated
double-torus with known topology will exercise the exact genus-2 code path.

For controlled registration experiments, the published common-refinement map
is held out as ground truth. A reproducible smooth diffeomorphic perturbation
of it supplies a deliberately imperfect but topology-valid initialization.
Only landmark pairs and geometry-derived scalar descriptors are exposed to the
refinement algorithm.

## Registration model

The optimized map is

`F = phi_K o ... o phi_1 o F0`,

where each `phi_k` is a small surface flow generated by a smooth target tangent
vector field. A composition of sufficiently small orientation-preserving local
flows cannot change homotopy class and is the mechanism that protects global
topology.

At iteration `k`, forces are assembled from:

1. landmark attraction, using target-surface distance descent;
2. curvature matching, using scale-normalized smoothed Gaussian/mean-curvature
   descriptors and their local target gradients;
3. optional inverse-consistency and velocity regularization.

Scattered forces are converted to a smooth global tangent field by solving a
sparse screened graph-Laplacian system. The factorization is cached. A CFL-like
trust radius limits displacement relative to local edge length. All mapped
points are then advanced through triangle charts by face walking; residual
tangent displacement is unfolded across each crossed edge.

This is not a variable-mu solver. QC quantities enter as diagnostics and, in a
later extension, as regularizers on local flow Jacobians. That separation is
intentional: first establish a globally meaningful arbitrary-topology map,
then optimize its conformal distortion rather than using mu as a substitute
for the global correspondence state.

## Discrete atlas and dynamic chart changes

For a face with vertices `(a,b,c)`, a 3D tangent displacement is converted to
a barycentric derivative. The earliest barycentric coordinate reaching zero
identifies the crossed edge. The point is transferred to the unique adjacent
face and the remaining displacement is rotated about the shared edge so that
intrinsic length and direction in the unfolded pair are preserved. Boundary
or nonmanifold encounters are errors because the accepted inputs are closed
manifolds.

Crossing a target cut seam never occurs because there is no cut graph. Crossing
a local-chart edge is ordinary atlas transition bookkeeping. Points landing on
vertices use a deterministic incident-face tie break and a small interior
canonicalization.

## Numerical homeomorphism certificate

The mathematical guarantee comes from composition with `F0` through local
flows. Because numerical integration and PL vector fields are approximate, no
run is accepted on theory alone. Each saved result must additionally pass:

- source and target topology equality and closed-manifold checks;
- positive local orientation sampled at three-point probes in native target
  face charts;
- no collapsed orientation probes under a declared ratio threshold;
- forward/inverse flow round-trip error below the declared tolerance;
- topology, orientation, CFL, and inverse consistency sufficient for the
  implemented numerical isotopy/degree-one inference;
- no trajectory failure, boundary encounter, or exhausted crossing budget;
- monotone accepted objective under backtracking.

The code does not explicitly count global preimages or use exact predicates.
Its `degree_one` field is therefore an inference from a certified base
homeomorphism composed with small reversible orientation-preserving flows, not
an independent exact degree computation.  The report will call this a
numerical certificate, not a formal proof of an arbitrary smooth map.

## Experimental matrix

### Exact-topology tests

- generated closed genus-2 double torus under rigid motion and anisotropic
  geometric deformation;
- landmark-only, curvature-only, and combined objectives;
- multiple perturbation seeds and strengths;
- edge and vertex crossing stress tests.

### Real-data tests

- official `Fig11_genus/3` pair;
- official `Fig11_genus/5` pair;
- official pretzel genus-3 pair as an additional shape/mesh-resolution case;
- at least three deterministic perturbation seeds per pair.

Real data remain outside Git and are identified by archive SHA-256. The
download page and the local inventory are recorded. No dataset license is
inferred from the absence of a license file, and the archive is not
redistributed.

## Baselines and metrics

Baselines are the perturbed `F0` without refinement, landmark-only flow, and
curvature-only flow. The combined method must be compared at the same iteration
and smoothing budgets. Metrics are normalized landmark error, dense error to
the held-out common-refinement correspondence, curvature residual, orientation
margin, round-trip error, crossing count, accepted-step ratio, runtime, and
peak memory when available.

Success requires improvements over the perturbed initialization on the
aggregate, zero failed topology certificates, and per-case disclosure. A single
successful model is not sufficient. Failure on a case is reported rather than
removed.

## Deliverables

- tested OBJ/common-refinement loader and topology audit;
- face-chart atlas transitions and dynamic surface-point tracing;
- curvature estimation, smooth vector-field solve, and registration loop;
- reversible flow history and numerical injectivity audit;
- official-data inventory with hashes and provenance;
- deterministic genus-2 and multi-case real-data experiment runners;
- machine-readable metrics, images of colored correspondences and trajectories,
